# 开发里程碑

以下为建议的推进顺序，待团队确认。比赛截止时间未知，暂不安排日期。

| 阶段 | 产出 | 完成标准 |
| --- | --- | --- |
| 1. 确认范围 | 比赛要求、工具方案、首版设计 | 团队能说明首版做什么和何时提交 |
| 2. 基础原型 | 简单场景与基础操作 | 能移动、射击、与资源交互 |
| 3. 合作验证 | 联机与核心合作操作 | 两名测试玩家能连接并完成一次合作 |
| 4. 单关闭环 | 示例星球、救援与撤离 | 单人及多人均能从开始玩到胜利或失败 |
| 5. 扩展内容 | 角色和后续星球 | 基于共同规则增加内容；数量按剩余时间确定 |
| 6. 提交准备 | 稳定试玩包和比赛材料 | 按官方要求验收、打包、录制和提交 |

优先完成可玩的完整流程，再扩展角色、星球和美术表现。
