# 探索类游戏玩法参考

状态：参考资料，不代表团队已确认的设计。按地图、推进、线索、风险、敌人、自由度、叙事七个维度拆分，只记录参考游戏的做法。

参考游戏：Outer Wilds、The Long Dark、Lethal Company、Deep Rock Galactic（DRG）、TUNIC、塞尔达传说：旷野之息（BOTW）、Subnautica、Pacific Drive、Hollow Knight。

| 游戏 | 代表方向 |
| --- | --- |
| Outer Wilds | 以知识为进度 |
| The Long Dark | 以生存状态限制移动 |
| Lethal Company | 以风险和撤离形成节奏 |
| Deep Rock Galactic | 以角色能力解决地形问题 |
| TUNIC | 以说明书和秘密推动理解 |
| BOTW | 以地形和远景地标吸引玩家 |
| Subnautica | 以深度、资源和碎片叙事组织世界 |
| Pacific Drive | 以远征和返回基地组织故事 |
| Hollow Knight | 以互相连接的区域形成长期探索记忆 |

## 1. 地图

- **Outer Wilds**：探索空间由“节点”和“路径”组成。地标、光线、建筑朝向和环境构图让玩家大致理解路通向哪里，但不给任务箭头。重要地点要能快速辨认，又不能让玩家觉得每个角落都必须搜索。
- **The Long Dark**：大型手工地图，多个区域通过山口、铁路、峡谷、洞穴、隧道和冰面连接。各区域的难度、资源密度和风险等级不同，避难所是路线网络中的节点。
- **DRG**：程序生成的洞穴，由房间、隧道、矿区和垂直空间组成网络，不是单条走廊。随机地图让路线记忆不能完全套用。
- **TUNIC**：大量“看得见但到不了”的结构：远处的宝箱、角落的隐藏道路、当前方向进不去的平台、被墙/树/瀑布/高低差遮挡的路，需要从另一侧绕行。地图不会一开始就完整出现。
- **BOTW**：远景地标提供方向。山顶和高塔提供区域视野；湖泊、峡谷、山脊形成自然边界；火光、烟雾、巨型敌人和特殊建筑吸引注意；地形遮挡让玩家逐步发现新区域。
- **Subnautica**：以深度划分探索层级。浅海资源少但相对安全；中层出现新生物和材料；深层需要更长续航和更高抗性；部分地点只能用特定载具或资源抵达。
- **Hollow Knight**：多个互相连接的区域，初次进入看不到完整地图，也不会立刻理解所有出口。包含纵向区域、隐藏房间、单向通路、传送点、可破坏墙壁、能力限制区域和通往旧区域的捷径。探索感来自区域之间的关系，而不是房间数量。

要点：地图是节点和连接组成的网络；地标与地形承担导航；信息逐步揭示；空间按难度或深度分层。

## 2. 推进

- **Outer Wilds**：进度单位是知识。玩家不靠等级或装备变强，而是因为知道了某个地点、规则或事件，才能进入之前无法理解的区域；通过重复访问逐步理解世界。
- **TUNIC**：旧的说明书页面在获得新能力后产生新含义，旧地点重新开放。
- **Hollow Knight**：获得新能力后出现新的移动方式；发现经过的墙可以破坏；解锁捷径减少往返时间。
- **The Long Dark**：生存状态决定探索范围。
- **Subnautica**：资源和装备扩大探索半径。
- **Pacific Drive**：在车库改装和升级车辆，解锁下一次远征的能力；车辆状态影响可探索距离。
- **Lethal Company**：用回收的废品完成公司配额。
- **DRG**：任务目标和资源收集同时存在。

要点：推进可以是知识、能力、装备或探索半径；新知识或新能力会改变旧区域。

## 3. 线索

- **Outer Wilds**：信号探测器先告诉玩家“某处存在信号”，玩家再去调查来源。信号不是答案，而是调查入口，不同信号逐渐连成线索网络。线索分层：
  1. 远处看到异常建筑；
  2. 用工具确认异常来源；
  3. 进入地点发现文字或设备；
  4. 得知某个地点、人物或自然规律；
  5. 新知识改变对旧地点的理解；
  6. 返回旧地点，发现新的通路或信息。

  日志保存的是玩家已理解的世界结构，记录线索与地点、人物、事件之间的关系网络。
- **TUNIC**：游戏内说明书是世界中的物品，同时包含地图、操作说明和暗示。部分文字初期看不懂，图片和符号先于文字传达信息。秘密藏在视角死角、墙壁缝隙、地形边缘和地图视觉规律中，玩家要观察环境，而不是只看任务文本。
- **Subnautica**：玩家可以放置自定义信标，标记残骸、资源区、危险区、基地和未完成调查的地点，是玩家自己的地图标记系统。
- **The Long Dark**：游戏提供信息但不给完整答案，地图信息逐渐由玩家自己绘制。
- **Pacific Drive**：异常现象既是危险，也是地图信息：哪些区域会损坏车辆、哪些路能通过、哪些资源值得冒险、哪些异常接近后会变化。

要点：先有信号，后有线索，线索不直接给答案；日志记录关系而不是清单；图像和布局也承担信息传递；玩家可以自己标记。

## 4. 风险

- **Lethal Company**：主要压力来自“还要不要再进去一次”。已经拿到一批值钱物品时，继续深入可能收益更多，也可能因为时间、怪物、路线或队员死亡而失去全部成果。废品价值和重量不同，携带会影响行动；价值越高的物品往往在越危险的区域。撤离本身是一次决策，信息不完整制造紧张感，队伍失误影响所有人的收益。
- **The Long Dark**：寒冷不是单纯扣血，而是直接限制探索半径。天气恶化会让原本能走通的路耗时更长，体温下降迫使玩家改变路线。避难所是判断“继续前进还是返回”的决策位置。
- **DRG**：撤离阶段通常比进入阶段更紧张。队伍要判断是否继续深入、是否提前呼叫撤离。
- **Pacific Drive**：一次远征是一段完整的探索单元，需要不断修理车辆，并判断是否继续深入或掉头返回。
- **Subnautica**：越深的区域需要越长的续航和越高的抗性。

要点：风险来自“继续还是撤离”的取舍；生存状态和负重直接限制行动范围；撤离是决策，不是结局动画。

## 5. 敌人与危险

- **Lethal Company**：敌人不是固定的任务目标，而是环境中的不确定因素，可能受时间、声音、光线、玩家位置、队伍是否分散、是否进入深处、是否拿着高价值物品影响。目标是回收，不是消灭所有敌人；敌人是探索节奏的压力来源。
- **The Long Dark**：野生动物和动态天气都会改变行动计划。
- **DRG**：部分任务需要在固定地点持续防守。
- **Hollow Knight**：原本安全的区域可能出现新敌人。
- **Pacific Drive**：异常区域本身就是危险，会改变路线和风险。

要点：敌人和天气是压力来源，不一定是目标；出现条件与玩家行为挂钩。

## 6. 自由度

- **BOTW**：同一目标有多条接近路线，可以绕路、攀爬、滑翔、游泳，或利用环境物体、天气和物理系统。玩家看到远处目标后，接近途中会经历许多小发现，而不是沿任务线直达终点。
- **Outer Wilds**：地标给出大致方向，不给箭头，保留玩家自己决定路线的自由，同时减少无目的徘徊。
- **DRG**：四个职业对应不同的地形问题：
  - Scout：移动速度快，负责侦察和照明；
  - Engineer：搭平台、建防御；
  - Driller：挖穿岩石，开辟隧道；
  - Gunner：提供火力、护盾和绳索。

  队伍要判断走主通道还是挖捷径、是否先采资源、成员是否保持在能互相支援的距离。
- **Lethal Company**：多人分工：一人进入内部，一人在外部观察，一人搬运，一人判断撤离时机；队伍是否分开影响信息掌握和救援能力。
- **Subnautica / Outer Wilds**：探索顺序可以不同，故事不按单一线性顺序展开。

要点：目标有多条路线；方向靠地标而不是箭头；职业差异体现在空间能力上；多人分工本身就是策略。

## 7. 叙事

- **Subnautica**：故事分散在逃生舱记录、无线电讯息、外星设施、失事残骸、PDA 文档、录音、生物与环境变化，以及玩家自建的基地中，可以按不同顺序发现。
- **The Long Dark**：较少依赖连续过场，通过遗留物资、废弃房屋、尸体、书信、旧营地、铁路设施和区域之间的地形关系，让玩家推测过去发生的事情。
- **Outer Wilds**：先让玩家看见兴趣点，再让玩家理解兴趣点；新知识改变旧地点的含义。
- **TUNIC**：说明书把教学、地图、提示和世界观合在同一套物件里。
- **Pacific Drive**：通过远征中发现的记录、地点和人物信息展开，每次返回都带回资源和故事信息。
- **Hollow Knight**：某个地点可能从普通通道变成剧情地点。

要点：叙事以碎片形式藏在环境里，玩家自己拼合；记录物同时承担教学或导航功能。

## 8. 机制分类总表

| 机制类别 | 代表游戏 | 具体表现 |
| --- | --- | --- |
| 知识推进 | Outer Wilds、TUNIC | 玩家因为理解规则而获得进展 |
| 生存限制 | The Long Dark、Subnautica | 温度、体力、氧气、资源影响探索距离 |
| 撤离风险 | Lethal Company、Pacific Drive | 决定继续深入还是带着成果返回 |
| 职业分工 | DRG | 不同角色拥有不同的空间处理能力 |
| 远景地标 | BOTW、Outer Wilds | 远处目标吸引玩家主动靠近 |
| 关系型地图 | Hollow Knight、The Long Dark | 区域通过通道、捷径和节点互相连接 |
| 碎片化叙事 | Subnautica、Outer Wilds、Pacific Drive | 故事分散在环境、设备、记录和地点中 |
| 游戏内说明书 | TUNIC | 教学、地图、提示和世界观由同一套物件承载 |
| 不确定性威胁 | Lethal Company、The Long Dark | 敌人和天气改变玩家的行动计划 |
| 远征循环 | Pacific Drive、Lethal Company | 出发、探索、获得成果、撤离、返回基地 |
