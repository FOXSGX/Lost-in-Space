# Resonance 01 Codex 迭代材料

本文件是独立工作区的设计材料，不更新正式总纲；所有新内容均标记为“待讨论建议”。

## 方案 A：连续工业通道（本轮实现）

目标是让玩家沿一条真实设施路线逐步恢复系统。反复动作是观察可见机械状态、搬运模块、调整 damper、在风场中抓扶/救援、准备矿车。优点是叙事和空间连续，最小验证可以只用一台风机和四个出发检查。非目标是敌人、战斗和复杂流体模拟。

## 方案 B：分层维护井

玩家在垂直维护井的上下层之间交换阀门和模块，风场由上下压差驱动。合作差异更强，但需要更多垂直碰撞、攀爬和镜头验证，最小验证成本更高。本轮不实现，保持为待讨论建议。
