# 核心玩法

## 已确认

玩家通过生存射击、探索和搜集物资推进星际返航。在分支路线中，可以快速通关，或探索支线获取资源。

## 待讨论的流程

以下为组织讨论的草案，并非会议已确认规则：

选择星球 → 准备 → 登陆 → 战斗与采集 → 撤离 → 使用资源继续航行。
