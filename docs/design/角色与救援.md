# 角色与救援

## 已确认的方向

- 计划设置具有不同技能或特点的角色。
- 联机模式：死亡后留在原地，队友到场救援复活。
- 单人模式：通过搜刮绷带、复活药等物资获得自我复活机会。

## 待确定

- 是否区分倒地和死亡？
- 救援是否有时限，是否消耗资源，需要多长操作时间？
- 救援过程中能否移动或射击，受伤是否中断？
- 复活后的生命值、位置和保护时间如何设置？
- 携带物资是否掉落或损失？
- 单人复活物资如何获得，有多少次机会？
- 全队死亡或单人复活机会耗尽后，重试范围与资源损失是什么？
- 首版包含哪些角色，技能如何兼容单人模式？

尚未确定飞船复活机制，不将此前助手建议作为已定规则。
