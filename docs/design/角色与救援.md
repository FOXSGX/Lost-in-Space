# 角色与救援

## 已确认的方向

- 计划设置具有不同技能或特点的角色。
- 联机模式：死亡后留在原地，队友到场救援复活。
- 单人模式：通过搜刮绷带、复活药等物资获得自我复活机会。

## 用户确认：角色专属工具（2026-10-17）

用户选定“混合”结构：**底层每人一件全局固定的专属工具，每颗星球再提供一个改装槽**，并确认首版一次做四名角色、允许工具直接替代霜烬星现有的 E/F 操作。

| 角色 | 专属工具 | 当前已实现的效果 |
| --- | --- | --- |
| 导能员 | 导能枪 | 修复距离 2 → 4.5 米；共振星直接接管轨道供能端（不再校准） |
| 工程师 | 磁力钩索 | 拾取距离 2.4 → 15 米（远距拉取电池）；共振星直接接管对接夹具 |
| 侦察员 | 广域扫描仪 | 扫描半径 ×1.5（风暴中同样生效） |
| 护盾手 | 便携护盾 | 附近无可交互物时按 E 展开护盾 3 秒，受到伤害降为 35% 且只吸收一次 |

- 工具按加入顺序分配，四人不重复，随主机快照同步。
- 星球改装：霜烬星「保温供能」（导能枪修复信标时附近 8 米队友体温 +15%）；共振星「抗过载」（快线过载增长减半）。
- 单人：工具照常可用，双端机关仍由无人机补位。

**尚未实现**：单人中途换装、工具的握持/攻击动画、以及四件工具更深的差异化（目前导能/钩索偏“距离与接管”，扫描/护盾偏“增益与减伤”）。

### 工具模型与护盾可视化（2026-10-18）

- 四件工具与护盾罩均已用 Blender 脚本生成（`art-source/editable/character-tools/build_character_tools.py`），导出为 `game/assets/characters/tools/*.glb`。
- 挂点：背包右侧腰间，缩放 1.7。曾尝试握在手心，第三人称背后视角几乎不可见，因此改为腰挂；角色没有骨骼动画，工具只能是刚体挂件。
- 护盾：按 E 展开时显示半透明球罩 + 发光底环，结束后隐藏。
- 换装即时生效（`SpacePlayer3D.set_tool()` → `ProtagonistVisual.set_tool_model()`），主机快照里仍只同步工具 id。

### 外观与星际集市（2026-10-18，用户确认）

- 默认角色换成「侦察兵」皮肤：钢蓝护甲、风衣后摆、青色面罩光缝。
- 星币来源：投送热能电池 +120 星币。
- 星际集市：在飞船上按 `B` 打开，`1-5` 选择、`Enter` 购买/装备。首版五套皮肤：

| 皮肤 | 标签 | 价格 |
| --- | --- | --- |
| 侦察兵 · 标准型 | 帅气（默认） | 0 |
| 轨道贵族 · 黑金礼服 | 帅气 | 1200 |
| 星云礼服 · 白瓷 | 好看 | 900 |
| 女武神 · 绯红重甲 | 好看 | 1500 |
| 充气小黄鸭 | 沙雕 | 600 |

- 皮肤模型由 `art-source/editable/characters/build_protagonist.py` 按 `STYLES` 生成，含 male/female 体型差异。
- 购买由主机校验并广播 `sync_market_state`；`player_skins` 记录每名玩家的当前皮肤。

**尚未实现**：星币与已购皮肤不落盘（重开会归零）、集市没有模型预览、皮肤只有五套且不能自由配色。

## 待确定

- 是否区分倒地和死亡？
- 救援是否有时限，是否消耗资源，需要多长操作时间？
- 救援过程中能否移动或射击，受伤是否中断？
- 复活后的生命值、位置和保护时间如何设置？
- 携带物资是否掉落或损失？
- 单人复活物资如何获得，有多少次机会？
- 全队死亡或单人复活机会耗尽后，重试范围与资源损失是什么？
- 首版包含哪些角色，技能如何兼容单人模式？

尚未确定飞船复活机制，不将此前助手建议作为已定规则。
