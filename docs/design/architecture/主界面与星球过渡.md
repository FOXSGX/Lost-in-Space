# 主界面与星球过渡架构

## 入口层

`game/scenes/main_3d.tscn` 是当前运行入口。`main_3d.gd` 创建真实 3D 星球场景，并使用 `CanvasLayer` 承载 HUD 与联机菜单：

- `Main3D`：`main_3d.gd`，负责真实 3D 世界、正交摄像机、联机玩家、敌人、波次和交互。
- `CanvasLayer`：`main_3d.gd` 内创建联机菜单、HUD、状态、生命和任务进度。

用户已确认的进入流程：先在飞船上了解交互和按键，再前往第一个星球。当前实现为“主界面 → 可移动的飞船教学区 → 星际航线图 → 霜烬星”。创建主机后进入飞船，所有船员依次练习移动、扫描、修复、拾取、投送、攻击和救援；完成后到航线终端打开航线图，由主机确认登陆。船内操作台顺序及训练完成条件属于当前原型实现，后续可按试玩反馈调整。飞船 HUD 使用 `CanvasLayer`，船舱与星球使用正交 `Camera3D` 呈现低模 2.5D 视觉。

船内玩家位置由各自客户端同步给主机，训练步骤由主机判断并同步。中途加入的玩家进入当前飞船场景，收到已有玩家及其训练进度。星球任务成功或失败后返回可操作飞船，并重置训练。

霜烬星 3D 玩法已补齐旧版关键规则：每 15 秒无限定时增援、暴风雪和缩小后的扫描范围、局部视野变暗、体温/氧气消耗与热源恢复、3 秒持续救援、全员倒地失败返航、目标完成且清场后撤离并返回飞船，以及主机权威同步玩家状态和任务物件。

## 航线状态

`PlanetRegistry` 是星球目录。每个目的地有标题、简介、场景入口、是否开放和主题色。主机只能通过 `request_stage_transition()` 发起开放目的地的过渡，客户端通过 `begin_stage_transition()` 跟随。

过渡期间：

1. 全部玩家停止移动和攻击。
2. 显示登陆或返航画面与进度条。
3. 主机计时结束后广播 `change_stage()`。
4. 发送 `finish_stage_transition()`，恢复关卡 HUD。

中途加入的玩家会同时收到当前阶段、玩家/敌人快照和过渡状态，避免看到空场景或停在错误阶段。
