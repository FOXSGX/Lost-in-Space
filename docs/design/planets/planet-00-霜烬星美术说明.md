## 1. 这次说的是哪份“模板”

共振星的美术不是靠一张概念图，而是三层可复用的做法，霜烬星这次只复用**方法**，不复用模型：

| 层 | 共振星的做法 | 霜烬星的对应实现 |
| --- | --- | --- |
| 材质族 | `game/shaders/cave_rock|floor|crystal|metal|energy.gdshader`，世界坐标、无贴图、每族独立磨损语汇 | 新增 `game/shaders/frost_panel|rock|snow|ice|bone.gdshader` |
| 美术层 | `game/scripts/resonance_cave_art.gd`：按材质名分配 shader 族、自建环境、灯光、粒子，不接管玩法 | 新增 `game/previews/frost_station/frost_art.gd` |
| 验收 | 四机位 + 近景特写 + 新旧同机位对照 + 性能五项 | `game/previews/frost_station/art_capture.gd`、`art_bench.gd` |

## 2. 视觉 DNA 落地（标准第 1 节的七条）

| # | 标准要求 | 霜烬星的落地 | 状态 |
| --- | --- | --- | --- |
| 1 | 机械有可信工业结构 | 站房墙体按 2.85×1.8 m 钢板分块，板缝有凹槽与倒角、四角铆钉；门斗是钢管立柱 + 横梁 + 雨棚 + 灯具，承力路径可读 | 部分（墙板是平贴面，未做真实倒角几何） |
| 2 | 自然环境有真实地质形态 | 基岩用高度驱动的层理（0.58–0.80 m 一层，层间硬错台）、解理裂纹、霜壳；远景脊顶压雪 | 部分（远景岩脊仍是旋转方盒，剪影不自然） |
| 3 | 晶体与环境发生关系 | 冰晶簇只长在仓库冰封门与骨口附近的地面裂隙，成群、倾斜、底部有吹积雪裙 | 是 |
| 4 | 材质体现使用历史 | 面漆 → 底漆 → 裸金属，掉漆只发生在板缝/铆钉/竖向流痕处；墙脚积垢；朝上面落雪；融冰后变湿变透 | 是 |
| 5 | 灯光建立主次 | 低角度主光 + 天空侧副光 + 骨口方向轮廓光；每栋门口有可见灯具与暖光；室内靠墙机装灯；环境光只托底 | 是 |
| 6 | 交互物清楚可信 | 吸推器、保险柜、控制台、运输车沿用原有可读件，只统一材质语言，不新增悬浮提示 | 是 |
| 7 | 近景有真实细节 | 1 m 内可见板缝倒角、铆钉、掉漆分层、混凝土骨料与气孔、冰的裂纹与气泡、骨孔 | 部分（无 UV 烘焙法线，倒角级转折缺位） |

**没有照搬的地方**（标准第 2 节明确要求）：不搬共振星的青蓝晶体、立柱横梁机械、红色岩层；霜烬星用冷蓝灰 + 奶白钢构 + 冰青 + 骨白，地质成因是“冰盖 + 风蚀 + 冻融”，危险信号是冰封与低温而不是熔岩。

## 3. 色板

三级关系（主色 / 辅色 / 点缀），六栋各有一个识别色，只出现在踢脚带、门斗与灯具上：

| 角色 | 颜色 | 用在哪 |
| --- | --- | --- |
| 主色 | 冷奶白 `#9e9789` | 站房墙板、屋面檐口 |
| 辅色 | 蓝灰 `#7b8387`（混凝土）、`#3a4f5e`（基岩）、`#c9d8e4`（雪） | 基座地坪、岩体、雪 |
| 点缀 | 锈红底漆 `#7d3f30`、裸金属 `#8b9296`、冰青 `#4a8fa3`、骨白 `#c9bfa6` | 掉漆、紧固件、冰体、骨架 |
| 识别色 | 主楼 `#72c5ce`、标本馆 `#c7b995`、生活楼 `#9dbb9f`、动力站 `#e1ae65`、车库 `#d8b47a`、仓库 `#b8be9b`、飞船 `#e5b676` | 踢脚带、门斗、灯具、室内灯罩 |

识别色沿用 0.4 原有 `shell(tint)` 布置，不新增语义。

## 4. 五个材质族

| 族 | shader | 覆盖对象 | 关键参数（实际取值） |
| --- | --- | --- | --- |
| wall | `frost_panel` | 墙、隔断、门柱 | 板 2.85×1.8 m、缝 28 mm、踢脚 0.95 m、掉漆阈值 0.70、粗糙 0.44 |
| painted | `frost_panel` | 门斗、雨棚、识别色构件 | 板 0.85×0.55 m、粗糙 0.40、金属度 0.22 |
| fitting | `frost_panel` | 灯具外壳、小型五金 | 板 0.34×0.22 m、无铆钉、金属度 0.55 |
| slab | `frost_panel`（`concrete_mode=1`） | 屋面、地坪、基座、湿痕带 | 骨料 + 气孔 + 模板缝，朝上面 82–100% 覆雪 |
| rock | `frost_rock` | 六栋以外的岩体、洞厅、冰缝 | 层高 0.58–0.80 m、霜 0.55–0.75、雪 0.85 |
| snow | `frost_snow` | 地面雪块、雪堆、雪檐 | 风向 `(0.82,0,0.57)`、风蚀纹、晶粒高光、灰土只在雪薄处 |
| ice | `frost_ice` | 封门冰、冰锥、冰晶簇 | 芯 `#0a2f3b` / 体 `#4a8fa3` / 边 `#c3edf7`，`melt` 由玩法 `amount` 驱动 |
| bone | `frost_bone` | 标本馆骨架、遗迹巨口、骨脊 | 骨孔 0.40、沉积染色 0.38、顶部薄雪 0.55 |

三张 shader 的共同点（与共振星一致）：世界坐标、无贴图、每个材质族一套独立的高度/粗糙度分布；不同族的色板与磨损语汇统一。

## 5. 灯光（GL Compatibility 下的取值）

| 灯 | 类型 | 取值 | 作用 |
| --- | --- | --- | --- |
| 主光 | DirectionalLight3D | `#ffe2c6`，0.88，俯角 24°，开阴影，阴影距离 240 m | 低角度极地斜阳，掠射墙面 |
| 副光 | DirectionalLight3D | `#8cbbff`，0.28，无阴影 | 天空侧补光，托住暗面 |
| 轮廓光 | DirectionalLight3D | `#c8e6ff`，0.22，无阴影 | 从骨口方向把屋脊剥出来 |
| 门口工作灯 | OmniLight3D ×7 | `#ffcf9a`，0.55，9 m | 有灯体、灯罩的可见灯具 |
| 室内机装灯 | OmniLight3D ×2 | `#cfe2ee`，0.85，22 m | 只给主楼与标本馆两处大空间 |
| 环境光 | Environment | `#9fb8c8`，0.50 | 只托底；关掉主光时形体仍可读 |
| 雾 / 色调 | Environment | 雾 `#8ba3b6` 密度 0.0038；Filmic，曝光 0.85，对比 1.05，饱和 1.06 | 远景大气层次 |

旧版的单盏平行光与渐变天空由美术层整体替换（`_replace_environment()`），避免双主光。

## 6. 形体级细节（美术层新增，均无碰撞）

- 每栋：混凝土基座、四边雪檐、门斗（2 立柱 + 横梁 + 雨棚 + 檐上雪）、门口工作灯、檐下冰锥 7–11 根、墙脚湿痕带、迎风侧雪堆。
- 站区：作业院雪地裂隙 6 条、仓库/骨口冰晶簇 4 组、三处稀疏飘雪。
- 冰封门：底部雪裙、冰面分块、底部冰锥（随融冰一起缩小）。
- 远景：两侧岩脊脊顶压雪（`RidgeSnow_*`）。
- 家具：Kenney 风格 GLB 家具的粉紫/黄原色向站区蓝灰收 55%、粗糙度提到 ≥0.58，避免“两种美术”。

## 7. 代码与开关

| 文件 | 作用 |
| --- | --- |
| `game/shaders/frost_panel.gdshader` 等 5 个 | 材质族 |
| `game/previews/frost_station/frost_art.gd` | 美术层：材质分配、环境、灯光、细节、融冰联动 |
| `game/previews/frost_station/world.gd` | 唯一接入点：`build()` 末尾调用 `install_art()` |
| `game/previews/frost_station/art_capture.gd` | 四机位 + 特写截图（同机位可复现） |
| `game/previews/frost_station/art_bench.gd` | 帧时 / Draw Call / 图元 / 材质 / 灯数采样 |
| `game/previews/frost_station/shader_check.gd` | 五个 shader 的真实编译检查 |

开关：`FROST_ART=0` 关闭整个美术层（用于改造前后同机位对照），默认开启。
美术层不改 `box()` 的碰撞、不改 `landmarks`、不改任何交互距离与主机权威结算。

## 8. 验收与未达标项

同机位对照与近景特写见 `work/art-iterations/20261124-frost-station-art/evidence/`；
逐项结论、性能数据与自评见该目录 `05-test-report.md`。

**视觉结论：CONDITIONAL GO**。技术侧全绿（玩法回归 54/54、shader 编译通过、静态检查 0 条新增问题），
视觉侧 B1/B4/B7 仅部分达成，主要缺口：

1. 墙板是“平贴面 + shader 板缝”，没有真实倒角几何与 UV 烘焙法线 —— 1 m 内仍能看出是程序化网格（B1/B10）。
2. 远景岩脊本体仍是旋转方盒，只有脊顶加雪，剪影不自然（B4）。
3. 封门冰整体仍是长方体，靠裂纹/雪裙/冰锥弱化，未做成不规则冰体（B5）。
4. 缺少 2K 法线/粗糙/掩膜贴图与顶点色掩膜，未达到模板 C4。
