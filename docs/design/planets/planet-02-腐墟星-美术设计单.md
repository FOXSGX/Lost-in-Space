## 1. 一句话定位

**被菌群吞掉的傍晚殖民城**：低天光下，旧米白工业立面压着暗泥炭褐与氧化铅灰的街道，
青绿是结构、安全与“已接通”，工业橙只出现在还能操作或需要警示的地方，
菌盖/星髓从排水口、墙脚和能源站裂缝里长出来——它必须一眼区别于共振星的红褐洞穴 + 青紫晶簇。

- 发光一律 `soft_knee(e) = e / (1 + e * 0.62)`；没有“整块发光塑料”。
- 植被并入基底统计，不单独占 10–15% 的壳色额度。

## 4. 材质家族与 2K 贴图

| 家族 | 用途 | 粗糙度 | 细节强度 | 贴图 |
|---|---|---|---|---|
| `paint_clean` | 建筑外壳/罩壳 | 0.50 | 0.85 | `paint_normal/rough/mask` |
| `paint_worn` | 街具、门板、普通设备 | 0.47 | 0.80 | paint |
| `paint_accent` | 可操作件、警示边界 | 0.48 | 0.85 | paint |
| `cast` | 铸铁底座、深钢 | 0.64 | 0.85 | cast |
| `mach` | 机加工：栏杆/手柄/阀/管 | 0.26 | 0.42 | mach |
| `conc` | 承台、勒脚、铺装 | 0.88 | 1.00 | conc |
| `rock` | 远景低丘、崩积、碎岩 | 0.45–1.0 | 0.70 | `rock_*`（`aqs2_rock`） |
| `bio` | 菌盖/菌褶/菌丝/感染体 | 0.55–0.75（湿 0.15） | 0.75 | `assets/ruin/textures/bio_*` |
| `foliage` | 树冠/灌木/草 | 0.86 | 0.55 | paint |
| `glass` | 窗玻璃、采光顶 | 0.20 | — | 标准材质 + 弱自发光 |
| `emissive` | 灯具/状态灯/孢子囊 | — | — | 标准材质 + 软膝 |

**纹理导入**（`game/assets/art-sample-002/textures/*.import` 与 `game/assets/ruin/textures/*.import`）：
- 法线：`compress/mode=2`、`compress/normal_map=1`、`mipmaps/generate=true`。
- 粗糙/掩膜：`compress/mode=2`、`mipmaps/generate=true`。
- 程序网格没有顶点色，所有分层 `ShaderMaterial` 必须 `vertex_mask_valid=false`；
  只有 `ART.batch_boxes()` 显式烘焙近似遮罩的合批网格才为 `true`。
- `bio` 家族由 `art-source/ruin/textures/make_ruin_textures.py` 生成（FFT 无接缝 + 同心生长纹 + 孔蚀 + 湿脉络）。

**禁止**
- 同一张噪声套所有家族；每族独立高度场/粗糙通道。
- 用裸 `BoxMesh/CylinderMesh/SphereMesh` 当成品；至少替换为倒角盒 / 车削 / 挤出 / 面化岩块。
- 发光拉满、无软膝；晶体/孢子/灯条必须保留色相梯度。

## 6. 物理因果与“零悬浮文字”

- **导管**：能源站→城区三轨装甲导管（沿墙脚/地面，绕开门洞，端面法兰 + 管卡），
  3 盏状态灯：`locked` 红 / `ready` 琥珀 / `active` 青；状态只读 `extraction_ready()` 与既有目标进度。
- **登陆艇控制台**：实体表盘读目标进度（0–1）、3 盏状态灯、贴壁纯图示铭牌（门锁→目标→撤离）。
- **四栋门锁**：锁板 + 锁芯 + 锁孔 + 带遮光罩三态灯 + 加固小牌 + 铰链/闭门器/门槛。
- **能源站 B1/B2**：泵房/反应堆控制台的图示铭牌 + 状态灯，只读 `story_plan/story_flags`。
- **禁止**：`Label3D`、Billboard、漂浮图标、空中箭头。所有提示走贴壁图示铭牌或 HUD。

## 7. 本星生态密度梯度（世界观视觉化）

| 区域 | 密度 | 载体 |
|---|---|---|
| 登陆艇 / 城市边缘 | 0 | 保持干净，作为安全锚点 |
| 街道排水口 / 背阴墙脚 / 超市排风口 | 低 | 菌丝斑 + 2–3 朵菌盖 |
| 医院 B1 药库、学校食堂角落 | 低–中 | 小菌簇 + 菌丝斑 |
| 能源站排风塔、裂开基座 | 中 | 菌簇 + 星髓晶柱 + 碎石压边 |
| 能源站 B1/B2、庇护所入口 | 高 | 菌盖群 + 荧光孢子囊 + 星髓柱 + 蒸汽 |

菌簇根部必须埋入宿主 15–25%，外圈有碎石/蚀变槽；不允许“摆在地面上的菌伞”。
星髓必须从裂缝里长出来，根部有压裂石片。

## 8. 几何工艺硬规则

- 主骨架大圆角 8–35 mm；加工棱 0.8–3 mm 且 ≥2 段；建筑主转角 40–60 mm。
- 立面分板留 **24 mm** 真实凹槽；薄板真实厚度 ≥8 mm 带折边。
- 所有落地件带承台/底脚/螺栓；管线带法兰与管卡；灯具带挂架与遮光罩。
- 陈设只贴墙/贴角放置，走廊净宽 ≥2.0 m；不新增玩法碰撞。
- 远景低丘/崩积必须“面化 + 平面切削 + 底埋”，禁止平滑球 + 噪声。
- 合批：静态小件走 `ART.batch_boxes()`（多 surface 单 MeshInstance）；
  投影只保留主光与建筑主体，薄片/贴地/合批细节 `cast_shadow=OFF`。

## 10. 已知偏离

本机没有 Blender 5.2.2，也没有腐墟星 `.blend` 源；指南方法一的“高模 Subsurf + Cycles 高烘低 + `.blend` 交付”未执行。

高模烘焙的曲率/AO 掩膜以合批顶点近似遮罩替代。该偏离在交付报告中按指南格式标记为 CONDITIONAL GO。
