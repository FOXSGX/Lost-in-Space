## 当前可试玩流程

1. 创建主机并生成玩家。
2. 点击“进入示范星球”，全部玩家移动到 4 个出生点槽位，危险区一带生成 4 只敌人。
3. 清除危险区内的敌人。玩家近身攻击距离 96，冷却 0.35 秒，每次 1 点伤害；按住空格即可连续攻击。信标可以在战斗中按 `E` 扫描。
4. 到资源区按 `E` 拾取资源箱，一次只能携带一份，携带期间移速降到 0.72 倍。
5. 把资源送到投送撤离点按 `E` 上交，重复到 4 份全部投送。倒地会把携带的资源丢掉，需要重新拾取。
6. 移动到 3 个示范信标附近按 `E` 扫描：客户端检测半径 96，主机复核半径 104；战斗中仍可扫描。
7. 界面显示 `信标 3 / 3　资源 4 / 4`，撤离点开启。
8. 全部在线玩家同时进入撤离点，持续 3.0 秒。
9. 显示“示范星球任务完成：全体队员已成功撤离！”，短暂显示完成状态后自动返回飞船准备区。

撤离读条要求所有在线玩家同时在范围内且没有人倒地，任意一名玩家离开半径或倒地，读条立即清零重新计时；敌人未清完、信标未扫完或资源未投送齐时读条同样保持清零。

离开热源后体温持续下降，降到 0 之后氧气消耗从每秒 1.0 加快到每秒 4.0；停留在热源半径内会回温并补充氧气。氧气归零会倒地，所以长距离搬运需要规划回安全屋补状态的时机。

## 灰盒布局

| 位置 | 坐标 | 作用 |
| --- | --- | --- |
| 出生点 | (145,275)、(235,275)、(325,275)、(415,275) | 进入关卡时玩家按编号落点 |
| 资源区 A | 矩形 (72,162)–(332,352) | 4 个资源箱位于 (105,240)、(145,300)、(245,220)、(275,300)；信标 1 位于 (185,255) |
| 安全屋 / 热源 | 圆心 (490,500)，半径 42 脉冲 | 恒温区，进入后回温；信标 2 位于 (500,520) |
| 危险区 | 矩形 (690,175)–(880,405) | 4 只敌人与信标 3；信标 3 位于 (790,285) |
| 投送 / 撤离点 | 圆心 (845,575)，半径 58 | 资源在此上交，也需要全员在此驻留 3.0 秒 |

三个信标分别落在资源区、安全屋和危险区，其中信标 3 就在敌人活动的危险区内，所以“清完敌人才扫得动信标 3”是设计上的依赖关系，不是巧合：危险区同时承担战斗压力和最后一个目标点。热源在安全屋、资源区又离热源最远，因此搬运路线天然需要往返补给。

当前灰盒视觉包含网格地表、分区色块、路线连接、资源箱、热源脉冲、危险区警戒条、岩柱和撤离点动画，用于让试玩者看懂路线和目标位置。

## 建立的公共接口

示范星球建立的接口包括阶段切换、主机权威交互、可靠状态同步、新玩家状态补发和关卡完成进度。后续星球应复用这些接口，不在各自关卡中重新实现联机状态。

- `change_stage(stage)`：主机切换 `ship` / `demo` / `electromagnetic`，切换时重置关卡进度并重新分配出生点、满血满氧满温。
- `request_interaction(kind, id)`：客户端上报交互请求，主机用 `handle_interaction` 按 kind 分发并校验距离后广播结果。kind 取值为信标 1、电力节点 2、资源箱 3、投送点 4、救援 5。
- `request_attack()`：客户端上报攻击，主机判定最近敌人并结算伤害。
- `sync_shared_state(stage, ids, enemy_ids, crates, deposited)`：新玩家加入时补发当前阶段、已完成节点、存活敌人、已取走的资源和已投送数量。
- `sync_vitals(snapshot)`：主机以 10 Hz 广播全队氧气、体温、携带、倒地与生命值。
- `complete_demo_mission()`：关卡通关广播，供资源与结算系统接入。
- `fail_mission()`：全队倒地时触发，返回飞船准备区。

## 已知问题

- **陷阱或解谜仍是空的**：危险区只有警戒条和岩柱装饰，没有专属机制，留给星球负责人接入。
- **数值均为占位值**：氧气消耗 1.0 / 4.0 每秒、失温 0.05 每秒、回温 0.4 每秒、携带移速 0.72 倍、救援 3 秒、救起氧气 40，都还没有经过四人试玩验证，需要按实际节奏调整。
- **未在真实联机下验证**：本卡的联机行为只做过单进程无头测试，没有在四台电脑或四个实例上跑过，主机权威判定与补发逻辑仍需实测。
- **验证范围**：已在 Godot 4.7.2 下用无头集成测试跑通全流程，共 38 项检查全部通过，覆盖阶段切换、清敌门槛、信标扫描、资源拾取与投送、撤离条件、热源失温与氧气、倒地与救援、全员倒地失败，以及中途加入补发敌人。未验证真实多实例联机、界面按钮点击和画面表现。
