# planet-00 霜烬星

`demo` 是霜烬星在代码和联机同步中的阶段 ID；显示名称统一使用“霜烬星”。本关卡是公共灰盒原型，用来验证四人合作生存关卡的共用接口。

| 项目 | 当前设计 |
| --- | --- |
| 星球编号与名称 | planet-00：霜烬星 |
| 状态 | 可试玩；已接入大地图探索、探索日志、地图标点、线索小游戏、知识解锁、气象信标、热能电池、异常冰样、热源生存、倒地救援、暴风雪、信号频段、条件式敌人、撤离与返航 |
| 一句话特色 | 在一整块 384×256 的冰原中追踪天气、热脉、生物和地下回声，逐步理解信标真正的作用，再决定如何让星球恢复安静 |
| 环境规则 | 热源半径 6.5：安全屋、6 个地热口、已修复信标，以及打开阀门后的热脉裂谷。离开热源后失温，体温越低氧气消耗越快；长途必须沿热源续命。氧气耗尽或生命归零会倒地；冰岩、冰脊、冰裂缝和坠落残骸会阻挡移动 |
| 调查与目标 | 3 个气象信标只是推进环境调查的节点；必须调查旧气象站、冰层裂谷和废弃通信阵列，再在中央中继站稳定或关闭地下异常，电池与异常冰样只属于可选回收 |
| 敌人节奏 | 第一座信标亮起后，热量会唤醒初次接触；第二座信标、暴风雪和异常冰样分别加深威胁。低频信号可以把敌人引向信号源，高频信号会揭示附近回波但提前唤来暴风雪，调查带来的是可操作的环境优势 |

## 当前可试玩流程

1. 在飞船准备区打开星际航线图，选择霜烬星并登陆；出生位置和地图布局由主机随机生成，再同步给所有玩家。
2. 按 `WASD` / 方向键移动。地图保持全亮，从安全屋出发会经过中央冰盆；四个主题区域各有远景地标、绕行路线和隐藏角落，探索压力来自距离、氧气、体温、障碍和路线选择。
3. 先观察地标、地面颜色变化和异常构筑物；它们是可见的环境信号，不会凭空弹出结论。按 `Q` 发出扫描脉冲，只有被脉冲捕捉到的拖痕、热融痕迹或地标回声，才会在地面显出可调查标记。
4. 脉冲持续 4 秒，固定起点并向外扩散；正常范围 11.0，暴风雪中为 7.5，冷却 6 秒。扫描只指出一条可追踪的信号，不直接给出最短路线。
5. 靠近已显形的调查标记或真实地标时，角色才会产生心理判断；发现过的事实会进入 `Tab` 探索日志。打开日志的地图页后，可用 `H` 标记附近热源、`C` 标记附近已探索线索、`V` 清除最近标记，也可以点击地图页按钮完成同样操作。
6. 第一座信标可以直接按 `E` 启动；启动后会揭示旧气象站的方向。靠近远景地标按 `E` 调查，地标进入视野只登记位置，不会自动解码知识。
7. 调查旧气象站后才能校准第二座信标；调查冰层裂谷后按 `E` 观察热脉，在回落期打开阀门，裂谷才会成为稳定热源；调查废弃通信阵列后才能校准第三座信标。每次调查都会先进入一段关联小游戏：气象站是频率顺序、裂谷是热脉时机、运输舱和通信阵列是不同的按键序列；失败会原地重置，按 `R` 可主动重试，不会消耗资源。
8. 靠近已启动的信标或通信阵列时，按 `1` 发送高频信号，会揭示信号源附近最多两条回波，但立刻拉来暴风雪和敌袭；按 `2` 发送低频信号，会把附近敌人吸向信号源，给队伍留下穿越窗口。两种频段共享 10 秒冷却，频段是环境工具，不是固定任务按钮。
9. 三座信标全部亮起后，回到废弃通信阵列，在中继站按 `E` 稳定地下共振，或按 `G` 关闭信标网络。两种选择都会改变日志和结局文本。
9. 电池和异常冰样仍可按 `F` 拾取、按 `G` 投送到撤离平台，用于额外回收价值；它们不再是完成任务的必要条件。携带物品仍会降低移动速度，样本仍会提高风险。
10. 处理地下异常且当前敌人全部清除后，撤离点开放。全员进入范围并保持 3 秒，任务完成并返回飞船；全员倒地或合同超时则任务失败并返航。

## 随机布局

每次登陆由主机随机生成安全屋、危险区、中央冰盆周围的 4 个热能电池和敌人出生点；四个主题地标保持可读的远景位置，设备和物资在各区域之间变化。安全屋始终位于西南侧，撤离点位于东南侧；布局通过 `sync_demo_layout` 补发给中途加入的玩家，客户端不自行生成布局。

| 位置 | 当前规则 |
| --- | --- |
| 出生点 | 4 个出生点槽位，按玩家编号分配 |
| 地图 | 384×256 世界边界内的冰原；12 道冰崖墙切出中央冰湖、六个主题区域和六条通路，安全屋位于西南，撤离点位于东南，障碍和目标位置每局由主机随机抽取 |
| 探索区域 | 西北·静默台地（旧气象站）、东北·热脉裂谷（冰层裂谷）、东南·残骸湾（坠毁运输舱）、西南·回声峡谷（废弃通信阵列）、中央·冰湖、西南·坠落点 |
| 热能电池 | 4 个随机位置；可选回收物，一次携带一枚，携带时移动速度降低 |
| 异常冰样 | 2 个随机位置；可选高价值回收物，携带时更慢并会提前唤醒敌袭 |
| 环境障碍 | 12 组同步冰岩、冰脊、冰裂缝和坠落残骸，具有玩家碰撞和纵深立面 |
| 投送 / 撤离点 | 世界坐标 `(172,74)`；同时承担上交和最终撤离 |

## 建立的公共接口

- `change_stage(stage)`：主机切换 `ship` / `demo` / `electromagnetic`；切换时重置关卡并恢复玩家生命、氧气与体温。
- `request_interaction(kind, id)`：客户端上报交互请求，主机验证距离、倒地状态和目标状态。
- `request_attack()`：客户端上报攻击，主机判定距离并结算伤害。
- `_world_snapshot()` / `sync_full_state(snapshot)`：同步本局随机布局、敌人、任务、日志和发现区域。
- `_sync_state(...)`：同步存活敌人、任务状态、玩家生存数值和探索日志。
- `request_scan()` / `sync_scan_state(...)`：主机验证扫描冷却并同步固定起点、移动锁定、最大范围；中途加入补发剩余锁定时间。
- `sync_storm_state(active, remaining)`：同步暴风雪开始与结束，确保所有客户端使用相同扫描范围。
- `sync_shared_state(...)` / `sync_session_snapshot(...)`：中途加入时补发阶段、目标、玩家、敌人和资源状态。
- `sync_vitals(snapshot)`：主机广播全队生命、氧气、体温、携带和倒地状态。
- `sync_exploration_state(story_flags, anomaly_resolved, ending_choice, rift_valve_open, signal_mode, lure_until, lure_position, cooldown_until, map_markers)`：同步调查进度、地下异常处理状态、最终选择、热脉阀、信号诱导状态和地图标点。
- `return_to_ship(reason)`：广播任务完成或失败并进入返航过渡。

## 待验证与后续方向

- 暴风雪持续时间、扫描范围、信号诱导窗口、敌人触发条件和热脉回落窗口仍需单人、双人、四人试玩后调平衡。
- 当前雪粒子、地表和音效仍为程序化灰盒表现，后续可补充风雪音效、冰面减速和冰裂缝地形。
- 需要在真实多实例局域网环境验证天气、随机布局和中途加入补发。
- 霜烬星是否计入最终四星路线、其他星球名称与玩法仍按团队设计文档确认。
