# planet-00 霜烬星

`demo` 是霜烬星在代码和联机同步中的阶段 ID；显示名称统一使用“霜烬星”。本关卡是公共灰盒原型，用来验证四人合作生存关卡的共用接口。

| 项目 | 当前设计 |
| --- | --- |
| 星球编号与名称 | planet-00：霜烬星 |
| 状态 | 可试玩；已接入登陆、战斗、气象信标、热能电池、热源生存、倒地救援、暴风雪、撤离与返航 |
| 一句话特色 | 在 0.8 摄像机缩放、带高度侧面的 2.5D 冰原、局部视野和周期性暴风雪中修复气象信标、投送热能电池，并守住撤离点等待救援航线建立 |
| 环境规则 | 热源半径 42 内回温并补充氧气；离开后持续失温，体温越低氧气消耗越快。氧气耗尽或生命归零会倒地；冰岩、冰脊、冰裂缝和坠落残骸会阻挡移动 |
| 资源与目标 | 3 个气象信标、4 枚热能电池；热能电池一次携带一枚，移速降至 0.72 倍，在投送撤离点上交 |
| 敌人节奏 | 登陆时生成第一波，之后主机每隔 15 秒生成一波，没有总波数上限。三个信标修复、4 枚电池投送后停止新增敌人，清除剩余敌人后开放撤离 |
| 暴风雪 | 霜烬星进入后保持局部视野；周期性暴风雪持续 10 秒，地图能见度和气象信标扫描范围下降；扫描脉冲以环形波面逐渐向外扩散，并短暂扩大可见范围 |
| 多人合作方式 | 交互、攻击、敌人生成、环境数值和撤离判定均由主机验证；布局、波次、天气、玩家快照和任务状态通过 RPC 同步 |
| 单人完成方式 | 主机可以独自修复信标、投送 4 枚热能电池、清除剩余敌人并完成撤离 |

## 当前可试玩流程

1. 在飞船准备区打开星际航线图，选择霜烬星并登陆；出生位置和地图布局由主机随机生成，再同步给所有玩家。
2. 按 `WASD` / 方向键移动。地图默认只显示玩家附近区域，摄像机缩放为 0.8，热源和已经修复的气象信标会保留微弱导航光。
3. 靠近气象信标按 `E` 修复；按 `Q` 发出扫描脉冲，与修复操作独立。脉冲持续 4 秒，固定起点并慢慢向外扩散；最大半径为 520 世界单位，暴风雪中约为 374。脉冲结束前禁止移动，随后恢复；扫描冷却为 6 秒。
4. 按住空格攻击敌人。敌人每 15 秒定时增援，拾取与修复都不会触发波次。
5. 靠近热能电池按 `F` 拾取，一次只能携带一枚；到投送撤离点按 `G` 上交，直到 4 枚全部投送。
6. 离开热源后体温下降；回到安全屋热源范围可以回温并补氧。队友倒地后靠近按 `R`，持续 3 秒完成救援。
7. 三个气象信标完成、4 枚热能电池投送、剩余敌人全部清除后，撤离点开放。全员进入范围并保持 3 秒，任务完成并返回飞船；全员倒地则任务失败并返航。

## 随机布局

每次登陆由主机随机生成安全屋、危险区、热源、4 个热能电池和敌人出生点。安全屋始终位于危险区左侧；布局通过 `sync_demo_layout` 补发给中途加入的玩家，客户端不自行生成布局。

| 位置 | 当前规则 |
| --- | --- |
| 出生点 | 4 个出生点槽位，按玩家编号分配 |
| 安全屋 / 热源 | 随机矩形，热源位于中心，半径 42 |
| 危险区 | 随机矩形，位于安全屋右侧；敌人和第三个气象信标集中在此 |
| 热能电池 | 4 个随机位置，避开安全屋、危险区、环境障碍和撤离点，彼此保持最小距离 |
| 环境障碍 | 11 个随机同步的冰岩、冰脊、冰裂缝和坠落残骸；采用清晰的俯视 2.5D 立体块风格，障碍按纵深排序，具有亮色顶面、深色立面、投影阴影和玩家碰撞 |
| 投送 / 撤离点 | 圆心 `(1290,760)`，半径 58；同时承担上交和最终撤离 |

## 建立的公共接口

- `change_stage(stage)`：主机切换 `ship` / `demo` / `electromagnetic`；切换时重置关卡并恢复玩家生命、氧气与体温。
- `request_interaction(kind, id)`：客户端上报交互请求，主机验证距离、倒地状态和目标状态。
- `request_attack()`：客户端上报攻击，主机判定距离并结算伤害。
- `sync_demo_layout(payload)`：同步本局随机布局和敌人出生点。
- `sync_enemy_wave(enemy_state, wave, wave_timer)`：同步存活敌人、当前波次和增援计时。
- `request_scan()` / `sync_scan_state(...)`：主机验证扫描冷却并同步固定起点、移动锁定、最大范围；中途加入补发剩余锁定时间。
- `sync_storm_state(active, remaining)`：同步暴风雪开始与结束，确保所有客户端使用相同扫描范围。
- `sync_shared_state(...)` / `sync_session_snapshot(...)`：中途加入时补发阶段、目标、玩家、敌人和资源状态。
- `sync_vitals(snapshot)`：主机广播全队生命、氧气、体温、携带和倒地状态。
- `complete_demo_mission()` / `fail_mission()`：广播通关或失败并进入返航过渡。

## 待验证与后续方向

- 暴风雪持续时间、扫描范围和局部视野半径仍需单人、双人、四人试玩后调平衡。
- 当前雪粒子、地表和音效仍为程序化灰盒表现，后续可补充风雪音效、冰面减速和冰裂缝地形。
- 需要在真实多实例局域网环境验证天气、随机布局和中途加入补发。
- 霜烬星是否计入最终四星路线、其他星球名称与玩法仍按团队设计文档确认。
