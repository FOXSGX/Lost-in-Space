# 霜烬星 · 科考站建筑设计

日期：2026-10-28。依据：本聊天七轮建筑采访及用户追加纠正。范围：独立新版科考站的设计，不代表正式旧信标关卡已经替换。

**状态说明：**“已确认方向”来自用户有效回答；“建议落位/待验证”是助手将回答转为空间的设计方案，不作为用户已逐项确认的决定。本文不宣称已实现或试玩通过。

## 1. 已确认的总体方向

- 六类建筑：主科研楼、标本保存与隔离馆、生活医疗楼、动力与生命保障站、机修车库、物资仓库。
- 一主、两辅、三配套，围绕中央作业院；用户同意收紧院落、强化停机坪识别主楼以及主楼望见骨口的视线。规划02的40×35米院落和建筑高度仍是具体尺寸候选。
- 氛围：曾是专业且有人生活的科考基地，如今匆忙撤离，留下使用与搬运痕迹。宿舍不以认识原科考队员为目标，不补定队员身份、人数、事故操作者或动机。
- 主楼的主要吸引力是发现有趣科考道具并自由把玩。小型道具可带进遗迹，大型仪器留在研究室；可以影响队友的位移或短暂状态，以合作和捣乱为乐。
- 不新增场景悬浮文字。入口标识、设备说明、生物介绍使用墙面/实体表面的图片、标牌和少量文字，必要交互使用简洁HUD。
- 已有主线结构保持：主楼发现保险柜与钥匙线索→遗迹取钥匙→返站开柜→回船安装能源并恢复航行。配楼可选探索与主楼道具把玩不增加主线门槛。

## 2. 主科研楼

### 已确认方向

中央大厅容易辨认，与一个较大的综合实验室通过宽开口直接相连，像连续工作区。配档案室、设备间和办公区，少分专门实验室。大厅侧面有明显楼梯，上到局部二层环廊，可以回望楼下。二楼首席办公室放能源保险柜和钥匙去向线索。北侧上层观察位置望向骨口。

第一件标志道具为**手持吸推器**：吸住小物件搬动、推出物件，也可推着队友玩。没有独立试用区；玩家看见货箱、家具、门或队友就可尝试。这里不等于所有门、家具和建筑构件都可任意拆毁。

### 建议落位：一楼

| 区域 | 具体内容 | 玩家行为与连接 |
| --- | --- | --- |
| 南侧入口与中央大厅 | 接待台、墙面站区图、未搬走的箱包、低矮推车；楼梯清楚可见 | 一进门能辨认上楼方向和实验室开口；推车与箱子可供自然尝试 |
| 东侧综合实验室 | 工作台、可拿取吸推器、轻物件、样本容器、固定大型仪器 | 建议吸推器放在靠近大厅的工作台，进入时即可注意；可直接对周围物件尝试并带走，无教学考核 |
| 西侧档案室 | 文件柜、现场照片、少量研究图表 | 可浏览背景知识；不设置必读数量，不收齐日志开门 |
| 西北设备间 | 器材架、检修桌、备件与可搜集物品 | 补充实物发现；大型器材固定，小件可携带。具体道具清单尚待定 |
| 西侧楼梯 | 明显普通楼梯、可回望大厅的转折平台 | 步行上楼，兼顾携物和四人错身；不依赖吸推器、喷气或供电才能登楼 |

### 建议落位：二楼

- 局部环廊围绕大厅挑空，能看见队友与楼下物件；护栏与开口应验证物件和人物的碰撞。
- 北侧首席办公室：能源保险柜与钥匙线索是主要现场。候选线索为墙面出勤/勘探路线图与实物钥匙保管说明，内容仅指向遗迹，不先确认更多事故真相。
- 北侧观察廊/大窗：面向骨口，帮助理解离开主楼后的方向；是可选观察位置，不要求玩家必须来这里才能出发。
- 其余办公区可结合环廊设置小工作位，避免再增加一整套多房间迷宫。

### 首次与回访动线

建议：进大厅→看到实验室与侧梯→可选取吸推器把玩→上楼找到保险柜与钥匙线索→从观察位置辨认骨口→下楼出发。取钥匙后走熟悉的大厅、侧梯、首席办公室开柜，再返船。自由探索顺序允许不同，不锁死“先拿道具再上楼”。

## 3. 标本保存与隔离馆

**已确认方向：**未拼装完成的巨大骨架为视觉主体，周围有骨段、吊装夹具、工作平台；标本看看即可，不用玩，可以加一点生物介绍。

**建议落位：**入口缓冲区→挑高骨架主厅→侧边生物介绍墙→后部保存区。后部保存区作为原有“保存与隔离”功能的布景与可见工作空间，不推定要加入活体操作系统。

主厅留能环绕骨架观察的路径，散落骨段和夹具解释拼装过程。生物介绍用少量图文，例如“已观察到的结构特征”“与遗迹骨架的对应部分”“尚不确定的推测”；新生物事实需要另行设定，不用标签硬写成已确认世界观。

**本楼不设置：**骨架拼装任务、吊装小游戏、吸推器搬标本要求、必做加热实验。普通装饰物可否受力另定，不能破坏静态观看主体。

## 4. 生活医疗楼

**已确认方向：**重点逛宿舍、搜集有意思的生活物资；食物现场能吃，部分物品可以收藏；取消游戏机。不以认识原科考队员或收集人物档案为任务。

**建议落位：**入口公共间连接宿舍区、食堂/茶水间、医务与更衣附间，形成短回路，玩家能从公共间反复辨认方向。

| 区域 | 建议物件 | 行为 |
| --- | --- | --- |
| 宿舍 | 床铺、储物柜、床头零食、可拿起的生活小物 | 找薯片等可食用物，发现部分可收藏物；用物件产生发现乐趣 |
| 食堂/茶水间 | 餐桌、储物橱、未收好的餐具和食品 | 补充可食用物、搬动小物；不开展做饭系统 |
| 医务/更衣附间 | 护理柜、清洁设备、衣物与防护用具架 | 维持建筑功能和少量搜集；具体可用物资不补定 |

薯片为用户明确举例；其他食物及收藏物清单仍属候选。食物回血/增益、收藏回船后的展示与保存、是否占既有手持格等参数未定。食用沿用已有拿取/使用习惯优先，不擅自引入饥饿值或复杂料理。

## 5. 机修车库

**已确认方向：**有一辆可实际驾驶的小运输车，能搬物件、载队友，能开入遗迹，尽量带车探索，遇真实地形阻挡再下车。

**建议落位：**面向外场的大车门→车位与装卸区→侧边维修间→工具/零件库→后部设备间。除了停放车辆，还要留有可步行探索、可搜集的功能空间。车门外连接站区通路和骨口方向，转弯位置应先按车体实测。

建议让运输车初次发现后可直接试开，不新增默认的“找多件零件修好才能开”任务。车辆是否需要启动步骤、燃料、损伤、固定座位和装货绑定仍未确认。

车辆进遗迹的边界按实际净宽、坡度、转弯、顶高和底盘通过能力建立；不能只按“已进入洞厅”禁用驾驶，也不能把主线钥匙锁在车才能运走的货物里。阻挡处留可停车、上下车与掉头的空间；步行主线保持可完成。

## 6. 动力与生命保障站

**已确认方向：**内部是较完整、多房间、可搜集的探索区域；可恢复部分站区照明和供暖，并开启更方便的慢充补氧点，外面也能看出变化。

**建议落位：**入口值守/控制室→机组大厅→侧边检修间及备件库→供暖/制氧设备间→回到控制室，或经检修回路返回入口。管线在建筑内外具有可追踪关系。

建议操作结构为一次可理解的局部恢复：观察控制台和实际设备→完成可达的复位操作→看到机组启动、站区部分灯和暖光出现→本地维护台可用。具体操作步骤尚未确认，不添加多楼串联解锁任务。

恢复效果应能从现场和出门后读出来：机组声/转动、管线暖色、院边灯、补给设备状态。供暖是否改变生存数值和影响范围待定。**动力站未恢复时仍有飞船等基础慢充补氧兜底**，避免探索耗尽热风机和氧气后永久卡住；不恢复动力也能完成取钥匙返航。

## 7. 物资仓库

**已确认方向：**完整的多房间探索与搜集；部分库房被冰雪封住，先逛开放区域，再用热风机融开局部入口找物资。

**建议落位：**装卸厅连接开放工具库、开放生活物资库，以及两处有不同外观的局部冰封库房。建议分类与数量供平面推敲，不作为已确认奖励配置。

- 开放库房让玩家先拿到少量有用物资，并从货架与搬运痕迹辨认分区。
- 冰封入口能看出“后面还有库房”，表层融冰打开真实通口；既有热风机即可处理，不增加另一把钥匙。
- 冰层融开后进度保留，物资不因离开重进而复制；建议沿用0.3已有规则。
- 装卸厅连接车辆装货位置，室内库房不要求开车挤入；吸推器可与可作用货物自然结合，不作为开库房的唯一解。
- 不预设冰封库房一定提供稀有装备或任务物件。具体奖励、刷新与收藏规则未定。

## 8. 对旧规划与原型的影响

| 旧内容 | 本轮有效方向 |
| --- | --- |
| 规划01/02一楼能源保管室放柜 | 改为二楼首席办公室；一楼该房用途重新归并 |
| 多个封闭实验室 | 合并为与大厅宽开口相连的大综合实验室 |
| 宿舍以队员身份和私人故事为核心 | 改为有趣生活物资，现场食用与部分收藏；游戏机取消 |
| 标本馆以实验或物理玩具为重点的候选 | 改为静态观看骨架与少量生物介绍 |
| 配套楼内部可简化的早期候选 | 动力站和仓库改为完整、多房间探索 |
| 车辆仅停放/限站区/停遗迹外的候选 | 可驾驶、运货载队友，允许进入实际可通过的遗迹地形 |

现有0.3原型尚无上述整套新站区、吸推器与运输车。建筑图是功能草案，普通门洞、上下层、车辆转弯与联机同步须另外实测；不直接用图面生成碰撞。

## 9. 下一步最小验证与未定项

**建议验证顺序：**

1. 主楼大厅/实验室/侧梯/环廊/二楼柜位的灰盒步行，检查首次找到线索、回访辨认与塔/骨口视线。
2. 吸推器作用小物件与队友的最小原型，验证自然把玩、不中断现有物品栏；范围、质量、推力、供能仍待调。
3. 车体和货物的最小原型先跑站区与一段遗迹，验证能开、能下车、能取货、能倒回，之后再定道路与门洞尺寸。
4. 动力恢复、仓库融冰和可吃物资的最短完整循环；使用既有测试和输入方式补受影响验证。
5. 双真实进程检查车辆、物件、动力与融冰状态由主机结算；中途加入和掉线不复制资源。真人测试后再定内容密度与耗时。

尚未确定：食物效果、收藏机制、吸推器参数、车辆参数/装载与恢复、动力恢复步骤、房间数量与尺寸、每类物资数量、阅读量及探索时长。不在采访结束时推定已确认。

用户明确要求按方案实现后，本轮已接入 `game/previews/frost_station/`，正式主舱新航程的出舱入口也已切换至本模块。旧0.3保留。
