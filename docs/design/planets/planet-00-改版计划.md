## 一、目标

当前霜烬星的问题：地图是一整块平面，散放小障碍，没有围合空间；地图上有导航线和剧透式标签；探索只产生日志文字，不影响玩法；目标就是“修 3 个信标、交 4 枚电池”这张清单。

改版目标：让玩家**看到想去的地方 → 去了有收获 → 回来时要做取舍**。

## 三、地图改版（已确认）

按草图把开放平原改为由区域和通路组成的手工地图。

**尺度（2026-10-12 修订）**：初版按 96×64 实现后实测偏小 —— 玩家 20 秒即可走完全图，摄像机（size 19）一眼能看穿五分之一的宽度，探索欲望无从产生。现改为 **384×256**（面积 13.75 倍，横穿约 66 秒），摄像机收到 size 28，视野占全图比例由 20% 降至 6%。区域、冰崖、通路、目标角落的坐标全部在 `game/scripts/frost_map_layout.gd`，`main_3d.gd` 只读取不重复定义。

### 3.1 区域

| 区域 | 位置 | 空间形状 | 内容 |
| --- | --- | --- | --- |
| 坠落点 / 安全屋 | 西南 | 圆形空地 | 出生点、热源 |
| 回声峡谷 | 西侧 | 向北弯曲的窄谷 | 废弃通信阵列、可破冰墙后的隐藏补给 |
| 静默台地 | 西北 | 层层抬高的高台 | 旧气象站、高处观景点 |
| 中央冰湖 | 中央 | 开阔冰面，带薄冰裂纹 | 信标、异常样本 |
| 热脉裂谷 | 东北 | 热泉地表，中间一道深裂缝 | 冰层裂谷地标、两个敌人巢穴、信标 |
| 残骸湾 | 东南 | 运输舱残骸围成的迷宫 | 可进入的坠毁运输舱、电池 |
| 撤离点 | 东南角 | 小空地 | 投送和最终撤离 |

### 3.1.1 地热口（2026-10-12 新增）

地图放大后，从安全屋直走到撤离点要 58 秒，中途没有取暖点会导致「出发即冻死」。因此新增 6 个地热口，兼作取暖点与地标，把长距离移动切成若干段：

| 名称 | 位置 | 所属区域 |
| --- | --- | --- |
| 回声温泉 | (-96, 44) | 回声峡谷 |
| 台地裂隙 | (-120, -56) | 静默台地 |
| 湖心泉眼 | (-14, 6) | 中央冰湖 |
| 北岸地热 | (44, -60) | 中央冰湖 |
| 裂谷热井 | (128, -70) | 热脉裂谷 |
| 残骸熔口 | (112, 62) | 残骸湾 |

生存数值随之重算（旧值按 96×64 设计，已不适用）：热源半径 4.5 → 6.5；体温消耗 0.018/秒（55 秒）→ 0.007/秒（143 秒）；氧气基础消耗 0.25/秒 → 0.12/秒。目标是「单程够用、全程往返必须靠地热口续命」，让路线规划成为主要压力来源。

### 3.2 通路与路线变化

- 区域之间只能通过窄道、主路、冰脊坡、冰檐小径、薄冰桥相连，其余位置都是不可通行的冰崖。
- **薄冰桥**：中央通往热脉裂谷的近路，暴风雪时封闭。
- **单向滑坡**：残骸湾滑向撤离点，下去后不能原路返回。
- **捷径门**：南侧外环，从撤离点一侧打开，打开后回安全屋的路程大幅缩短。
- **可破冰墙**：回声峡谷侧，后面是隐藏补给。
- **隔崖可见**：东侧有一枚电池能隔着冰崖看见，要绕路才能拿到。

### 3.3 视觉规则

- 去掉地面的 4 条导航长条。
- 去掉剧透式标签，例如“【危险区/暴风雪前线】”“【中央冰盆】四条路线的交汇处”。名称在玩家走近或扫描后才显示。
- 四个地标改用不同轮廓区分：倒塌天线塔、冒蒸汽的裂口、斜插的运输舱、成排的阵列，不再统一用“平台 + 发光柱”。
- **探索迷雾**（已确认）：未去过的区域整体压暗、去掉细节，但地形轮廓和地标发光仍然可见。
- **高处观景点**：站上静默台地观景点时，相机临时拉远，玩家可以看清全图结构。

### 3.4 目标摆放

目标不再从散点候选坐标里随机抽，而是在每个区域预设的“藏东西的角落”之间随机，保证每个目标都位于有意义的地点。数量不变：3 个信标、4 枚电池，另加 2 个隐藏补给。

## 五、技术实现

| 项目 | 做法 |
| --- | --- |
| 地图数据 | 新建 `game/scripts/frost_map_layout.gd`，只存放区域、冰崖墙、通路、兴趣点和目标角落等数据 |
| 地图构建 | `main_3d.gd` 中的 `_build_ground()`、`_build_zone_visuals()`、`_build_obstacles()`、`_build_landmarks()` 改为读取布局数据，去掉 `OBSTACLE_LAYOUT`、`ZONE_DATA`、`*_CANDIDATES` 等硬编码常量 |
| 探索逻辑 | P1–P4 放进新的 `game/scripts/frost_exploration.gd`，`main_3d.gd`（现有 2338 行）只负责调用和联机同步 |
| 高度表现 | `space_player_3d.gd` 每帧把 `velocity.y` 设为 0，没有重力和上坡逻辑，因此台地先用“围墙 + 视觉高差 + 坡道入口”模拟，不做真实高度 |
| 迷雾 | 按区域记录“已探索”状态，未探索区域叠加压暗材料；状态由主机权威维护，并同步给客户端 |
| 灰盒优先 | 先用方块和坡面搭出空间，验证好不好逛之后再补美术 |
