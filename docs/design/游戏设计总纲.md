# 迷失太空（Lost in Space）· 游戏设计总纲

状态：依据第一次会议及后续团队决定维护；未确认细节明确标为待定。

## 已确认的方向

- 游戏名称：《迷失太空》（Lost in Space）。
- 定位：多人联机合作类派对游戏，支持单人尝试通关。
- 基础玩法：生存射击闯关，探索、搜集物资、躲避或对抗异星生物。
- 主线：飞船星际迷航，在不同星球搜集燃料与物资，最终返回地球。
- 关卡路线：参考地铁线路图设计分支，包含必玩星球和隐藏支线。
- 联机复活：队友前往死亡位置救援。
- 单人复活：搜刮绷带、复活药等物资获得自我复活机会。
- 角色：计划具有不同技能或特点。
- 关卡可包含陷阱或解谜任务。

## 团队倾向

- 优先 2D，参考《元气骑士》等游戏的表现形式；视角与引擎待定。
- 美术偏写实，利用 AI 辅助制作；具体美术负责人待记录。

## 当前需要决定

1. 比赛要求、可用时间、人员技能和分工。
2. 引擎、目标平台、视角、联机方式及人数。
3. 多人合作的核心操作，以及单人完成同一目标的方式。
4. 第一个星球的规则和首版制作范围。
5. 救援、复活和失败的具体代价。

## 当前开发重点（2026-10-12）

用户要求先完善太空舱，并选择优先补齐储物、维修、补给等舱内玩法。本轮原型已接入共享库存、维修消耗、补给恢复、物资制作、全员准备及星球往返；具体数值是原型实现，仍待试玩调整，不补推其他成员分工或团队最终决策。

运行与实现说明：[太空舱玩法](../../game/docs/ship-hub-3d.md)。

用户随后要求舱室更大、超出单屏。本轮主舱扩大到约 42×33 米，采用角色跟随镜头；设备保持人物尺度，功能区分散布置。

## 用户美术偏好更新（2026-10-12）

用户认为现有表现过于简陋，明确不偏好像素风，并选择“精致卡通：清晰轮廓、圆润设备、统一色彩”。太空舱先按这一方向迭代；原有团队写实倾向保留为会议记录依据，不推定为本轮最终美术决策。具体实现见太空舱说明。
