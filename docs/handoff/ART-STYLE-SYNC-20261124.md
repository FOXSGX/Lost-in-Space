# 共振星美术风格学习与腐墟星应用记录

- 日期：2026-11-24
- 来源：[共振星美术制作与 AI 协作指南](../resonance/美术制作与AI协作指南.md)
- 参考：`game/act1/`、`game/act23/`、ART-SAMPLE-002、Act1 五层布光与 ArtPbrLib

## 学到的硬约束

1. **风格**：精致卡通，清晰轮廓、圆润设备、统一色彩；禁止像素风，禁止悬浮 3D 文字。
2. **色彩比例**：约 70% 中性骨架、10–15% 高明度奶油/浅灰分块、5–10% 青绿功能色、
   ≤8% 工业橙/琥珀可操作件、<2% 警示红。
3. **结构**：倒角、装配缝、真实厚度、落地/锚固支撑；禁止裸 `BoxMesh` 当成品。
4. **兼容性**：Godot 4.7 `gl_compatibility`；不依赖 SSR/SSIL/体积雾；
   自发光要保留色相梯度，不能过曝成纯白。
5. **五层布光**：1 盏带阴影主光 + 无阴影补光 + 冷色轮廓光 + 墙面/地面掠射光 +
   绑在可见灯具/能源体上的实用光。
6. **空间可信度**：贴地接触阴影、碎石围边、悬垂软管、微尘/蒸汽；
   晶体必须从岩层/裂缝中长出来。
7. **交互可读性**：不靠空中文字，用管线状态、实体表盘、贴壁铭牌和 HUD 提示。

## 应用到腐墟星的部分

- **没有照搬共振星的红棕洞穴 + 青紫矿柱配色**；指南本身要求新星球保持自身题材。
- 学校/超市室内保留腐墟星原有的奶油、青蓝、暖橙、鼠尾草绿；
  新增 **每层一盏带阴影的暖色主光**，原有吸顶灯降为无阴影补光，
  接近五层布光的“主光/补光”关系。
- 保留腐墟星既有的倒角方块语言、贴墙提示和 HUD 交互提示；
  没有引入悬浮 `Label3D`。
- 能源站已使用 ART-SAMPLE-002 的金属/岩石/晶体资产与 LIS Physics 物理门，
  与指南的“真实支撑和装配关系”一致。
- 后续可继续补：接地渐变尘圈、悬垂软管、环境微尘/蒸汽和贴壁图示铭牌；
  这些只做视觉层，不改碰撞和玩法节点。

## 不改变的内容

- 腐墟星医院、学校、超市、能源站、图书馆的布局、碰撞、任务物和门锁逻辑。
- 腐墟星整体低饱和傍晚/阴天基调，不改成共振星洞穴配色。
- 霜烬星与共振星原有场景不被腐墟星风格反向覆盖。
