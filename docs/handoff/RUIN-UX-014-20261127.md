# RUIN-UX-014-20261127 · 出门朝向、去丧尸/激光剑、统一医院式楼梯

## 1. 所有建筑出门后面向外侧

`main_3d.gd` 新增统一辅助：

- `_place_player_outside(player, exit_point, door_origin)`
- 从门到门外的水平方向计算 yaw，同时设置身体、镜头 yaw 与 pitch。
- 医院、学校、超市、能源站统一调用；庇护所按能源站暗门方向计算。

验证：
- 医院/学校/超市/能源站测试均检查身体与镜头朝外。
- 新增 `ruin_shelter_exit.gd`：庇护所离开暗门后身体/镜头都背向暗门。

## 4. 统一医院式楼梯

新增 `game/scripts/ruin_stair_template.gd`：

- 固定 `LANE_WIDTH=2.3`、`DIVIDER_WIDTH=0.12`、14 级实体踏步。
- 两条梯段槽位；偶数 interval 西槽，奇数 interval 东槽。
- 每级 `StairStepFill + StairTread`，楼梯下方不是空心。
- 中央分隔墙贯穿整层。
- 楼梯门框沿 Z 轴生成，修复学校/超市之前门框横放在 X 轴的问题。
- 每层只有一个入口，入口侧按层数交错。

各建筑：
- 医院：原楼梯改用模板。
- 学校：楼梯井扩到 `x[-12,-7]`，删除贯穿门洞的 Wainscot，地板/天花板改用 `STAIR_X0`。
- 超市：楼梯井扩到 `x[-14,-9]`，单条斜坡改为双槽模板。
- 能源站：楼梯井扩到 `x[-15,-10]`，删除旧 1.7 m 槽位封边，改用模板。
- 所有入口墙仍保持“入口侧可过、另一侧实墙”。

验证：
- `ruin_stair_parity` 56/0：四栋建筑、每层入口/封闭侧、梯段落脚面、中央分隔墙、踏步数量、Z 轴门框。
- `ruin_hospital_stair_traversal` 154/0。
- `ruin_interior_clipping` 1477/0。
