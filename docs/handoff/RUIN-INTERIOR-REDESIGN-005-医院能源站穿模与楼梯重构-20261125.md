# RUIN-INTERIOR-REDESIGN-005 · 医院/能源站穿模与楼梯重构

日期：2026-11-25
范围：腐墟星能源站 1F 入口/控制室、医院四层室内与楼梯、全图墙体/胶囊/楼梯审计、医院/能源站局部美术统一。
未改：任务物 ID、剧情节点、病房门锁规则、主游戏/Act23、敌人与物品数值、联机字段。

## 一、根因

### 能源站 1F 右转墙缝

`ruin_energy_station_interior.gd`：

- 南墙左右段长 13.7 m、中心 x=±8.35，内边缘 x=±1.5。
- 入口门洞宽 2.6 m，半宽 1.3 m；门框与墙之间留下约 **0.2 m 竖缝**，门框也没有封边碰撞。
- 控制室/冷却间的控制板、冷却罐、配电柜等只有视觉 mesh，没有碰撞，玩家可穿过去。

### 医院楼梯“被堵死”

`ruin_hospital_interior.gd`：

1. **楼梯门是假关闭门**：`_door_frame` 默认 `with_panel=true`，两个楼梯门各生成一整扇视觉门板。
2. **门框方向错误**：楼梯门位于 X 方向墙，但 `_door_frame` 按 Z 方向墙建门，门柱沿 X 偏到 ±0.9 m，**一根门柱直接横在门口**。
3. **坡道上下叠放**：所有层坡道都在 x=-9 同一条线上；上层坡道底面和下层坡道之间净高不足玩家高度，走上去会撞头，这是“根本上不了楼”的物理根因。
4. **1F 接待台/担架/轮椅在楼梯井内**：接待台 x=-7.8、z=4，轮椅/担架 x≈-10.2，实际落在楼梯井范围。
5. **楼梯门/平台被家具堵**：长椅在 1F 楼梯平台，各层 `_cabinet(-6.6,z7.2)` 和走廊担架/轮椅压缩通道。
6. **2F 检查床与 X 光床重叠**、护士台在中央走廊、主要家具缺碰撞。

## 二、修复

### 能源站

- 1F 南墙内边缘改为 x=±1.3，与门框重叠；左右补 0.30×3.0×0.44 m 门框封边碰撞。
- 控制板、冷却控制台、三只冷却罐、配电柜、储物柜补碰撞；控制室设备内收。
- 控制室补洗墙灯、发光墙板和更亮的控制区照明；墙/结构色板改为石墨蓝灰 + 奶油设备 + 青色能量 + 琥珀安全边。
- 能源站楼梯也改为两条独立梯段（西/东交替），中间封边，补楼梯灯，避免同样的上层坡道叠放问题。

### 医院

- **楼梯**：
  - 偶数层坡道走西侧 x≈-10.05，奇数层走东侧 x≈-7.95，宽 1.6 m；上下层坡道不再叠在同一 x。
  - 东墙楼梯门改为 1.8 m 开放门洞，只留门柱/门楣；新增 `_door_frame_z` 按 X 方向墙正确展开，不再有挡门柱。
  - 坡道两侧/中间补 0.3–0.5 m 封边楼板；平台/坡道补灯和实体层色牌。
- **1F**：接待台移到 x=-5.8，长椅/轮椅/担架移出楼梯井；大厅中轴清空。
- **2F**：检查室位置去掉与影像室 X 光床重叠的 (-3,-5) 担架；护士台移到东侧凹位。
- **走廊**：删除走廊中央的担架/轮椅/输液架；各层楼梯口前的柜子移走。
- **家具**：病床/担架/桌台/柜子/药架/冷柜/太平间抽屉墙/影像设备补碰撞；门洞两侧留 1.2 m。
- **美术**：中性冷灰墙、奶油色墙帽/扶手、青蓝状态灯、琥珀警示，墙面加墙帽与踢脚；减少旧绿色调。
