## 5. 已知偏离 / 未达标 / 后续

1. **无 Blender（结构性偏离）**：本机与工作区没有 Blender 5.2.2，也没有腐墟星 `.blend` 源。
   指南方法一（高模 Subsurf ≥50k + Cycles 高烘低 + `.blend` 交付）未执行；
   以“程序化真实倒角/厚度/承力 + 2K 分族法线/粗糙 + 世界空间四层旧化 + 合批顶点近似遮罩”替代。
   因此近景缺少高模烘焙的曲率/AO 与大形非对称历史痕；若需要达到 ART-SAMPLE-002 英雄件级别，
   需安装 Blender 并为门锁、激光剑、能源站控制台等 5–8 件关键件补高模烘焙。
2. **色板比例**：B 机位 base 69.1% / shell 17.3% / teal 10.3% / orange 2.6% / red 0.7%，
   全部落在 ±3 容差内；shell 与 teal 都贴上沿，下一轮可继续把少量分板换深色、部分青绿降为暗青。
3. **室内亮度**：医院大厅/能源站 1F 仍偏亮（地面采样约 RGB 118–136），已比改造前降一档；
   下一轮优先给室内加「可见灯具 + 灯罩 + 局部暗角」，而不是继续整体降环境光。
4. **性能**：p50 13.44 ms / p95 16.50 ms（74/61 fps）达标；draw calls 2,146 高于设计单 ≤1,400 的目标，
   但 60 fps 已成立。全场景网格 5,512 个（含室内），下一轮优先给室内层设置 `visibility_range`、
   把室外装饰按材质进一步合批。
5. **未做**：其他四栋建筑的室内完整重做、主角远端模型、HUD 重绘、音效、`ExplorePropKit` 的 E 键自由探索接入。
