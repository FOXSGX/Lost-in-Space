# RUIN-ANIM-004 · 腐墟星激光剑手腕挥动

日期：2026-11-25
范围：第一人称激光剑攻击动作，仅改视模型层级与动画，不改攻击判定/伤害/冷却/联机同步。

## 问题

旧的攻击把 `_ruin_viewmodel` 整体绕 X 轴压到 -105°：
剑、手套、前臂、袖口一起转，看起来像整条手臂抡出去，而不是手腕挥剑。

## 修复

- 在视模型里新增 `SaberWrist` 手腕枢轴，位于手套中心 `(0,0,-0.13)`。
- 剑柄/握柄缠带/护手/护手耳/发射口/三层刀身，以及手套、拇指、手指、指缝、指节带，全部 `reparent` 到 `SaberWrist`，保持原世界位置。
- 前臂 `Forearm` 和袖口 `Cuff` 留在 root 下，不跟手腕转。
- 动画改为：
  - 手腕绕 X -52°、Y -18°、Z 55° 的斜向挥砍；
  - root 只做约 6° 前送 + 2° 侧摆 + 10° 侧倾，以及 4.5 cm 前移；
  - `SaberBladePivot` 额外 -6° 跟随。
- 攻击时长仍 0.26 秒，`play_ruin_attack()` 与命中/冷却逻辑不变。

## 验证

- `ruin_laser_sword.gd`：18/0，新增 `SaberWrist` 存在、攻击时手腕旋转 >0.5 rad、root 旋转变化 <0.5 rad 的检查。
- `ruin_first_person.gd`：21/0。
- `ruin_art_audit.gd`：47/0。
- 连续帧截图：`work/ruin-anim-20261125/sword_00_idle.png` … `sword_05.png`。

## 已知边界

- 视模型仍只有前臂+手套，没有上臂/肘部；这是第一人称手持模型，不重做完整手臂。
- 攻击判定、伤害、冷却、网络同步均未改。
