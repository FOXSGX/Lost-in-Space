# RUIN-UX-017-20261127 · 医院2F空门框、能源站手轮、跃迁钥匙回对话

## 1. 医院 2F 房间只留空门框

- 2F 门诊/检查室门洞的 `DoorPanel` 不再生成；`_door_frame(..., false)` 只保留立柱和门楣。
- 门洞无碰撞，玩家可直接穿过。
- 验证：`ruin_hospital_interior.gd` 69/0：
  - 每个 2F 门洞胶囊可直接通过；
  - 2F 不存在 `DoorPanel` 模型。

## 2. 能源站菌群泵/主反应堆：转轮交互

参考共振星的可旋转装置：

- B1 菌群泵控制台新增 `PumpWheel` 手轮；
- B2 主反应堆控制台新增 `ReactorWheel` 手轮；
- 每次按 E 将手轮旋转 25%，提示 `转动手轮 · 25% / 50% / 75%`；
- 4 次转满才触发：
  - 菌群泵关闭；
  - 主反应堆重启。
- 反应堆手轮在菌群泵关闭前被机械锁死，不能提前转。
- 手轮旋转进度写入 `story_flags["pump_wheel"] / ["reactor_wheel"]`，并通过快照同步到客户端。

验证：`ruin_energy_station_interior.gd` 40/0；`ruin_story.gd` 49/0。

## 3. 反应堆完成后必须回对话领钥匙

新流程：

1. B1 手轮转满 → 菌群泵关闭；
2. B2 手轮转满 → 主反应堆重启；
3. 此时 **不开放撤离**，目标变为：
   `回庇护所/配电间门外通讯，领取跃迁钥匙`
4. 回到配电间门外/庇护所通讯，出现选项 `领取跃迁钥匙`；
5. 对话后：
   - 获得物品栏关键道具 **跃迁钥匙**；
   - `story_flags["launch_key"]=true`；
   - 才真正开放撤离；
6. 回登陆艇按 E 结算真结局。

防御：
- 未拿钥匙时登陆艇交互会提示先回去通讯，不会提前结算。
- `extraction_ready()` 对医生路线要求 `launch_key`。
- 旧快照中的 `reactor_restarted` 不会绕过钥匙。
