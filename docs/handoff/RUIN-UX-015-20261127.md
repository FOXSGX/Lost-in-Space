- 验证：`ruin_hospital_interior.gd` 62/0，逐门洞胶囊检查通过。

截图：`work/goal6-fix2/ruin_hospital_capture/06_ward_3f_locked.png`

## 2. 医院一楼悬空板

- `_light_panel()` 原来把灯板压到 `_floor_y + 2.60`，比天花板低 0.4 m，看起来像悬空板。
- 现在灯板固定在 `_floor_y + 2.78`，底座高度 0.24 m，顶端直接顶到天花板。
- 一楼大厅、走廊的吸顶灯不再悬空；灯仍保留照明。

截图：`work/goal6-fix2/ruin_hospital_capture/01_lobby.png`

## 3. 超市办公室封闭 + 楼梯防坠

- 二层经理室补成四面封闭：
  - 西墙 `x=4`，延伸到 z=9；
  - 南墙只保留门洞西侧一段；
  - 新增东墙 `x=8.5`；
  - 门洞仍在 `x=7.8 / z=3.2`，宽 1.4 m。
- 公共楼梯模板新增：
  - 每层入口平台 `StairLanding`，填满门洞到第一级踏步之间；
  - 入口前沿防坠护栏 `StairGuard`，只留本层有梯段的槽位；
  - 平台向内伸入 0.5 m，避免门边缝隙。
- 验证：`ruin_market_interior.gd` 34/0，办公室四面墙和门洞检查通过；`ruin_stair_parity.gd` 85/0。

截图：`work/goal6-fix2/ruin_market_capture/08_office_task_2f.png`
