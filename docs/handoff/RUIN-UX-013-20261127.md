# RUIN-UX-013-20261127 · 小任务栏/Tab、任务揭示、无 NPC 病房与门板清理

## 1. 任务栏缩小与 Tab

- 任务栏宽度 `420`，位置 `(104,112)`，避开左上两个装备方框。
- 未接任务时高度 **148**；接到任务信息并列出六件物品时高度 **228**。
- 增加小字提示：`Tab 收起任务栏` / `Tab 展开任务栏`。
- Tab 已接入输入：展开 ↔ 收起；收起时只保留标题、提示和当前目标。
- 装备栏切换从 Tab 改为 **I**；旧存档/配置中的 `toggle_equipment=Tab` 自动迁移到 I。
- 验证：`ruin_task_hud.gd` **14/0**（位置、方框不重叠、Tab 按键收起/展开、初始小尺寸）。

## 2. 任务物品按对话揭示，并即时刷新

- 任务栏初始只显示：
  `任务物品 · 未获取任务信息 / 先到能源站配电间门外使用门禁通讯`。
- 第一次打开庇护所门禁通讯后写入 `story_flags["quest_intel"]`，任务栏才列出六件任务物和位置。
- 任务物拾取时（医院/学校/超市/能源站）立即调用 `controller._update_hud()`，不等下一帧或重新打开面板。
- 六件进度示例：
  - `任务物品 3/6`
  - `✓ 低温稳定剂 · 医院 B1 药库`
- 验证：`ruin_task_hud.gd` 检查初始隐藏、对话后显示、拾取后 `1/6` 即时更新。

## 3. 医院 2F/3F 门板与病房布局

- 删除病房门上的棕色悬空装饰：
  - `WardThreshold`
  - `WardLockPlate/Cylinder/Keyhole/Hood/Tag`
  - 门面凸出上下凹板
- 西南角未上锁病房门板直接删除，改为开放门洞；只保留五扇上锁病房门及互动。
- 病房布局调整：
  - 病床从贴西墙的 `x=-4.0` 内移到 `-3.6`
  - IV 架从 `x-1.35`（穿墙）改到 `x-0.85`
  - 移除病房/检查室隔帘，避免门洞附近穿模和遮挡
- 验证：`ruin_hospital_interior.gd` **57/0**；`ruin_interior_clipping.gd` **1492/0**。

## 4. 全地图取消 NPC 实体

- 医院观察室 3 个 `SedatedNurse` 护士实体全部删除，任务物仍可正常拾取。
- 庇护所工程师/医生实体删除；只保留不可见对话锚点，交互仍通过门禁通讯对话。
- 验证：`ruin_hospital_interior.gd` 检查无 `SedatedNurse`；`ruin_story.gd` **37/0** 仍能完成对话流程。
