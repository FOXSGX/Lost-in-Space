## 一、剧情：离开的关键是什么

**一句话**：登陆艇的跃迁电池已经死了，腐墟星殖民城的主反应堆是唯一还能给它充电的东西；
反应堆点火芯在爆发时被弹射进能源站 B2 应急舱。取回**星髓点火芯**，配上**低温稳定剂**和
**导航密钥**，重启反应堆，回登陆艇离开。

| 任务物 | 位置 | 作用 |
|---|---|---|
| 星髓点火芯（ID 仍为 `reactor_core`） | 能源站 B2 应急舱 | 能量钥匙；星髓菌群代谢结晶，不是普通电池 |
| 低温稳定剂 | 医院 B1 | 防止点火芯重启过热 |
| E-07 门禁卡 | 医院 1F | 打开 B2 应急舱 |
| 天文观测数据 + 民用导航模块 | 学校 3F / 超市 2F | 拼成导航密钥，算出安全跃迁路线 |
| 镇静实验病历（可选） | 医院 2F | 质问工程师、影响对话与尾声，不卡通关 |

### 流程

1. 登陆 → 能源站 1F 配电间暗门 → 地下庇护所。
2. **分别与工程师、医生交谈**；两人都谈过才开放最终三选一。
3. 医院 B1 稳定剂 + 1F E-07；学校 3F 观测 + 超市 2F 导航模块（拼导航密钥）。
4. 能源站 B2 取星髓点火芯。
5. 回庇护所选择方案。
6. 按方案执行，最后**回登陆艇按 E**结算：
   - 工程师：180 秒倒计时，回艇按 E → 星球毁灭。
   - 医生：B1 关泵 → B2 重启 → 回艇按 E → 真结局。
   - 隐瞒：直接回艇按 E → 能源不足迫降。
7. 倒计时耗尽 → 超时沦陷。

## 四、感染体造型细化

保留原有骨架、枢轴、`animate()`、碰撞尺寸与三种形态剪影，只加造型层：

- **步行者**：头骨缩小、补眉骨/颧骨/耳/鼻/颈腱；肋笼改左右三段曲线 + 胸骨；
  衣领/撕裂衣襟/腰包/肩垫；上臂/前臂收分，补袖口、腕、指节、拇指；鞋帮/鞋底、光脚脚趾。
- **鼓胀者**：头略缩小、补眉骨/颧骨/下颌褶；肚子补下垂褶、撑破衣条、鞋底；四肢收分。
- **爬行者**：补脊椎骨节、肩胛、拖行肌腱、第二排肋骨、眉骨/颧骨；手部保留爪状指。
- 调色：皮肤更灰绿、工装更脏、靴子提亮、眼睛孢子光从 0.35 降到 0.20；
  移除“黑色贝雷帽”式整块头发，改为无发/少量残发。
- 细节件仍挂原枢轴，动画测试 40 项通过；新增 `ruin_infected_capture.gd` 三种形态棚拍。
