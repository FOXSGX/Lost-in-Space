# 《迷失太空》八周开发计划

## 1. 最终目标

八周结束时交付一款可完整游玩的学生作品，而不是只展示一个技术样例：

- 四人可以在同一局域网加入同一局游戏。
- 飞船是基地，玩家可以准备装备并选择星球。
- 四个星球都可以进入、采集、战斗、撤离。
- 每个星球都有一种独特环境规则。
- 玩家可以倒地，队友可以救援。
- 完成第四个星球后返回地球并显示结算。
- 单局目标时长约 30～45 分钟。

四个星球都做成固定的小型手工地图。共用玩家、资源、武器、敌人、联机和撤离系统，不为每个星球重写一套底层代码。

## 2. 固定范围

### 必须完成

- Godot 4 项目。
- 四人局域网联机。
- 一艘飞船基地。
- 四个小型星球。
- 一种主要资源和一套任务进度。
- 两种基础武器。
- 两种基础敌人。
- 倒地与救援。
- 撤离和星球解锁。
- 返回地球结算。

### 首版不做

- 互联网匹配、专用服务器和主机迁移。
- 持久存档和跨局成长。
- 职业树、技能树和随机装备词缀。
- 程序化生成大型地图。
- 大量敌人和复杂 Boss。
- 多人中途加入正在进行的任务。

## 3. 四个星球

| 星球 | 核心规则 | 需要玩家形成的合作 |
|---|---|---|
| 冰冻星球 | 离开热源后失温并加快氧气消耗 | 携带热源、扫描资源、护送搬运者 |
| 沙暴星球 | 沙暴周期性降低视野 | 提前标记路线、判断继续探索还是撤离 |
| 沼泽星球 | 泥地减速，重物进一步降低移动速度 | 搬运者需要队友护送和清理路线 |
| 电磁星球 | 干扰扫描器和武器，需激活电力节点 | 一人找节点，其他人保护和搬运 |

每个星球至少包含：两个资源区域、一个环境危险、敌人遭遇、一个撤离点和一个必须配合的局面。

## 4. 八周安排

### 第1周：共同入门和工程准备

- 四人完成 Godot 4 基础练习。
- 建立 Git 分支和 Pull Request 规则。
- 完成玩家移动、碰撞和基础场景。
- 完成局域网主机/加入测试。
- 搭建飞船灰盒和基础 HUD。

**周验收：**四个实例能够连接并看到四个不同玩家。

### 第2周：联机玩家和基础战斗

- 玩家生成和移动同步。
- 普通能量枪。
- 第一种近战敌人。
- 玩家生命、弹药和受击反馈。

**周验收：**四人在同一张测试地图上移动、射击并击败敌人。

### 第3周：资源、救援和冰冻星球

- 燃料资源的拾取、携带、放下和存入飞船。
- 氧气、倒地和队友救援。
- 冰冻星球完整流程。
- 热源范围和失温规则。

**周验收：**四人能够在冰冻星球采集、战斗、救援并撤离。

### 第4周：沙暴星球和沼泽星球

- 沙暴视野机制。
- 沼泽减速机制。
- 第二种远程敌人。
- 星球完成后返回飞船。
- 星球解锁和进度显示。

**周验收：**前三个星球能够连续完成，且玩法差异明显。

### 第5周：电磁星球和最终返乡

- 电磁干扰。
- 电力节点。
- 强化敌人模板。
- 最终资源区域。
- 返回地球结算。

**周验收：**从飞船出发到返回地球的完整流程可运行。

### 第6周：表现和数值

- 替换关键占位素材。
- 加入音效、危险提示和任务引导。
- 调整武器、敌人、氧气、资源和撤离数值。
- 完善飞船和结算界面。

本周结束后冻结新机制。

### 第7周：四人压力测试

- 四台不同电脑同时加入。
- 测试多人同时拾取、攻击和救援。
- 测试玩家退出、重复开局、星球切换和主机断开。
- 找没有参与开发的同学试玩。

### 第8周：打包和提交

- 修复阻断流程的问题。
- 导出 Windows 版本。
- 整理启动说明和联机说明。
- 录制从飞船到返回地球的演示视频。
- 连续完成三次最终验收。

## 5. 进度削减顺序

如果时间不足，按以下顺序削减：

1. 删除可选资源和装饰区域。
2. 删除飞船升级动画，保留功能。
3. 删除强化敌人的特殊效果。
4. 暂时隐藏第二种武器。
5. 减少音效和装饰素材。

以下内容不能删：四人局域网、四个可进入星球、每个星球一个环境机制、资源收集、基础战斗、倒地救援、撤离和返回地球。
