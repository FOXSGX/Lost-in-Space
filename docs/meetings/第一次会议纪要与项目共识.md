# 第一次会议纪要与项目共识

本文依据团队提供的第一次会议纪要整理，供后续设计讨论和群内同步使用。会议日期未提供。

参会发言人：胡展赫、马文韬、孙同恩、陈斯齐。

## 一、会议明确的方向

- 游戏定位：多人联机合作类派对游戏，支持单人尝试通关，降低评委试玩门槛。
- 基础玩法：生存射击闯关，兼顾物资搜集、探索以及躲避或对抗敌人。
- 世界观：地球人的飞船在星际迷航，需要在不同星球搜集燃料与物资，最终返回地球。
- 关卡结构：参考地铁线路图组织分支路线，通过星球跳跃连接关卡；包含必玩关卡与可探索的隐藏支线。
- 路线体验：允许玩家选择快速返航或探索支线获取更多资源。是否设置计时、排名或独立竞速模式尚未确定。
- 联机救援：玩家死亡后留在原地，由队友前往救援复活。
- 单人复活：通过搜刮绷带、复活药等物资获得自我复活机会。
- 角色方向：计划设置具有不同技能或特点的角色。
- 敌人方向：不同星球的异星生物；允许关卡包含陷阱或解谜任务。
- 美术生产：安排特定成员负责美术，并利用 AI 辅助生成资源；纪要未注明该成员姓名。

## 二、团队倾向，尚需落实

- 优先考虑 2D 开发，参考《元气骑士》等 2D 射击游戏的表现形式；具体引擎与视角尚未确定。
- 美术倾向写实，但具体风格样例、资源规格和动画制作流程尚未确定。
- 此前讨论过各成员分别负责星球；当前纪要尚未列明最终分工。

## 三、已放弃的方向

- 纯竞技模式。
- 地铁末日作为最终世界观背景；地铁线路图仍作为关卡路线的设计参考。
- 传统僵尸作为主要敌人设定。

## 四、待确定的具体规则

1. 比赛完整名称、规则、截止时间、提交平台和试玩条件。
2. 联机人数上限、局域网或异地联网方式，以及单人模式如何独立完成合作操作。
3. 具体引擎、2D 视角、输入方式与目标运行平台。
4. 射击、采集、搬运及角色技能之间的核心合作关系。
5. 首个星球的环境、敌人、资源、撤离条件和胜利条件。
6. 死亡后是否区分倒地与死亡、救援时限、救援消耗、物资损失及全队死亡后的处理。
7. 单人复活物资的获取方式、次数、消耗和复活位置。
8. 分支路线选择规则、跃迁燃料消耗、隐藏支线收益及资源不足时的处理。
9. 角色数量、差异化技能与制作优先级。
10. 美术负责人、各成员技能与可投入时间，以及后续关卡分工。

## 六、此前助手建议的状态

下列内容属于此前助手提出的建议，未经本次会议确认，不作为团队已定设计：

- 2D 俯视角。
- 首版两名玩家、一个星球、两种工具、一种主要资源。
- 风暴星、钻机与护盾、合作搬运及约 8–12 分钟的单局长度。
- 死亡后在飞船消耗共享资源复活。

其中，联机死亡后在飞船复活的建议与本次会议的原地队友救援方向不同。后续设计以本次会议方向为准，具体救援细则仍需确认。
