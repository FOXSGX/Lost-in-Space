## 七、第 3 批：R-15 结论更正（实测证伪手算）

| 项 | 内容 |
| --- | --- |
| 原审计结论 | 撞击帧锤头悬停在铁砧上方 **0.22 m**（手算：`4.30 − 3.50·cos30° − 0.39 = 0.883` vs 砧面 `0.66`） |
| 实测结果 | 锤头 AABB 底面 **y = 0.672**，铁砧（含 `StrikePlate`）AABB 顶面 **y = 0.805**，**重叠 0.133 m** |
| 结论 | **原审计的"悬空"判断错误，R-15 的几何部分不成立**。锤头确实落在砧面上。 |
| 误差根因 | 手算把锤头当成不旋转的 0.78 高箱体。实体挂在 `_pivot` 下随摆臂旋转 −30°，`HeadBand`（高 0.86）与 `StrikerFace`（z 偏 0.62）使旋转后世界 AABB 显著长高，必须量 AABB 而不是算中心减半高。 |
| 处理 | 上一轮误加的 0.22 m 抬高铁砧**已完整回滚**；`hammer_rig.gd:138-146` 恢复原值，并补注释说明实测校核值，防止再次被手算推翻。 |
| 保留部分 | R-15 后半（锤头/铁砧**无碰撞体**、`struck` 位置写死）**仍然成立**，转入"剩余工作"。 |

### 教训（已写入工作规则）

> 凡涉及"某实体在某帧是否接触某面"的结论，**必须实例化场景量世界 AABB**，不得用"枢轴高度 − 臂长·cosθ − 半高"手算。旋转体、多子网格、带朝向的箱体都会让手算与实测相差 0.1~0.4 m 量级，足以把"重叠"判成"悬空"并触发一次错误的几何改动。
