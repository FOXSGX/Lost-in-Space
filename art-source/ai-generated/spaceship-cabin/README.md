# 飞船主枢纽舱｜概念探索

当前探索图：`concepts/ship-hub-v2.png`。此前两张过小的单间舱室图保留在 `archive/`，不作为当前方案。

## 已确认需求

- 舱室要足够大，能作为游戏中的可用空间。
- 有驾驶台，玩家在此选择下一颗要前往的星球。
- 有储物区。

## 当前布局建议（待讨论）

| 位置 | 区域 | 可能的游戏用途 |
| --- | --- | --- |
| 前方高台 | 驾驶台 | 选择目的地，查看可前往星球和出发状态；唯一的选星球交互点 |
| 中央 | 星图展示与开放地面 | 预览航线、保持视野与通行；星图可只作驾驶台操作的反馈 |
| 左侧 | 储物区 | 存取探索所得材料、装备或样本 |
| 右侧 | 整备／维修台 | 整理装备、维修或升级；具体玩法待定 |
| 右后侧 | 氧气／能源补给点 | 出发前补给；是否需要该功能待定 |
| 后方 | 出舱口 | 在飞船与星球关卡之间切换 |

可选：任务／通讯终端，用来回看线索和下一步目标；样本展示墙，用来反馈星球探索进度。这些都是建议，尚未确认为玩法。

建议游玩动线：从出舱口返回 → 整理储物和补给 → 查看目标 → 到驾驶台选择星球。主通道至少容纳两个角色并行，交互设施靠墙布置，中央星图不堵住通路。最终尺寸、交互内容与舱段数量仍需讨论。
