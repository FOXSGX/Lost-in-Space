# 生命 HUD 第 1 层

`approved-ui-demo-20261023.png` 是用户在会话中确认的 imagegen 预览：绿色五格、无爱心、左上角，顶部中间只保留“主舱”。它是设计参考，不作为游戏整屏背景或可交互 UI 使用。

同目录三个 SVG 为本轮编写的可编辑图标原稿，运行副本位于 `game/assets/ui/health/`。面板、五格布局和受伤边缘反馈由 Godot 原生容器与 shader 实现。实际规则和验证见 `game/docs/health-layer1.md`。
