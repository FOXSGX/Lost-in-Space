# 飞船主枢纽舱 3D 源模型

这是根据 `art-source/ai-generated/spaceship-cabin/concepts/ship-hub-v2.png` 制作的第一版可编辑、可导入的低多边形舱室模型。它保留了概念图的功能区和配色，但为游戏视角简化了小零件。

## 文件

- `generate_ship_hub.py`：源模型生成脚本；修改参数后运行 `python generate_ship_hub.py` 可重建模型和预览。
- `ship_hub.glb`：标准 glTF 2.0 二进制模型；所有设施均有独立名称，便于在 3D 软件或引擎中查找。
- `ship_hub-preview.png`：当前模型的等距视角预览。
- `interaction-anchors.json`：交互点坐标建议；仅是数据标记，不包含玩法逻辑。

## 尺度和朝向

- 主地面约 42 × 33 米；Y 为高度，驾驶台位于 -Z，气闸门位于 +Z。
- 舱室以现有人物模型约 2.14 米的高度为尺度参考。
- 主地面顶部为 Y=0；驾驶台高约 0.66 米，两侧有台阶。
- 中央星图是展示设施。按已确认需求，星球选择交互建议接在驾驶台。

## 实现范围

已建出可见几何：地面、舱壁、舰桥与驾驶台、星图、储物架与箱体、维修台、补给柱、任务终端、气闸门。维修、补给、任务终端已按本轮用户要求接入原型，具体规则仍可调整。

游戏场景已接入模型、简化碰撞、共享储物、维修、补给、任务记录和星球往返流程，详见 `game/docs/ship-hub-3d.md`。游戏镜头隐藏近侧门结构以免遮挡角色，源模型保持完整。当前驾驶台从地面前方操作，尚未配置登台与导航网格。

## 2026-10-12 空间扩展

按用户反馈扩大到原面积的 9 倍；舱壁、地面和舰桥平台扩展，储物、维修、补给、任务设施保留人物尺度并分散到各功能区。主舱使用角色跟随镜头，整舱超出单屏，走动才能看到不同区域。

## 精致卡通迭代

用户选择清晰轮廓、圆润设备和统一色彩。本版使用圆角设备、平滑表面、奶油白/青蓝/暖橙配色，补充座椅、边桌、植物与设备细节；此前较简陋的模型和预览保留于 `archive/v0.1.2/`。GLB 颜色由 sRGB 转换到线性空间后输出，避免导入后颜色失真。
