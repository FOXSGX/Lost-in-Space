## 投影和简化

总图 X/Z 等比例，1 世界单位对应 1.88 像素；上方约定为世界 −Z，仅作图面北向，不推定星球地理北极。科考楼放大图使用每世界单位 15 像素。

飞船约 `(0,11)`；仓储楼 `(-38,-95)`；生活楼 `(38,-210)`；主科考楼 `(-36,-340)`；骨口 `z=-463`；三厅中心依次 `z=-530/-680/-830`；钥匙 `(-2.4,-882)`，高约 12.9。纵深约 940 世界单位，地表地台宽 150；仅用于理解现有试玩区域，不是整颗星球的地形图。

图中地表主轴和各厅骨脊具有空间依据，房屋、补给、表层雪和陈设经过简化。屋顶与高处横向骨架省略。紫色支路连接已存在的平台，表达探索关系，不作为逐步导航或碰撞实测结果。观察夹层以虚框标识上层，密闭观察窗不画成通道。
