## 尺度与读图

主图约定上北下南，坐标为本图局部规划坐标，不是现有游戏世界坐标。横纵等比例，1米=8.25像素，规划参考范围180×176米。遗迹在北侧图外，不指定它与站区的最终距离。

主科研楼70×34米，标本馆34×42米，生活医疗楼34×38米，动力站32×26米，机修车库48×25米，仓库43×25米。尺寸用于比较体量，尚不是施工或关卡落地数据。

青线表达主线往返；紫色虚线表达可选连接；米黄线为架空管线，交叉处可以从下方通行；浅色双线为有顶短连廊。主楼东侧留约12米宽建筑间距用于前往骨口。室内墙上普通门洞、楼梯与二层平面省略，不可据此直接生成碰撞。
