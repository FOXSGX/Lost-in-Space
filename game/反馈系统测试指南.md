# 反馈系统测试指南

## 🎮 快速测试步骤

### 1. 启动游戏
1. 打开 Godot 4
2. 加载项目
3. 点击"主机" 创建房间
4. 点击"登陆星球"

---

## ✅ 测试清单

### 移动反馈（WASD）
- [ ] 按 **WASD** 移动
- [ ] 观察脚下是否出现 **浅蓝色脚步粒子**
- [ ] 粒子应该向下淡出消失

### 攻击反馈（空格）
- [ ] 靠近红色敌人（浅蓝圈范围内）
- [ ] 按住 **空格键** 攻击
- [ ] 应看到：
  - ✅ **青色光束** 从玩家射向敌人
  - ✅ 屏幕中央显示 **"命中 -1 HP"**（橙色）
  - ✅ 击杀时出现 **红色粒子爆发** + **"✓ 击杀异形"**（浅红色）
- [ ] 在无敌人时攻击，应显示 **"× 超出射程"**（红色）

### 扫描反馈（Q键）
- [ ] 按 **Q键** 扫描
- [ ] 应看到：
  - ✅ 屏幕中央显示 **"扫描启动..."**（蓝色）
  - ✅ 扫描圈从脚下扩散
  - ✅ 玩家无法移动（锁定3秒）
- [ ] 冷却期间再按Q，应显示 **"× 扫描冷却中 X.Xs"**（橙色）

### 修复信标（E键）
- [ ] 找到 **金色天线塔**（有黄色光源）
- [ ] 靠近后按 **E键**
- [ ] 应看到：
  - ✅ **金黄色粒子爆发**（20个）
  - ✅ 屏幕显示 **"✓ 信标修复成功"**（金黄色）
  - ✅ 信标标签变为 **"气象信标已修复 · 求救信号正常"**

### 拾取电池（F键）
- [ ] 找到 **绿色电池罐**（有青色光源）
- [ ] 靠近后按 **F键**
- [ ] 应看到：
  - ✅ **青绿色粒子爆发**（15个）
  - ✅ 屏幕显示 **"✓ 电池已拾取"**（青绿色）
  - ✅ 电池模型消失
  - ✅ 左下角生命栏显示 **"携带: 1"**

### 投送电池（G键）
- [ ] 拾取电池后，前往 **蓝色平台**（有蓝色光源）
- [ ] 进入平台范围按 **G键**
- [ ] 应看到：
  - ✅ **蓝色粒子爆发**（25个）
  - ✅ 屏幕显示 **"✓ 电池投送 X/Y"**（蓝色）
  - ✅ 右上角进度更新

### 受伤反馈
- [ ] 让敌人靠近你（红色异形）
- [ ] 被攻击时应看到：
  - ✅ **红色粒子从身上爆发**（12个）
  - ✅ 屏幕显示 **"受到攻击 -1 HP"**（红色）
  - ✅ 左下角血量减少

### 倒地反馈
- [ ] 让血量降到0
- [ ] 应看到：
  - ✅ **深红色粒子大爆发**（25个）
  - ✅ 屏幕显示 **"× 你已倒地！"**（深红色，2.5秒）
  - ✅ 无法移动和操作

### 救援反馈（R键）
- [ ] 需要两名玩家测试（或等AI队友）
- [ ] 靠近倒地队友按 **R键**
- [ ] 应看到：
  - ✅ 开始时显示 **"救援中..."**（金色）
  - ✅ 3秒后 **青绿色粒子爆发**（30个）
  - ✅ 屏幕显示 **"✓ 队友救援成功"**（青绿色）
  - ✅ 队友站起

## 🎨 视觉效果检查

### 粒子质量
- [ ] 粒子颜色鲜艳明显
- [ ] 粒子有向上抛射轨迹
- [ ] 粒子平滑淡出消失
- [ ] 无粒子残留或卡顿

### 文字提示
- [ ] 文字显示在屏幕中央
- [ ] 字号够大（32）
- [ ] 有深色描边（清晰可见）
- [ ] 颜色符合语义（绿=好，红=坏）
- [ ] 自动消失不遮挡

### 光束效果
- [ ] 攻击光束明亮可见
- [ ] 光束从玩家指向目标
- [ ] 光束有发光效果
- [ ] 光束快速消失（0.15秒）

---

## 🐛 常见问题排查

### 反馈不显示
1. 检查 `_feedback_label.visible` 是否为 true
2. 检查 `_game_layer.visible` 是否为 true
3. 确认游戏已启动（`game_started == true`）

### 粒子不出现
1. 检查 `_world_root` 是否存在
2. 确认粒子位置在视野内
3. 查看控制台是否有错误

### 光束不显示
1. 确认攻击在范围内（浅蓝圈）
2. 检查是否在扫描锁定状态
3. 确认攻击冷却已结束
