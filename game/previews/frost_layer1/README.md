# 霜烬星 · 第 1 层独立灰盒

状态：本轮获授权的空间预览。第一人称环境探索；只做第1层。废弃停机坪、暖光、高塔与冰雪遗迹是候选布景，不确立正式剧情。原霜烬星、正式入口和成员未提交工作均保留。

双击本目录 **play.cmd**。使用当前本机 Godot 4.7.2，或设置 `GODOT_PATH`。也可在 Godot 编辑器打开 `preview.tscn`，按 F6。请先试着自己找入口，路线与截图在验收材料中，可能剧透。

命令行：

```powershell
& "$env:LOCALAPPDATA/Programs/Godot/4.7.2/Godot_v4.7.2-stable_win64.exe" --path "D:/Projects/Lost in Space/game" res://previews/frost_layer1/preview.tscn
```

| 操作 | 输入 |
| --- | --- |
| 走动 / 环视 / 加速 | WASD / 鼠标 / Shift |
| 跳跃 / 推进 | 短按空格 / 长按空格；初始装备一瓶氧气，基础0.5秒推进 |
| 门闩与地面物件 | 看向并靠近后 E |
| 两格手持 / 两格装备栏 | Tab 切栏；滚轮或1、2选格；G放下/卸下；左键安装手持氧气瓶 |
| 暂停操作 / 继续 | Esc；释放鼠标，重力与物理继续 |
| 重新开始 | F5；本轮地图和物品恢复初始状态，不读取或写入正式存档 |
| 关闭 | 窗口关闭按钮或 Alt+F4 |

先从停机坪出发，寻找能进入遗迹的路线，再返回停机坪。没有敌人、死亡坑、失温、收集门槛或强制等待。推进可练习和观察，不是通路门槛。暖色设备当前只提供环境线索，不会融冰。

本轮复用：`SpacePlayer3D` 胶囊、移动数值与跳跃/推进函数，`CrewItems3D` 的两格手持、两格装备与独立氧气/压力资源，`HealthHUD3D` 的五格显示。独立角色适配器负责第一人称镜头与地图输入，不修改公共脚本。

本预览只启动一个本机离线主机，暂不提供加入房间。没有将独立预览冒充已完成1～4人远征接入；第4层再验证主机状态广播、加入与掉线。正式工程已有客户端角色移动权限和主机物资/生命结算保持原样。

初次3～5分钟是待真人验证的设计目标，没有通过慢移速或锁门倒计时凑时长。自动输入回放用于检查碰撞与通行，不证明空间有趣。请记录：哪里首次想靠近、哪里没看懂、是否找到了门闩、返回时有没有主动用捷径。

方案、冲突、测试计划与原始记录：仓库 `work/gameplay-iterations/20261023-frost-layer1/`。交付验收见本目录 `ACCEPTANCE.md`。
