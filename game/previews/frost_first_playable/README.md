# 霜烬星首版 · 0.3 科考站扩展

独立入口：本目录 `play.cmd` 或 `adventure.tscn`。保留 frost_layer1 / frost_open_layer1 / frost_heat_layer2；不要用旧预览验收新蓝图。2026-10-28 正式主菜单已通过航程适配接入本关，选择“新航程”从坠落飞船内开始；星球往返、归航储备与独立航程存档见[新航程说明](../../docs/campaign-navigation.md)。本 README 下方未特别标注的网络端口、导出包与无退出存档限制指独立 0.3 入口。

本轮入口：`builds/Frost_FirstPlayable_v0.3_20261025/启动霜烬星.cmd`，无需安装 Godot。菜单和窗口标题显示 0.3；旧 v0.1/v0.2 保留供比较。菜单选择单人、创建主机，或填写局域网主机 IP 加入，UDP 24579，最多四人。不写正式存档。

本轮新增：主科考楼增加带图示的接待台、样本处理台、冷藏架、能源保管柜、观察夹层与密闭观察窗。东侧检修门被冰封：融冰后 E 开门，进附间复位电源，实验灯和附间慢充台恢复。回到西侧解冻样本，E 观察；继续对粉色切片吹风可看它鼓胀，松手缓慢回缩，切片不弹射。夹层有可步行往返的坡、科考档案和补给。该环路完全可选；拿钥匙开保险柜不要求供电、实验或收齐日志。

保留 0.2：入口厅冰封运输橇、栖息厅弹射观察台、深厅设备侧台，基地生活痕迹、广泛融冰与原路返航。物资箱开过不刷新，团灭与断线重连不复制物资。第一人称鼠标转向修复保留。

WASD、鼠标、Shift；短空格跳跃，长按在装备氧气瓶后推进。E 拾取/操作，左键使用选中物品，1/2 或滚轮选择，Tab 切换手持与装备栏，G 放下/卸下，J 查已见记录，Esc 释放光标。联机 Esc 不暂停世界。

从船舱走出，在停机坪两侧拾取热风机、电池、氧气瓶；氧气瓶左键安装。热风机选中后按住左键，瞄准冰雪持续加热。电池与热风机同时携带时，选电池左键更换；各维护电源旁按住 E 可慢充和补氧，避免耗尽软锁。生物背部向下吹可单人弹射，队友可互相加温。空手左键驱离深厅小型生物，亦可绕开。

主线：融开停机坪出口 → 科考站保险柜线索 → 巨型骨口 → 三厅骨脊 → 深处钥匙 → 原路返回科考站 → 开柜 → 回船操作核心台两次，先安装、再恢复航行。日志不作为通关门槛。钥匙与能源由队伍任务匣保管，不占两格且不能丢弃。装机后同一能源不重复进入库存。

灰盒边界：广泛分块表层融冰，不是无限体素挖掘。可见蓝白冰雪可融，暗岩、金属、骨骼是不可融基底；冰雪表层消失后不再挖深。薄层 0.3–0.6 米、出口厚层等有真实碰撞变化。最后约 8% 碎冰化作无碰撞残水，防止留下不可瞄准的小碰撞。

失败选择（本轮可逆实现）：5HP、坠落伤害；队友近旁按住 E 救援约两秒。全队倒地/单人倒地两秒后回飞船，装备、剩余消耗品、钥匙、融冰与世界进度保留；不补满消耗品、不刷新物资。掉出世界的非任务物件回到其可达掉落点。断线玩家物资留原地，重连不凭空赠送装备。

已知限制：手工灰盒，不是最终美术；尚无真人节奏与趣味验收，20～30分钟是目标。当前三厅共用骨脊结构，变体与探索密度仍需真人反馈。主机权威、无客户端移动预测，适合局域网；无主机迁移、无退出存档，暂未做四名真人与公网高延迟测试。没有跨星球系统。起飞为任务完成状态与提示，未制作飞行动画。
