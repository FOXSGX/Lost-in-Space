# Mining Station Prototype 01.1 · 独立审阅工程

本工程仅用于视觉、移动、碰撞和性能检查。未接入正式关卡、矿车驾驶、战斗或网络同步。以仓库内 Godot 4.7.2 打开 `project.godot` 后运行主场景。

## 操作

- WASD：移动；Shift：奔跑。
- 鼠标左键捕获鼠标，移动鼠标旋转第三人称相机；Esc 释放鼠标。
- Tab：切换随角色移动的 1.65m 近景检查相机。
- F1–F4：A 入口、B 矿车侧面、C 矿脉、D 回望的固定参考相机。
- F5：回到可移动第三人称角色。固定相机时角色隐藏并暂停。

正式项目 `SpacePlayer3D` 依赖 Main3D、网络和交互状态，不能直接作为独立预览实例加载。这里复制两个纯相机/移动方法、参数和已有 `ProtagonistVisual`/ranger 资产，增加最小预览适配层。胶囊、移动速度、重力、FOV 和共振星角色比例来自现有实现。相机额外采用 0.22m 球体扫掠、插值后再约束；小场景相机最大臂长 7.5m，靠近两端矿道时连续收至 3.2m，减少转角岩面遮挡。跨轨道使用最大 0.36m 的小台阶检查，仍使用真实碰撞。

## 材质边界

静态场景使用 Blender 源节点的基础色/粗糙度采样、真实 Cycles 静态漫反射光照烘焙和 Blender AgX LUT。36 个参数配置共用一个着色器。COLOR_0 保存对数光照；UV0/UV1 保存颜色与粗糙度数据，**不是可直接换成普通 PBR 的 UV**。自动生成的导入材质由共享着色器替换。

实时部分是角色受光、三组近似 GGX 高光与晶体轻微脉冲。Compatibility 没有本预览所需的 Eevee 屏幕空间反射、区域灯和动态间接光照组合；没有声称原生复现这些效果。开放洞口的稀疏顶点光照经过有尺度限制的低频滤波，不能保留所有小阴影。

**矿车当前作为停靠状态烘焙。移动矿车或改变灯具/场景位置后必须重烘焙。** 此管线不能直接用于行驶矿车。静态表面不接收角色的原生实时阴影，角色脚下使用通用接触阴影近似；角色动态受光仍与静态景物存在差距。

`capture_reference.gd` 保存四个固定参考机位；`walk_test.gd` 用实际 Input 动作和物理移动串行走查；`benchmark.gd` 在移动中采集未限帧墙钟帧间隔。它们从命令行 `--` 后接收绝对输出目录。`walk_test.gd` 另加 `steps` 启用本轮步进修正。示例命令及完整结果位于本轮证据目录的交付报告。
