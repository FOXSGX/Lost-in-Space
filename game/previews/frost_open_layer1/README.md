# 霜烬星 · 开放探索第1层

**本轮请启动这个开放版。** 双击 [play.cmd](play.cmd)，或用 Godot4 打开 `preview.tscn` 按F6。使用当前本机Godot4.7.2，其他安装位置可设置环境变量 `GODOT_PATH`。

命令行：

```powershell
& "$env:LOCALAPPDATA/Programs/Godot/4.7.2/Godot_v4.7.2-stable_win64.exe" --path "D:/Projects/Lost in Space/game" res://previews/frost_open_layer1/preview.tscn
```

从停机坪出发，自由寻找进入高塔下方遗迹的路线，再返回。连续雪地可以横穿，西侧高地和东侧低地都能接近遗迹。请先不看验收材料中的路线与截图，保留首次探索体验。

| 操作 | 按键 |
| --- | --- |
| 移动 / 环视 / 加速 | WASD / 鼠标 / Shift |
| 跳跃 / 推进 | 短按空格 / 长按空格；初始装一瓶，基础0.5秒喷气 |
| 操作门闩 / 拾回物件 | 靠近并看向后 E |
| 切换手持与装备栏 | Tab；滚轮或1、2选格；G放下/卸装，左键安装手持瓶 |
| 暂停操作并释放鼠标 | Esc，再按继续；物理与重力继续 |
| 重新开始 / 关闭 | F5 / Alt+F4或关闭窗口 |

保留5HP与绿色五格UI、两格手持加两格装备、现有双资源推进。新预览复用旧预览适配器与公共系统；旧正式霜烬星、主舱和成员未提交文件均保留。无正式存档写入。

只完成第1层空间验证：没有融冰、敌袭、失温、任务奖励或正式联机；外侧设备只是可走近观察的空间地标。候选的“冰川吞没地热观测站”尚非确定剧情。

真人首次3～5分钟、是否愿意偏离路线和入口是否自然可读，仍需要试玩验证。自动回放知道路线，不代表探索已经有趣。请反馈你首先想去哪、是否换过方向、何处看不懂、返回时是否主动使用检修门。
