# 已知问题 · Resonance 03.1

按严重度排列。`P1` 影响是否能称为可交付试玩；`P2` 影响体验但可绕过；`P3` 是记录项。

## P1

1. **还没有真人试玩证据。** 32 项自动探针、三段脚本化第三人称演示和打包启动都通过，
   但“玩法是否有趣、是否能在不解释的情况下学会”仍未验证。不要对外宣称已证明好玩。
2. **Windows 包不是标准导出模板产物。** 本机没有安装 4.7.2 导出模板，交付包使用官方
   Godot 4.7.2 编辑器二进制作为运行器（`Resonance_03_Winch.exe`），体积约 181 MB，
   窗口标题带 `(DEBUG)`。它可正常游玩，但不是优化发行版。
3. **首次启动约 3 秒同步构建，且首次看到新材质可能有一次管线编译长帧。**
   测试沙箱的 `user://` 不可写，着色器缓存被禁用，因此冷启动数据是最坏情况；
   正常 Windows 用户首次运行后会写入缓存。详见 [PERFORMANCE.md](PERFORMANCE.md)。
4. **包未签名。** Windows SmartScreen 可能提示“未知发布者”；需要“更多信息 → 仍要运行”。
   不要为此关闭系统安全设置。

## P2

5. **仅单人。** 没有网络同步、双人职责、掉线/重连；`docs/coop-future.md` 只是未验证的未来方向。
6. **控制单一。** 只支持键鼠；没有手柄、按键重绑、鼠标灵敏度、音量设置界面。
7. **视觉仍是原型级。** 墙、地面、晶体是程序化几何，没有完整共振星矿洞美术；
   吊耳/锁定销的 3D 文字是临时标识。核心装置（绞盘、轨道、接收架、缆绳）已做结构细化。
8. **深度过冲的恢复需要 W/S 点按。** 超过约 -2° 后放线会让轨道荡回并可能越过复位线到 +7° 左右，
   需要再短按 W 追回。自动测试可以完成，但真人可能需要几次尝试；这是本轮最需要试玩验证的点。
9. **操作控制台时会锁定移动。** 必须按 E 离开绞盘才能走动；HUD 底部有提示，但如果玩家直接按 WASD
   会以为卡住。这是有意的操作姿态，不是输入 bug。
10. **相机在贴墙/贴设备时可能被压近角色。** 有镜头扫掠保护，但没有做完整的遮挡淡出。
11. **锁定座与前端吊耳只隔约 3 米。** 交互用“未挂缆时吊耳优先、挂缆后按最近目标”避免抢键；
    极端站位（两者几乎等距且已挂缆）仍可能先选中锁定座。
12. **音效是占位合成音。** 绞盘循环、离合器提示沿用旧原型的 wav；没有音乐、没有混音设置。

## P3

13. **没有存档/关卡进度。** 只有 R 重置当前任务，完成计数在本次运行内保留。
14. **演示驱动是脚本，不是人类操作。** `--demo=full/wrong_eye/overshoot` 用于录像和打包验证，
    不能用来证明真人可完成或觉得有趣。
15. **draw calls 约 1800–2260。** 当前 1280×800 余量充足，但没有做大型场景的批次合并；
    接进正式矿洞前需要重新测。
16. **窗口模式固定 1280×800。** 没有分辨率/全屏选项。
17. **没有暂停菜单。** Esc 只是暂停并释放鼠标；没有继续/重开/退出按钮。
18. **编辑器二进制作运行器会创建编辑器设置文件。** 在受限目录下可能出现
    “Cannot save editor settings” 日志；不影响游戏运行。
