《迷失太空》Resonance 03.1 · 绞盘轨道修复
单人试玩说明
========================================

一、怎么开始
----------------------------------------
1. 双击同目录的“启动_Resonance_03_Winch.cmd”。
2. 如果 Windows 提示“未知发布者”，点“更多信息”→“仍要运行”。
   本包没有签名，这是正常提示；不需要关闭系统安全设置。
3. 不需要安装。请保持 exe、pck 和本说明在同一个文件夹。

二、你要做什么
----------------------------------------
维修舱里有一段卡在碎石中的轨道。把它拉回接收架，插上锁定销，通路就恢复。
没有人会在任务里告诉你“正确答案”；观察机械、试一次、根据反馈调整。

大致顺序：
  找到断裂轨道 → 把缆绳挂到吊耳 → 回到绞盘操作 → 让轨道回到复位线 → 去锁定座插销

提示（不是答案）：
  * 轨道上有两个吊耳，位置和力臂不一样。先挂哪个由你决定。
  * 绞盘拉不动时，听声音、看张力表、看轨道有没有动；换一个连接点可能更好。
  * 收过头，轨道会越过复位线。按 S 放线，让它荡回来；再用 W 轻轻追。
  * 接管绞盘后不能走动，按 E 离开。
  * 对齐不靠数字：看轨道端部的指针、接收架上的绿色“复位线”和锁定座上的灯。

三、操作
----------------------------------------
W / A / S / D    移动
鼠标             转动视角
Shift            跑（接管绞盘后是慢速微调）
E                挂缆绳 / 接管或离开绞盘 / 检查或插入锁定销
W / S            接管绞盘后：收缆 / 放线
空格             鼓式刹车
Q                松开缆绳
F                装锁定销
R                重置任务（保留完成次数）
F1               操作帮助
F3               正常界面 / 调试界面
Esc              暂停并释放鼠标

四、界面
----------------------------------------
正常界面只显示：当前目标、一行机械状态、张力条、当前可做的操作。
F3 打开调试界面，才显示角度、缆绳长度、端部偏差、张力数值和帧率。
第一次玩建议先不要开 F3，靠轨道和缆绳判断。

五、卡住时
----------------------------------------
* 按了 WASD 不动：你可能还在操作绞盘，按 E 离开。
* 鼠标不见了：按 Esc 释放，再点一下游戏窗口。
* 想重新开始：按 R。
* 想退出：Alt+F4，或 Esc 后关闭窗口。
* 画面第一次看到某个装置时可能顿一下：这是首次着色器编译，不是持续卡顿。

六、这还不是最终版
----------------------------------------
- 只支持单人、键鼠；没有手柄、没有设置菜单。
- 场景是独立测试舱，不是正式矿洞美术。
- 玩法是否有趣、难度是否合适，需要你实际试玩后才能判断。
- 试玩后请记录：你第一次挂了哪个吊耳、什么时候明白要回绞盘、过冲后是否知道按 S、
  有没有觉得来回跑太多。这些比“感觉不错”更有用。

已知问题详见同目录 KNOWN-ISSUES.md；帧时间分析见 PERFORMANCE.md。
