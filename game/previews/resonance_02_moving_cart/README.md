# Resonance Co-op Playtest 01

《迷失太空》共振星 · Resonance Co-op Playtest 01

解压整个文件夹，在 Windows 64 位系统双击 Resonance_Coop_Playtest_01.exe。
必须让同名 .pck 文件留在 EXE 旁边。无需安装或打开 Godot 编辑器。
本包使用已有的 Godot 4.7.2 官方程序作为自定义运行器；未找到标准 Windows 导出模板，故体积较大，不能称为标准模板优化的发行版。

单人试玩
在主菜单选择“单人试玩”。这里只有你自己的一个角色，没有伪造第二个网络玩家。
沿黄色踏步登上矿车，在托盘处取核心，送入共振环底座。随后寻找 A 与 B 两个控制设备。
单人可先在 B 把预载调进稳定带，按 E 离开并锁存 24 秒，再去 A 调频。F1 可随时重新显示提示。

创建与加入房间
1. 房主选择“创建房间”，使用默认 UDP 端口 26741 或输入其他 1024—65535 的端口。
2. 房主把大厅显示的局域网 IPv4 地址和端口告诉队友。有多个地址时，选择与队友同一 Wi-Fi/网线网络的地址。
3. 第二名玩家选择“加入房间”，输入房主 IP 与相同端口，点击连接。
4. 大厅显示 2/2 后，由房主点击“开始合作任务”。本轮房间最多两人。
5. 任务开始后谢绝新加入。要换队友，双方返回主菜单再创建房间。
同一台电脑开两个 EXE 时，第二个窗口填写 127.0.0.1。两台电脑时不能填 127.0.0.1。

操作
W/A/S/D：移动；Shift：跑动；鼠标：转动第三人称视角。
F：靠近并面向核心拾取。核心较重，移动和转身会受影响。
X：在前方有支撑和净空的位置缓缓放下，可再拾取。
G：持芯靠近并面向共振环底座，送入插槽。等待导轨定位和锁爪闭合。
E：靠近并面向设备，接入或离开。A 端 A/D 调频；B 端 W/S 调锁爪预载。
C：靠近控制端停机，保留已安装核心，随后可 E 重试。
Esc：打开任务菜单 / 继续；F1：显示或隐藏操作提示；M：静音。
F9：显示或隐藏开发信息。正常试玩不需要此功能。

合作与失败
两人分别接入 A、B。观察自己的指针、稳定带和另一端状态，交流后微调。
B 的预载也会改变 A 的目标；两人只接入设备不调整，不能完成任务。
短时偏离会使共同进度回落。取得一定进展后持续失配约 8 秒会保护停机，显示原因并释放控制位；核心仍保留，可重新按 E 校准。
成功会有共振环分段接通、能量流、声音和“合作完成”反馈。

重试、找回与离开
Esc 菜单中房主可“重新开始任务”，设备和客户端同步复位，网络会话保留。
地上核心找不到时，房主在 Esc 菜单点击“找回地上的核心”，核心回到托盘。已持有或安装的核心不会被回收或复制。
掉出地图边界的自由核心会自动回收。正常放下不会自动完成安装。
客户端离开后，房主的物品归属和控制位会释放，可按单人规则继续，也可返回菜单重建房间。
主机退出后，客户端返回主菜单并显示断开原因。不支持主机迁移或恢复原房间。

设置
可以调整总音量、鼠标灵敏度，或减少能量流与局部脉动灯光。设置保留到本次程序退出。
本轮以键盘和鼠标为目标；没有完整手柄或按键重绑适配。

连接失败排查
确认双方同一局域网、IP 和端口正确，房主仍在大厅且未满员。约 8 秒连接超时后会返回菜单，可重新尝试。
端口被占用时换一个端口，并让队友使用相同端口。房主返回菜单可释放旧房间。
Windows 若提示网络访问权限，由电脑所有者自行决定是否允许私人网络通信。本包不会关闭防火墙或修改系统安全设置。
校园/访客 Wi-Fi 可能启用设备隔离。不同局域网直连可能需要自行配置 VPN 或路由器 UDP 转发；本版没有公网匹配和 NAT 自动穿透。

验证边界
已经使用两个独立 Godot 进程在本机回环网络验证合作，并保留自动输入录像。
这些属于技术与运行验证，不能证明跨设备/跨网络稳定，也不是两名真人的体验验收。
