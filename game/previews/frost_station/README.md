# 霜烬星 0.4 · 六栋科考站

入口：`play.cmd`，或Godot场景 `res://previews/frost_station/adventure.tscn`。正式主舱的新航程“出舱”也已加载本版本。旧0.3入口保留。

按七轮采访实现主楼上下层、六栋可进入建筑、吸推器、可吃物资与收藏、小运输车、动力恢复及仓库融冰；建筑仍为低模可玩原型，尚非最终美术与真人趣味验收。

## 玩法

- 主楼：中央大厅与综合实验室直接连通。工作台拿吸推器；侧面明显楼梯步行到二层环廊，在首席办公室发现能源保险柜与钥匙线索。北侧大窗可看骨口。
- 标本馆：观看静态、尚未拼装完成的巨大骨架，墙面有少量生物介绍。不设拼装或标本实验任务。
- 生活楼：宿舍、生活区搜集薯片和纪念杯；薯片拿起后左键现场吃，单次消耗，本版只提供食用反馈，不改变血量或引入饥饿值；纪念杯带回地面飞船收藏柜E收藏。没有游戏机。
- 车库：侧面E上车，第一位为驾驶员，其余乘员跟随座位；WASD驾驶，E安全下车。车尾携带手持物件E装货，空手E卸一件。货斗8件、最多4人、最高约9.5米/秒为本轮实现数值。无需额外燃料或修车任务。
- 运输车可进入实际能通过的遗迹地形，没有按洞厅禁驾。地形太窄/坡度或转弯不够时停车下车；主线可以全程步行。车辆掉出边界回车库，货物保留。
- 动力站：E恢复旁路，院边部分灯亮起，供暖区域提供宇航服暖意，本地慢充补氧台恢复。飞船基础维护台始终可用；不修电也能通关。
- 仓库：开放库房搜集物资，用现有热风机融开两处冰封库房。融冰和拾取状态保留，不重复刷物资。

## 操作

WASD / 鼠标环视 / Shift；短空格跳跃，装备氧气瓶后长按推进。E拾取/操作/上下车/车尾装卸，左键使用；吸推器按住左键吸住小物件，右键推出，可影响队友但不直接扣生命。G放下，Tab切栏，1/2或滚轮选格，J日志，Esc释放鼠标。推出后需松开左键再吸，避免立刻重新抓回。

## 主线

主楼二层发现保险柜→巨型骨口→三厅骨脊→深处钥匙→原路返回主楼二层开柜→回地面飞船核心台E两次（安装、恢复航行）。主舱联动版再到进舱设备E回正式主舱。钥匙和能源沿用共享任务匣，不占两格、不可丢弃。配楼、吃食与收藏不增加通关门槛。

## 联机与保存

沿用UDP24579独立预览，最多4人。角色、车辆、货物、吸附物件、动力、收藏与融冰由主机结算，客户端仅提交输入，快照20Hz。无客户端预测、无主机迁移，面向局域网；尚未四真人或公网高延迟验收。掉线释放座位与吸附并留下携带物资。

独立预览退出不保存；主舱航线模式沿用航程检查点保存。新地表schema=4；旧0.3进度导入时保留任务进度，不把旧冰块索引套到新图；主机先在user目录备份原始地表快照 `frost-v3-before-station-*.dat`。几何重建会重新布局地面物资，旧地表物件可从备份恢复；携带物资随主舱物品栏交接。
