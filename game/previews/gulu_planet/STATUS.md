## 本轮（2026-10-30）—— 奶龙静态模型

- 先核对素材：仓库外第三方 `nailong.glb` 71.8 MB、无骨骼、**无 LICENSE** → 不能用；没有其他可用授权模型。
- 因此用 Blender **自建**（`tools/blender/build_nailong.py`）：
  - 身体/头/四肢/尾巴/耳朵 = 骨架曲线 + Skin + Subdivision，**一个连续水密曲面**
    （18,880 三角面、0 非流形边、无孤立点），不再是互相穿插的球体；
  - 五官（眼白/瞳孔/高光/嘴/舌/腮红/鼻孔）由**射线检测贴合曲面**摆放；
  - 曲面内按位置分「奶油色身体 / 浅色肚皮口鼻」两个材质区，不靠叠椭球；
  - 面朝 Blender +Y（Godot -Z），脚底 z=0，高 1.728 m。
- 产出：`assets/characters/nailong.glb`（632 KB）、`tools/blender/nailong.blend`（可编辑），
  预览图 `docs/model/nailong_{front,side,back,three_quarter,first_person}.png`。
- 验证（几何层，不是审美）：Godot 导入 13 网格 / 30,400 三角面 / 脚底 y=0 / 面朝 -Z；
  正前方射线逐个命中眼、瞳、嘴、舌、腮红、鼻孔（都没被头吞掉）。
- **明确未做**：没绑骨骼、没做动画、**还没替换游戏里的占位外观**。

## 本轮（2026-10-29 晚）改了什么

### 1. 第一次游玩的流程
- 出生点 `(-11, 0.02, 5.0)` 一眼能看到三样东西：脚前的**教学罐**、中场的**奶龙**、
  右侧的**船头装货口**（截图 01，三者都在屏幕内）。
- 教学罐在奶龙 `spot_cargo_range`(7.5 m) 之外（实际 10.6 m），
  所以第一次抱货时它不会来抢 —— 先学会 E 拾取 / 送到装货口。
- 第二罐在奶龙窝边（4.2 m），抱起就会被它看见、凑过来，贴太近会被抢；
  想安全搬就得绕路，想快就得利用它的扑击。
- 第三罐开场就在它嘴里 —— 想拿回来只能骗它扑。
- 提全是短句，且随状态变化（不锁操作、不播剧情）。

### 2. 修掉的机械重复 / 无意义等待
| 问题 | 处理 |
| --- | --- |
| 原地按 3 次 Q + 横移无限循环 | 上头增量按情境：叼着货 +0.50（**按 2 次**就够）、你抱着货 +0.42、平时 +0.34；冷却 0.65 s |
| 够不到也扑，扑完待在原地 | 蓄势前先确认**在扑击射程内**（`pounce_speed×pounce_time−0.4`≈4.2 m），太远就继续靠近；挑衅已满则记 pending，靠近即扑 |
| 锁定时机看不清 | 蓄势瞬间在地面生成**红圈标记**（`PounceLockMarker`），圈消失=扑结束；HUD 同步提示“离开红圈” |
| 大部分时间在等恢复/回窝 | 恢复 1.5→**1.25 s**；失去兴趣才回窝 |
| 站在装货口里挑衅、零风险通关 | 舱内（x>11.2）**禁止挑衅**，提示“先退到舱口外” |
| 借力装货站位太苛刻 | 容错盒扩到 x 12.45–15.90、z ±2.40；抛出后进入舱口范围会被**斜面引导向中间**（横向加速） |
| 安全搬运没有代价 | 奶龙看见你抱货会凑过来，贴太近 0.75 s 会**抢走**手上的罐子（有 HUD 预警 + 咀嚼音，不掉血），被抢后正好可以骗它扑回来 |

### 3. 美术
- 天空从“纯色 + 全强度雾”改成 **ProceduralSky**，雾只轻微影响天空（`fog_sky_affect 0.15`）；
  过曝从 10% 降到 0.5%，mean 0.41–0.55。
- 修掉三处 `TorusMesh` 朝向错误（地面环之前是竖着的）。
- 手持燃料不再带地面光环、灯光调暗（之前会把半个屏幕染成琥珀色）。
- 奶龙视线现在会**盯住你手里那罐**（`set_look_point`），抢货时伸长脖子、张嘴。

### 4. 为多人留的接口（不做联网）
- 奶龙不再写死单个玩家：`setup_actors([...])` + 每 0.3 s 取“最近的、看得见的”目标。
- 燃料记录 `carrier` 与 `credit_peer`，装货口记录 `last_credit_peer`。
- 未新增任何网络代码；不声称多人已验证。

## 已知问题（影响可玩性/美观的前三）

1. **抢货可能过凶**：玩家停在奶龙旁边 0.75 s 就丢货。若真人觉得烦，先把
   `snatch_delay` 提到 1.1 s 或 `snatch_distance` 降到 1.7 m。
2. **借力送货的“命中姿势”仍偏单一**：几乎总是“站在舱口前 4 m 左右 → 侧移”。
   站位窗口约 3.6 m 宽（7.6–11.2），够宽容但变化少。
3. **奶龙仍是程序化占位**：脸是球体拼的，近看（<2 m）能看出接缝；
   正式模型/IP 授权仍未解决。
