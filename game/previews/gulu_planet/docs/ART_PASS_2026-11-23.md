# 美术升级：复用其他星球的成品模型（2026-11-23）

## 1. 目标与原则

爸的要求：建模精细度做不上去，就直接复用同一 GitHub 仓库里**别的星球**已经做好的模型，
把奶龙星的美术拉起来。

本轮原则：

- **只动“看得见的东西”**：新增模型全部是纯装饰 `MeshInstance3D`，不带碰撞、不进物理世界。
- **不碰玩法**：球路、进球判定、奶龙 AI、玩家参数、边界墙碰撞都没有改。
- **不复制外部版权素材**：只复用**本仓库自建**的共振星（洞穴/采矿站）资产；Kenney 的 CC0
  套件本轮没有引入，避免卡通风格与现有写实工业风打架。
- 模型按包围盒等比缩放、底部对齐 `y=0`、水平中心对齐落点；不放进场内球路走廊。

## 3. 实现

新增 `scripts/gulu_asset_dressing.gd`（`GuluAssetDressing`），由
`nailong_environment.gd::_build_imported_dressing()` 在环境建完后作为子节点挂上。

- **缩放**：先把模型入树、量 world AABB，再按“目标高度 / AABB 高度”整体缩放。
  ⚠️ 第一版 bug：在没算入 Y 轴旋转的情况下量 AABB，导致 48 m 的石墙被摆到场地里、
  整个画面变黑；已改用 `mi.global_transform * mi.get_aabb()`（见 `_place`）。
- **材质**：洞穴岩石的原始 albedo 只有 0.16 左右，直接放进亮色沙漠就是一圈黑影；
  `aqs2_rock` 又依赖顶点色（GLB 没有，COLOR=1 会把 AO 打到最暗）。
  因此导入岩石统一改用 `StandardMaterial3D` 砂岩色（`#a89e89 / #93a49c / #c6bca8`），
  但保留模型自带的 `Crack*` 暖橙裂隙条，作为岩层里的暖色纹理。
- **晶簇**：`Cave_OreAmber/Cyan` 表面覆盖为自发光材质（emission 1.35），
  另给最近两簇各加一盏 4.5 m 的点光；其余靠自发光，控制灯数量。
- **碰撞**：只有大门两根立柱加了 `StaticBody3D`（防止玩家穿模），其余装饰零碰撞。
- **阴影**：远处崖壁 / 塔 / 停机坪关闭投影；只有大门和晶簇开阴影，控制阴影贴图开销。

## 6. 第二轮：后期与岩石顶点色（2026-11-23 晚）

上一轮只是把模型搬进来，画面仍然“平”：没有 AO、没有辉光，岩石只能纯色。本轮补上：

### 6.1 环境后期（`gulu_app.gd::_build_environment`）

| 项 | 参数 | 作用 |
| --- | --- | --- |
| SSAO | radius 1.35 / intensity 1.7 / power 1.4 | 货箱、门框、岩体的接触面压暗，物体不再“飘” |
| Glow | intensity 0.55 / threshold 1.05 / screen | 只抬燃料罐、球、晶簇、门带，不让整屏发糊 |
| Adjustment | contrast 1.06 / saturation 1.10 | 抵消 ACES 的灰 |

性能代价：352.8 → **340.7 FPS**（-3.4%），draw call 不变。

### 6.2 导入岩石的顶点色烘焙

`aqs2_rock` 把 `COLOR` 的四个通道当 arris / ao / patch / up 用；外部 GLB 没有顶点色，
缺省白色会让 AO 直接乘到 0.2，岩石变成近黑（上一版就是这样，所以只能退成纯色）。

`gulu_asset_dressing.gd::_bake_rock_colors()` 按顶点位置/法线生成近似值（同一个 mesh 只烘一次，
结果按 `mesh.instance_id` 缓存）：

- `arris` = 位置噪声 × 噪声 → 小面积亮棱
- `ao` = 0.20–0.65 → 凹处压暗
- `patch` = 噪声平方 → 崩落坑
- `up` = 法线 y → 朝上面积尘

同时把 `kit.rock()` 默认的绿色尘土 `#a9b4ad` 换成暖沙 `#d3c3a4`，湿气换成暖褐 `#6b5f4c`，
并在 `_bake` 后重新套用 `aqs2_rock`。这样崖壁终于有了层理、裂隙和明暗层次。

## 6. 侧风与声音反馈（2026-11-23 第三轮）

### 6.1 侧风

- 只在**真实游玩**时开启（`--shots` / `--record` / `--perf` / 确定性测试都不开），
  避免截图和回归不确定。
- 每 20–30 s 起一阵，持续 6 s，横向力 2.4–3.8 N（球质量 1.2 kg，约 2–3 m/s²）。
- 实现：`EnergyBall.wind` 持续力（`apply_central_force`），只在球睡醒时生效；
  `gulu_app._start_gust()` 只负责写这个向量，不改速度、不改位置。
- HUD：顶部中央下方显示「侧风 →→ 3.2」，同时一行提示「侧风来了！球会被吹向…」。

### 6.2 声音

- `sfx.play_pitched()`：可改音高的播放接口。
- 进球音随着连击升调（combo 越高越亮）；最后 10 秒每秒一声倒计时滴答；
  哨声（结束时低音）；起风时一声低频“呼”。

## 7. 地面细节（2026-11-23 第三轮）

`nailong_environment.gd::_build_ground_detail()`，全部无碰撞、厚度 ≤ 5 mm：

- 两条**车辙**从西侧拉到装货平台（z=±1.18），带 14 段胎纹，读得岀“天天过车”。
- 平台前两条**刹车痕** + 三块**油渣黑斑**。
- 场边 12 块**碎石**（`kit.rock_mesh`，0.1–0.3 m），全部在 |z|>3.0，不遮球路。

性能：340.7 → **323.8 FPS**（碎石未合批；后续微调后实测 310–324 区间波动），
draw call 1155 → 1273。
