# 玩法升级：90 秒装卸挑战（2026-11-23）

## 1. 为什么要改

原来的循环是「进一球 → 通关 → R 重开」，只有一发子弹，没有重复游玩的理由。
本轮把它改成有节奏、有风险的街机循环，同时保留原来的手感和物理：

**90 秒限时 · 连击计分 · 每球加时 · 奶龙越来越凶 · 蓄力抽射 · 球随机复位**

## 2. 规则

| 规则 | 数值 | 说明 |
| --- | --- | --- |
| 单局时长 | 90 s | 顶部中央倒计时，≤10 s 变红 |
| 进球得分 | 100 × 连击 | 连击从 x1 起，最高 x9 |
| 进球加时 | +5 s | 上限 90+30 s，鼓励持续进攻 |
| 连击窗口 | 12 s | 12 s 没进球，连击回落到 x1 |
| 被拦断连 | 立刻回到 x1 | 奶龙真的拦下（`blocked` 信号）才触发 |
| 球复位 | 进球后 0.9 s | 从 5 个固定点位随机重生，逼玩家重新走位 |
| 难度递增 | 每 2 球一档 | 奶龙步行/冲刺速度、反应延迟、拦截冷却逐步加强 |
| 结束 | 倒计时归零 | 显示本局得分与历史最高分，按 R 重开 |

难度公式（`_raise_difficulty()`，rank = 进球数 / 2）：

```
walk_speed          = min(base + 0.07·rank, 3.2)
charge_speed        = min(base + 0.06·rank, 4.0)
intercept_cooldown  = max(1.2, base - 0.08·rank)
react_delay         = max(0.10, base - 0.010·rank)
```

R 重开时全部恢复到初始值（`_restore_difficulty()`），不会把难度带进下一局。

## 3. 蓄力踢

- 左键**点一下**：力度 1.0，和以前完全一样（冲量 16 N·s）。
- 左键**按住**：0.15 s 起开始蓄力，1.10 s 到顶，力度线性 1.0 → 1.6。
- 蓄力时屏幕提示「蓄力 xx%　松手踢出」，>1.25 倍时闪「全力抽射！」。
- 只是改变 `EnergyBall.kick()` 的冲量大小；方向、遮挡、距离判定全部不变。

## 4. 兼容性

- `--selftest`、`--physics`、`--motion*` 这些**确定性模式仍用旧规则**（进一球即结束），
  所以 45 条物理/玩法回归一条没动。
- 街机模式由「没有确定性参数」判定，正常启动、`--shots`、`--record` 都是街机。
- 最高分存 `user://gulu_record.cfg`（不进仓库），重开游戏仍保留。

## 5. 自测

新增 `--arcade-test`（21 条，不依赖人工操作）：

```powershell
& $godot --headless --path . -- --arcade-test
# GULU ARCADE SUMMARY passes=21 failures=0
```

覆盖：模式判定、计分、加时、连击上升/被拦清零、球重生且重新可踢、
难度随进球上升、R 重置恢复难度、倒计时结束 + 横幅 + 最高分、蓄力射门速度更快。

原有回归：

```powershell
& $godot --headless --path . -- --selftest   # passes=45 failures=0
& $godot --path . -- --perf                  # 340.7 FPS / 1155 DC
& $godot --path . -- --record                # scored=true loaded=1
```

> 说明：`--record` 的第二脚脚本对帧时敏感，若第一脚斜射没进，会退到
> 「门柱空当」再补一脚（真实物理，不直接改分）。

## 6. 下一步可加（等爸点头）

1. **风向/沙暴**：每 20 s 一次侧风，球路偏移 + HUD 箭头提示，增加预判。
2. **多球同场**：同时 2 个球，进一个补一个，忙起来更爽。
3. **奶龙技能**：扑救冲刺（短距离爆发）和假动作，制造「被骗」的瞬间。
4. **连击奖励**：x5 以上进球时飞船装货口给一次全屏脉冲/加速带。
