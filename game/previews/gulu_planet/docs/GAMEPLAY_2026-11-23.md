# 玩法升级：90 秒装卸挑战（2026-11-23）

## 1. 为什么要改

原来的循环是「进一球 → 通关 → R 重开」，只有一发子弹，没有重复游玩的理由。
本轮把它改成有节奏、有风险的街机循环，同时保留原来的手感和物理：

**90 秒限时 · 连击计分 · 每球加时 · 奶龙越来越凶 · 蓄力抽射 · 球随机复位**

## 2. 规则

| 规则 | 数值 | 说明 |
| --- | --- | --- |
| 单局时长 | 90 s | 顶部中央倒计时，≤10 s 变红 |
| 进球得分 | 100 × 连击 | 连击从 x1 起，最高 x9 |
| 进球加时 | +4 s | 上限 90+30 s，鼓励持续进攻 |
| 连击窗口 | 10 s | 10 s 没进球，连击回落到 x1 |
| 被拦断连 | 立刻回到 x1 | 奶龙真的拦下（`blocked` 信号）才触发 |
| 球复位 | 进球后 0.9 s | 从 5 个固定点位随机重生，逼玩家重新走位 |
| 难度递增 | 每 2 球一档 | 奶龙步行/冲刺速度、反应延迟、拦截冷却逐步加强 |
| 结束 | 倒计时归零 | 显示本局得分与历史最高分，按 R 重开 |

难度公式（`_raise_difficulty()`，rank = 进球数 / 2）：

```
walk_speed          = min(base + 0.07·rank, 3.2)
charge_speed        = min(base + 0.06·rank, 4.0)
intercept_cooldown  = max(1.2, base - 0.08·rank)
react_delay         = max(0.10, base - 0.010·rank)
```

R 重开时全部恢复到初始值（`_restore_difficulty()`），不会把难度带进下一局。

## 3. 蓄力踢

- 左键**点一下**：力度 1.0，和以前完全一样（冲量 16 N·s）。
- 左键**按住**：0.15 s 起开始蓄力，1.10 s 到顶，力度线性 1.0 → 1.5。
- 蓄力时准星下方有**进度条**（青→琥珀），屏幕提示「蓄力 xx%　松手踢出」，>1.25 倍时闪「全力抽射！」。
- 只是改变 `EnergyBall.kick()` 的冲量大小；方向、遮挡、距离判定全部不变。

## 4. 兼容性

- `--selftest`、`--physics`、`--motion*` 这些**确定性模式仍用旧规则**（进一球即结束），
  所以 45 条物理/玩法回归一条没动。
- 街机模式由「没有确定性参数」判定，正常启动、`--shots`、`--record` 都是街机。
- 最高分存 `user://gulu_record.cfg`（不进仓库），重开游戏仍保留。

## 5. 自测

新增 `--arcade-test`（21 条，不依赖人工操作）：

```powershell
& $godot --headless --path . -- --arcade-test
# GULU ARCADE SUMMARY passes=21 failures=0
```

覆盖：模式判定、计分、加时、连击上升/被拦清零、球重生且重新可踢、
难度随进球上升、R 重置恢复难度、倒计时结束 + 横幅 + 最高分、蓄力射门速度更快。

原有回归：

```powershell
& $godot --headless --path . -- --selftest   # passes=45 failures=0
& $godot --path . -- --perf                  # 340.7 FPS / 1155 DC
& $godot --path . -- --record                # scored=true loaded=1
```

> 说明：`--record` 的第二脚脚本对帧时敏感，若第一脚斜射没进，会退到
> 「门柱空当」再补一脚（真实物理，不直接改分）。

## 5. 奶龙：看得懂的意图 + 会犯的错 + 性格（2026-11-23 第六轮）

目标：不用新按键、不看说明，玩家能看出它要扑哪边，主动骗过它，并且觉得它扑空很好笑。

### 5.1 它会“读站位”（可观察信息，不读输入）

- 玩家在球 2.9 m 内、且大致处在“球→门”方向上时，奶龙会读
  `sign(玩家z - 球z)`——你站在球的哪一侧。
- 站定 **0.40 s** 才锁定；换边会清零重读。
- 锁定后它会把站位偏移 **0.42 m**，并做重心偏移 + 侧倾（`set_anticipation`），
  头部始终先跟球。

### 5.2 它会犯的错

- 扑救瞬间若“实际来球方向”与预判侧相反，它会按预判侧扑出去（不是修正）→ 扑空。
- 扑出后目标锁死 `intercept_time`，恢复期不能瞬间反向。
- 所以：**先站在一侧把它骗过去，再绕到另一侧射门**，就能造出空当。

### 5.3 性格

| 事件 | 表演 |
| --- | --- |
| 扑空 | 先看滚走的球 0.35 s，再回头看玩家 0.6 s，同时前倾（`play_whiff`） |
| 扑住 | 短促挺胸得意（`play_save`），随后直接进回防，不强制停下等动画 |

## 6. 侧风降为实验开关

- 默认 **关闭**；只有加 `--wind` 启动参数才启用（声首不变）。
- 开启时仍是 25–35 s / 5 s / 2.0–3.0 N，HUD 显示方向。
- 新增 `--wind-goal`：开着侧风跑完整进球/计分/重开周期 —— 6/0。

## 7. 表现层：标题屏 / 开场 / 结算（2026-11-23 第五轮）

目标不是加玩法，而是让它“像一个发出来的游戏”。新增 `scripts/gulu_presentation.gd`
（独立 CanvasLayer，只做包装）：

| 模块 | 内容 |
| --- | --- |
| 标题屏 | 「奶龙星·物流站 / 装卸挑战」大标题、副标题、按键说明、最高分、呼吸提示；点击/回车开始 |
| 开场 | 3 → 2 → 1 → 「开始！」大字，带回弹缩放 + 淡出；倒计时结束前不能踢球、不能计时 |
| 进球反馈 | 全屏轻闪 + 世界坐标浮字「+400」「连击 x3」向上飘散 |
| 结算 | 居中面板（圆角/描边）：本局分数、进球数、最佳连击、最高分、「新纪录！」、按 R 重开 |
| 氛围 | 极轻暗角（10%）+ 场地漂浮尘埃粒子（220 个，无碰撞） |

自动化模式（`--selftest` / `--shots` / `--record` / `--perf`）**直接开局**，不显示标题与倒计时，
保证截图与回归确定性；`--ui-shots` 可单独拍标题/倒计时/结算三张。

自测：`--flow-test` → 5/0（标题屏不能踢球、倒计时期间不开局、倒计时后开计时、恢复控制）。

## 7. 侧风与声音（2026-11-23 第三轮）

| 机制 | 数值 | 说明 |
| --- | --- | --- |
| 侧风间隔 | 25–35 s | 只在真实游玩开，截图/录像/回归不开 |
| 侧风持续 | 5 s | 横向力 2.0–3.0 N，HUD 显示方向与强度 |
| 连击音高 | +6% / 层 | 进球音随 combo 升调 |
| 倒计时 | 最后 10 s | 每秒一声，越接近越尖 |

自测：`--wind-test` → 7/0（起风、HUD、横向速度、停风归零、停风后不再加速）。

## 7. 下一步可加（等爸点头）

1. **风向/沙暴**：每 20 s 一次侧风，球路偏移 + HUD 箭头提示，增加预判。
2. **多球同场**：同时 2 个球，进一个补一个，忙起来更爽。
3. **奶龙技能**：扑救冲刺（短距离爆发）和假动作，制造「被骗」的瞬间。
4. **连击奖励**：x5 以上进球时飞船装货口给一次全屏脉冲/加速带。

## 8. 局内控制与统计（2026-11-23 第七轮）

| 项目 | 行为 | 实现 |
| --- | --- | --- |
| 暂停 | `P` 打开/关闭；鼠标已释放时 `Esc` 也可打开；菜单里 `P`/`Esc` 继续 | `get_tree().paused` 冻结计时/物理/AI，表现层 `PROCESS_MODE_ALWAYS` |
| 暂停菜单 | 「继续比赛 / 重新开始 / 音效：开·关」三个按钮，鼠标可点 | `gulu_presentation.gd` 的 `show_pause/hide_pause` |
| 静音 | `M` 或菜单按钮，关掉全部音效；写进 `user://gulu_record.cfg` 的 `[audio] muted` | `sfx.gd` 的 `set_muted/is_muted` |
| 统计 | 本局射门数、被奶龙扑出数；结算面板显示「射门 12 · 被扑出 4 · 进球率 42%」 | `shots_this_round` / `saves_this_round` |
| 等级 | 每 2 球奶龙 +1 级，HUD 显示 `Lv.N`，提级时进球浮字带「奶龙 Lv.N」 | `dragon_level`，与 `_raise_difficulty()` 同步 |
