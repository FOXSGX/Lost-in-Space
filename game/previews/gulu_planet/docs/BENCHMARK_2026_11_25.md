# 奶龙星 · 对标已上架游戏的全层面改造方案（v1 · 2026-11-25）

> **这份文档是什么**：把《奶龙星 · 90 秒装卸挑战》当成一个**要上架的作品**，逐层对着已经上架、且卖得动的游戏找差距，并给出可执行、可验收的改造单。
>
> **这份文档不是什么**：不是重做立项，不改第四颗星球的定位、不改现有物理与奶龙 AI 的判定逻辑（视觉/表现层优先）。**除标注【已确认】的条目外，其余均为助手建议，未经团队确认。**
>
> **配套**：[美术制作与AI协作指南 v2.0](../../../docs/resonance/美术制作与AI协作指南.md)（第 6 部分是本作画面返修单）、[GAMEPLAY_2026-11-23.md](GAMEPLAY_2026-11-23.md)（现有规则）、[DECISIONS.md](../DECISIONS.md)。

## 1. 对标基准怎么定

### 1.1 选定基准（不是 FIFA，是「一个人也能做完、但看起来像商品」的那一档）

| 对标作品 | 拿它对标哪一层 | 为什么是它 |
|---|---|---|
| **Rocket League**（免费训练场） | 球感、射门权力感、镜头、训练模式 | 同样是「把球送进一个门」，但玩家觉得自己在开车撞墙——**权力感来自尺度与反馈**，不是规则复杂度 |
| **Windjammers 2** | 蓄力 / 超级射门 / 回合张力 | 蓄力与超级招式的读招、骗招结构，与本作的「蓄力抽射 + 骗奶龙」同构（[系统说明](https://wccftech.com/windjammers-2-five-tips-tricks-the-ins-and-outs-of-disc-throwing/)、[蓄力说明](https://www.shacknews.com/article/128449/how-to-do-a-charged-shot-windjammers-2)） |
| **Mario Strikers: Battle League** | 超级射门演出 + 守门员对抗 | 「蓄力必杀 → 守门员用力抵抗」这一整套戏剧结构，正是本作缺的高潮（[Hyper Strike 与守门](https://game8.co/games/Mario-Strikers-Battle-League/archives/378571)） |
| **Fall Guys** | 角色喜剧感与可读性 | 靠**形状、物理、肢体**让人笑，不靠台词——本作奶龙最缺这一层 |
| **Pikmin 4** | 生物表演（待机、注视、反应） | 给「不会说话的小生物」设计表情与行为的教科书 |
| **OlliOlli World** | 分数攻击循环与连击 | 短局 + 连击 + 重开，与本作 90 秒挑战同型 |
| **Neon White / Hades** | 重试节奏与打击反馈 | 死亡到重开 <2 秒、命中 60–90ms 顿帧——本作**完全没有**顿帧与镜头反馈 |
| **Golazo! 2 / Super Arcade Soccer** | 街机足球的整体气质 | 说明「小体量 + 高完成度」在足球题材里是成立的（[同类清单](https://nodal.gg/game/super-senseless-soccer-3328320)） |

### 1.2 三条硬约束（否则方案没法落地）

1. **不抄 IP**：奶龙形象、Mario、Rocket League 的车都不能直接搬运；对标的只能是**结构、节奏、反馈方式**。
2. **不超现有产能**：所有 P0 项都必须在 `gulu_planet` 这个 Godot 工程里、由 1–2 人 1–2 周内完成。
3. **不动玩法判定**：球路、进球平面 `x=12.45`、奶龙拦截半径/冷却、玩家移动参数不碰；改造集中在**表现、镜头、UI、音频、场景、进度**。

## 2. 现状体检（只列事实，都有出处）

| # | 事实 | 出处 | 对标的后果 |
|---|---|---|---|
| 1 | 屏幕上有**四处常驻文字**：左上 4 行说明板、顶部 `01:29 / 0 分 / Lv.1`、底部提示条、右上「第一人称 / 已进 0 球」 | `docs/ui_review/20_title.png`、`shots_art_2026_11_25/A_wide.png` | 上架作品的首屏不会把操作说明铺在左上角；且「第一人称」是调试信息 |
| 2 | 球门是**黑底同心圆靶**，视觉语义 = 打靶 | `shots_art_2026_11_25/C_interaction.png` | 玩家会以为自己站在射击场，而不是在给飞船装货 |
| 3 | 奶龙只露**一个黄色球头 + 一只眼**，无骨骼、无四肢动作 | `C_interaction.png`、`DECISIONS.md` D-59 | 角色喜剧感为 0；Fall Guys/Pikmin 层级靠的是整身可读姿态 |
| 4 | 全工程**没有**镜头抖动 / 顿帧 / 慢放 / 球拖尾 | 全脚本 grep `shake|hitstop|time_scale|slowmo` 无结果 | 踢球与扑救只有声音和一次白闪，没有「打中了」的身体感 |
| 5 | 音频仅 **4 个音效**（`ball_kick` / `dragon_block` / `fuel_loaded` / `goal_frame`），**无音乐** | `assets/audio/` | 街机向作品没有 BGM 等于没有节奏 |
| 6 | **无手柄支持**（全脚本无 `JOY_*`） | 全脚本 grep | Steam Deck / 主机 / 客厅场景直接排除 |
| 7 | 进度只存**最高分**（`user://gulu_record.cfg`） | `GAMEPLAY_2026-11-23.md` §4 | 第二局之后没有新目标，留存断在 15 分钟内 |
| 8 | 教学全部靠**文字提示**（「左键按住蓄力，松手射门」重复 3 处） | `gulu_presentation.gd`、`gulu_app.gd` `_flash` | 上架作品靠关卡引导，不靠说明书 |
| 9 | 性能余量极大：**316–340 FPS / 1.2k DC** | `STATUS.md`、`TESTING.md` | 有余量做镜头、粒子、后期，不用怕加特效 |

**一句话诊断**：这个 demo 的**规则已经立住了**（90 秒 + 连击 + 骗守门员），缺的是**「像一个商品」的那 30%**：镜头与打击反馈、角色表演、信息设计、音频、目标层。

## 3. 八层对标（核心）

### 3.1 核心循环与结构

| 对标 | 它做对了什么 | 奶龙星现状 | 差距 | 动作（可验收） |
|---|---|---|---|---|
| Rocket League 训练场 | 把「射门」拆成可重复的**小目标**（射门 / 扑救 / 空中），每个目标 3–15 秒 | 只有一个循环：90 秒乱踢 | **B** | P0：结算页加「本局 3 个目标」——进球数、最高连击、全力抽射成功率；P1：拆出 3 个练习关（定点射门 / 骗守门员 / 连击保持），从标题屏进 |
| OlliOlli World | 连击是**可见的资源**：槽会掉、会在屏幕上爬 | 连击只体现在顶部 `x3` 与浮字 | **B-** | P0：把连击做成一枚会**倒计时收缩的环**，挂在准星右下 2 cm；窗口 10 秒可见地流走 |
| Neon White | 重开成本近乎 0（<1 秒） | 进球后 0.9 s 复位、R 整局重开 | **B+** | P0：结算页「再来一局」直接回车；保持现有 R |

### 3.2 手感与打击反馈（差距最大的一层）

| 对标 | 它做对了什么 | 奶龙星现状 | 差距 | 动作（可验收） |
|---|---|---|---|---|
| Rocket League | 每次触球都有**球体形变 + 音高随力度 + 轻微镜头推进** | 只有 `_flash` 白闪与一个 kick 音 | **D** | P0：踢球瞬间 ① 顿帧 `60 ms`（只冻球与奶龙的动画，不冻时间）② 镜头位移 `0.05 m` / `0.18 s` 回落 ③ 球拖尾 0.25 s ④ 音高按力度 `+0~+18%` |
| Windjammers 2 | 蓄力有**明确读条与顶点提示**，满蓄有质变 | 有蓄力（1.0→1.5）+ 进度条 + 「全力抽射！」 | **B+** | P0：满蓄 1.25 倍时给「枪口上抬 + 屏幕轻微位移」；P1：加**必杀槽**（3 次满蓄解锁一次「超载射门」） |
| Mario Strikers | 必杀射门是**0.5–1 秒的演出**：慢放、放大、守门员表情 | 无任何演出 | **D** | P1：全力抽射命中门框范围时，`time_scale 0.35 / 0.4 s` + FOV `50→44` + 奶龙扑救动作放大 |
| Hades | 命中 60–90 ms 顿帧是所有反馈的基座 | 无 | **D** | P0（同 RL 第一条） |

> **这一层是「为什么它不像上架游戏」的最大答案**：不需要新玩法，只需要 4 个反馈通道（顿帧 / 镜头 / 拖尾 / 音高）同时到位。

## 4. 改完后的「首 10 分钟」体验脚本

| 时间 | 玩家看到 / 感到 |
|---|---|
| 0:00–0:03 | 标题屏：游戏名 + 一行副标题 + 呼吸的「点击开始」；背景是场地实拍而非 UI 面板 |
| 0:03–0:06 | 3–2–1 倒计时，球在脚下**发光脉动**，装货口有**吸力粒子**往内流 |
| 0:06–0:20 | 奶龙**趴着睡**；玩家踢第一脚（无阻挡）→ 进球 → 全屏慢放 0.35 s + 装货口脉冲 + 首个「+100」 |
| 0:20–0:25 | 奶龙醒来，伸懒腰，走到门前（**行为教学，不用文字**） |
| 0:25–1:30 | 正式 90 秒：连击环收缩、蓄力条、被拦断连、每 2 球提档；每次扑救有顿帧 + 奶龙得意挺胸 |
| 1:30–1:40 | 结算：分数、3 个目标勾选、最高分、「再来一局 / 换个难度」 |
| 1:40–3:00 | 第二局难度 ×1.3，奶龙更快；玩家开始主动**骗站位** |
| 3:00–10:00 | 挑战清单提示「今晚目标：连击 x5」；换时段（黄昏）再打一局；尝试全力抽射 |

**验收标准**：把一个没看过说明的人放到电脑前，**不给他任何口头提示**，他能在 20 秒内踢进第一球，60 秒内自己发现「站到一侧再绕另一边」能骗过奶龙。

### P1 · 让它「有理由再玩一局」（建议 2–3 周）

- 本地挑战清单 10 条（存盘）
- 难度三档自选 + 分档最高分
- 3 个练习关（定点 / 骗守门员 / 连击保持）
- 音量三总线 + 设置页
- 30 s 预告片

### P2 · 让它「能撑住一个商店页」（视排期）

- 3 个时段预设（正午 / 黄昏 / 夜班）
- Steam 排行榜（本地 → 在线）
- 第二个场地变体（同一套规则，换构图与地貌）
- 每日挑战种子

## 5.5 玩法大改提案（建议 · 待确认）

**现在的问题不是「不够多」，是「没有决策」**：90 秒里玩家只做一件事——走到球边、对准、踢。奶龙的预判可以被同一个套路（站一侧、绕另一侧）稳定骗过，所以第 3 局之后就没有新东西可学。

提案分三条，按「改动量 ÷ 决策增量」排序：

| 提案 | 做法 | 新增的决策 | 改动量 | 风险 |
|---|---|---|---|---|
| **A. 多舱口 + 货单（推荐先做）** | 装货口拆成 3 个舱层（下/中/上），每 30 秒换一张「订单」指定值钱的那一层，命中 ×2 | 「先打哪层」「低平球还是挑高球」「奶龙站着的那层还值不值」 | 中（已完成第一版） | 低：判定仍是「球越过舱口平面」，只是多记一个高度 |
| **B. 奶龙会偷球** | 拦截成功后 35% 把球叼走 4 秒，玩家 2.5 m 内按 E 抢回（**抢回 +1 必杀槽**）；每局 2 次、冷却 8 s | 「追还是等」「它在哪片区域偷」 | 中高（AI + 交互） | ✅ 已落地，用冷却/次数/抢回收益压住「追着跑」的负体验 |
| **C. 风险射门** | 满蓄射门必进但若被扑，则奶龙进入 5 秒「得意加速」；轻推命中则连击 +0.5 层 | 「这一脚要不要冒险」 | 低（改数值与状态） | 低 |

**结构层面（三选一，建议 B 结构）**：

- A 结构：维持 90 秒单段（改动最小，节奏最平）。
- **B 结构（推荐）**：90 秒拆成 3 段 × 30 秒，每段之间 1.5 秒「换货单」定格；第 3 段奶龙提速 20%。这样一局里有三次「重新读局面」的机会，也让 90 秒不再是一条直线。
- C 结构：改成 5 波防守（每波 8 球），中间有补给；更接近塔防，改动最大。

**验收标准**：让同一个人连打 3 局，第 3 局他必须**主动做出一个第 1 局没做过的决定**（换舱口 / 放弃远射 / 冒险满蓄），否则说明决策没做出来。

## 6. 明确不做（防止范围爆炸）

| 不做 | 原因 |
|---|---|
| 多人联机 | 现有工程是单机确定性自测体系，联机要重写物理与同步，远超本项目产能 |
| 换引擎 / 换渲染管线（Forward+） | `gl_compatibility` 已跑 300+ FPS，换管线只为「更好看」会把 45+ 条回归全部推翻 |
| 给奶龙上骨骼动画 | D-59 已明确「静态模型定住」，且用户反馈过变形；用节点变换做表演（P0-5）性价比高一个数量级 |
| 抄任何 IP 形象/音乐 | 版权风险；对标只对标结构与节奏 |
| 做开放世界/自由探索 | 与本作「90 秒挑战」冲突，会把 15 分钟的完整体验摊薄 |
