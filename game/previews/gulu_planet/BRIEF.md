# BRIEF — 奶龙星第一人称试玩预览

状态：**可完整试玩的一小关**（阶段 A–F）。不是正式星球关卡，不接入航线。
分支：`feature/gulu-planet-preview`；目录：`game/previews/gulu_planet/`
引擎：Godot 4.7.2

## 1. 名称与定位

- 「奶龙星」是第四颗星球，内部原型名；生物采用奶龙形象方向。
- 本轮目标不是搭框架，而是**真人能从开场打到装货完成**的一关。
- 不修改正式星球选择、航线、主线、公共系统或其他星球。

## 2. 本轮玩法目标

```
奶龙叼着燃料 → 玩家站到装货口前挑衅 → 它靠近、蓄势、锁定 →
玩家侧移躲开 → 燃料脱口飞入收集仓
```

失败可补救：没对准就落地，捡回来再试；被扑中只掉手上的货。

两种运货方法都要有使用价值：

| 方法 | 路线 | 代价 |
| --- | --- | --- |
| 安全搬运 | 自己抱进装货口 | 路远、绕石堆；路上可能被盯上 |
| 冒险借力 | 骗它扑、把货甩进仓 | 快；要站准位置、要会躲 |

## 3. 已确认约束

- 第一人称复用共振星独立预览 `station_player.gd` 的手感；不另造控制器。
- 但**镜头必须与飞船第一人称完全一致**（用户本轮明确要求）：
  眼高 1.6、FOV 74、俯仰 ±1.25 rad、灵敏度 0.0020、near 0.05、纵向符号一致。
- 玩家模型必须与飞船/其他星球一致：同一套 `protagonist_visual` + `skin_ranger.glb`，缩放 1.0。
- 挑衅需要距离、朝向、视线；不能隔墙全场生效。
- 扑击前必须有清楚预兆，目标方向在**明确时刻**锁定，之后不追尾转弯。
- 扑击结束有恢复窗口；不能无休止追逐。
- 不穿墙、不每帧重复触发、不无规律切换目标。
- 参数集中在脚本顶部，全部标注为原型值。
- 不做漂浮 3D 文字；指引放 HUD 或实体反馈。
- 不新增饥饿、好感、技能树、装备品质等系统。

## 6. 场地

- 40×30 m 岩壁场地：船头装货口 + 停机坪 + 两条地面导引路线。
- 玩家出生 `(-9, 0.02, 6.5)` 朝 +X；奶龙窝 `(1.5, 0, -0.5)`。
- 燃料：`(1.5, -1.9)`（开场在奶龙嘴里）、`(-6.5, -7.0)`（北路）、`(-5.0, 7.5)`（南路）。
- 装货口在 x≈12.8~15.9、z ±2.05；判定用固定 AABB，比视觉开口略宽。
- 石堆 5 处可挡视线、可绕行；货箱 3 处做遮挡。
