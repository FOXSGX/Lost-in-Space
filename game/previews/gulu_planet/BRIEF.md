# BRIEF — 奶龙星第一人称试玩预览

状态：最小互动原型；不是正式星球关卡，不接入航线。
分支：`feature/gulu-planet-preview`（沿用上一轮；目录名也沿用 `gulu_planet`）
目录：`game/previews/gulu_planet/`
引擎：Godot 4.7.2

## 1. 名称与定位

- “咕噜星”本轮起在原型内改称 **奶龙星**，是现有三个星球之外的第四颗新星球。
- 阻碍玩家搬运燃料的生物原型采用**奶龙**形象；正式模型与动画未定。
- 这是现有游戏中的新增预览，不是另起一个游戏项目。
- 本轮不改正式星球选择、航线、主线流程、公共系统或其他星球。

## 2. 本轮唯一目标

验证最小互动：

```
玩家按 Q 挑衅 → 奶龙注意并靠近 → 连续挑衅后蓄势 → 扑来
→ 玩家侧移躲开 → 奶龙短暂恢复 → 玩家获得搬运窗口
```

本轮**不**实现：

- 真实燃料搬运、抢夺、叼走、追回或交换。
- 伤害、血量、结算、道具、麦克风/声音吸引、联网扩展。
- 正式奶龙模型、骨骼动画、完整关卡、正式美术。

## 3. 已确认约束

- 第一人称必须复用共振星独立预览 `station_player.gd` 的手感；
  不用飞船第一人称或正式共振星第三人称另猜一套。
- 默认第一人称；键盘鼠标必须能完成挑衅与躲避。
- 挑衅需要距离、朝向和可见条件；不能隔墙、全图生效。
- 连续挑衅逐渐上头；扑抢前必须有清楚预兆；玩家能躲开。
- 扑抢结束有恢复窗口；不能无休止追逐。
- 不穿墙、不每帧重复触发、不无规律切换目标。
- 参数集中可调，全部标注为原型数值。
- 不新增漂浮 3D 文字；指引放 HUD 或实体表现。

## 6. 当前场景

- 32×26 m 灰盒：地板、舱壁、箱子、低台、碰撞墙、视线测试柱。
- 玩家出生 `(-8, 0.02, 0)`，朝 +X；奶龙在 `(2, 0, -3.5)`，燃料在 `(5, 0, 3)`。
- 奶龙是程序化奶油色占位模型 + 状态环；行为与外观分离。
- HUD：操作、视角、奶龙状态、上头条、短提示、F3 调试。
