## D-03 挑衅按键选择 Q
- 排除 WASD、Shift、Tab、R、F3、F4、F1、Esc、鼠标左右键、H、E。
- 选择 **Q**：不与视角/移动/拾取冲突，单手可反复按。
- 只有 `InputEventKey` 按下且非 echo 才触发；控制器侧 0.7 s 冷却。
- 玩家必须在 9 m 内、相机前方 ±55°、且与奶龙之间无墙体遮挡。

## D-04 最小状态机
- 状态：待机 → 找燃料 → 注意 → 靠近 → 蓄势 → 扑击 → 恢复 → 回窝。
- 注意 0.55 s：转向玩家、状态环变青（仅调试）。
- 靠近 2.7 m/s，停靠 2.3 m；超 9 s / 13 m / 失去视线就回窝。
- 上头：每次 +0.34，停手 1.2 s 后按 0.10/s 衰减；到 0.95（通常第 3 次）进入蓄势。
- 蓄势 1.0 s：压低身体、抖动、HUD 红色预警。
- 扑击 0.42 s、11 m/s：只朝锁定点直线移动，不转向追踪。
- 恢复 1.5 s：不响应挑衅，结束后回待机并清零上头。
- 命中判定 1.25 m；本轮无伤害。

## D-05 不穿墙、不每帧触发、不切换目标

- 目标只有当前玩家，因此不存在随机切换。
- Q 用事件 + 冷却，不是 `_process` 轮询。

## D-16 玩家模型缩放 1.0

- 上一轮预览照抄了 0.78；本轮改为 1.0，使奶龙星与飞船/其他星球一致。

## D-17 蓄势开始即锁定扑击目标（而不是蓄势结束）
- 原因：若在蓄势结束时才取玩家位置，玩家在 1.0 s 预兆期间侧移会被「重新瞄准」，
  等于无法靠预兆躲避，也违反「明确时刻锁定、之后不追尾」。
- 选择：`_begin_windup()` 记录 `_pounce_target`；蓄势期间朝向锁定点；
  扑击阶段只朝该点直线推进。
- 效果：预兆期间侧移 → 一定躲开；扑击结束位置 = 玩家被锁定时的位置，
  燃料也从那里向前抛出，形成可学习的「站位 → 侧移」技巧。

## D-18 燃料释放用可控抛物线，不用刚体
- 需求原文：释放使用可控方向和速度，避免不可预测的高速物理碰撞。
- 选择：`FuelProp` 是 `CharacterBody3D`，抛出后自行积分
  （水平 7.2 m/s、上抛 3.4 m/s、重力 18、少量旋转），落地后恢复可拾取。
- 落点约在释放点前方 4.2 m；配合装货口 3.1 m 深的 AABB 判定，
  容错约 ±1.5 m，不需要像素级瞄准。
- 撞墙/斜面时水平速度快速衰减，避免弹飞或卡进几何体。

## D-19 装货口判定用固定 AABB + 漏斗斜面
- `collector.gd` 的 `CATCH_MIN/MAX` 是常量，比视觉开口宽一点。
- 视觉上是两侧 24° 斜面 + 0.22 m 门槛（步进辅助可跨过），
  让「差一点」的投掷也能被引导进去。
- 入仓只计一次：`FuelProp.collected` 与 `mode == "loaded"` 双重保护；
  重复 `consume()` 直接返回。
- 重开时 kill 入仓 Tween，避免动画把已复位的燃料又拉回仓里（本轮实测踩到过）。

## D-20 奶龙叼货与找燃料规则
- 嘴部挂点 `MouthAnchor`（头部子节点），燃料作为世界空间跟随体，
  不做物理咬合。叼着时罐子横卡在嘴里，一眼可见。
- 找燃料：8 m 内、无遮挡、且不在装货口附近（x > 10.8 不捡）。
  后者避免它把已经送到门口的货又叼回去。
- 叼货期间仍可被挑衅，上头增速提高到 +0.42（它更护食），
  让「先让它叼起来再骗它扑」比机械按三次更快。

## D-21 声音：本地合成，不引入第三方音频
- 5 个 WAV 由 `tools/audio/make_sfx.py` 用 Python 标准库生成
  （正弦/噪声 + 包络），22050 Hz 单声道 16-bit。
- 可复现、来源明确、许可无障碍；不使用网络热梗录音。
- 每种音有最短间隔；失败/命中不叠加播放。

## D-22 场景配色对齐飞船，而不是另起一套风格
- 取自 `ship_hub_3d.gd`：壳体 `#c4d2d0` 系、结构 `#375967`、

# 第二轮打磨（2026-10-29 晚）

## D-23 上头增量按情境，不再固定三次 Q
- 叼着货 **+0.50**（2 次就到阈值）；你抱着燃料 **+0.42**；空嘴空手 **+0.34**；阈值 0.95；冷却 0.7→**0.65 s**。
- 目的：把「原地按三次 Q + 横移」的机械循环换成“看情境按 1~3 次”。
- 保留单次 Q，不引入长按。

## D-24 够得着才扑：蓄势前先确认射程
- 新增 `_windup_reach() = pounce_speed * pounce_time - 0.4`（≈4.2 m）。
- 上头已满但距离超过射程时不再原地蓄势，而是 `_pending_windup = true` 继续靠近，靠近后立即蓄势。
- 目的：消除“在够不到玩家的位置扑空”的假动作（用户本轮点名的问题）。

## D-25 锁定时刻可视化：地面红圈
- `MilkDragon` 发出 `windup_locked(point)` / `pounce_ended(point)`；
  app 侧的 `PounceLockMarker` 在锁定点画一圈 0.98 m 的红环 + 四根短刻线，蓄势期间脉动，扑完淡出。
- 不靠文字：玩家看到圈就知道“这块地要被扑了”，走开即可。
- 自检覆盖：蓄势时标记可见且位置误差 < 0.4 m。

## D-26 装货口是卸货区，不是掩体
- app 侧：玩家 x > 11.2（舱口内）时挑衅直接拒绝，提示“它不肯冲进装货口”。
- 奶龙侧：`loading_zone.contains_point(player)` 为真时不做抢货。
- 目的：消除“躲在舱口里零风险完成全部装货”。

## D-27 抢货：有预警、有冷却、不掉血
- 触发：你抱着燃料、它空着嘴、距离 ≤ 2.1 m、持续 0.75 s；冷却 4 s。
- 表现：伸长脖子 + 张嘴（`set_snatch`）、咀嚼音、HUD 警告。
- 目的：让“安全搬运”真的有代价，也给“被抢→骗它扑→送进仓”这条链一个入口。
- 不新增血量/死亡；被抢只失去手上的货物。

## D-28 装货容错再加一层：漏斗内横向引导
- 容错盒扩到 `x 12.45–15.90, z ±2.40`；
- 抛出物进入 `x 12.0–16.2, |z| < 3.2` 后获得向中线 `7.0 m/s²` 的横向加速度（视觉上就是斜面把它引进去）。
- 目的：把“借力装货”从像素级矦准变成“大致站在舱口前 4 米”就能成。

## D-29 多人的最小接口（不做联网）
- `MilkDragon.setup_actors([...])` + 每 0.3 s `_pick_target()`：取最近、看得见的目标，不再写死单个节点；
  看不到任何人时保留当前目标（避免每帧切换）。
- `FuelProp.carrier` / `credit_peer`，`FuelCollector.last_credit_peer`：交付归属可追溯。
- 没有任何网络代码；不声称多人已验证。

## D-30 天空与地面环：两个画面级 bug
- `fog_sky_affect` 默认 1.0，指数雾把 BG_COLOR 整片染成浅灰 → 改用 `ProceduralSky`，
  `fog_sky_affect = 0.15`；过曝从 10.4% 降到 0.5%。
- `TorusMesh` 默认就躺在 XZ 平面，之前多余的 `rotation.x = PI/2` 让地面环全竖着 → 去掉。
- 手持燃料不显示地面光环，其 OmniLight 从 0.35 降到 0.10（否则半个屏幕发琥珀）。
