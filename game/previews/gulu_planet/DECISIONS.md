## D-03 挑衅按键选择 Q
- 排除 WASD、Shift、Tab、R、F3、F4、F1、Esc、鼠标左右键、H、E。
- 选择 **Q**：不与视角/移动/拾取冲突，单手可反复按。

- 玩家必须在 9 m 内、相机前方 ±55°、且与奶龙之间无墙体遮挡。

## D-04 最小状态机
- 状态：待机 → 找燃料 → 注意 → 靠近 → 蓄势 → 扑击 → 恢复 → 回窝。
- 注意 0.55 s：转向玩家、状态环变青（仅调试）。
- 靠近 2.7 m/s，停靠 2.3 m；超 9 s / 13 m / 失去视线就回窝。
- 上头：每次 +0.34，停手 1.2 s 后按 0.10/s 衰减；到 0.95（通常第 3 次）进入蓄势。
- 蓄势 1.0 s：压低身体、抖动、HUD 红色预警。
- 扑击 0.42 s、11 m/s：只朝锁定点直线移动，不转向追踪。
- 恢复 1.5 s：不响应挑衅，结束后回待机并清零上头。
- 命中判定 1.25 m；本轮无伤害。

- 目标只有当前玩家，因此不存在随机切换。
- Q 用事件 + 冷却，不是 `_process` 轮询。

## D-16 玩家模型缩放 1.0

## D-17 蓄势开始即锁定扑击目标（而不是蓄势结束）
- 原因：若在蓄势结束时才取玩家位置，玩家在 1.0 s 预兆期间侧移会被「重新瞄准」，
  等于无法靠预兆躲避，也违反「明确时刻锁定、之后不追尾」。
- 选择：`_begin_windup()` 记录 `_pounce_target`；蓄势期间朝向锁定点；
  扑击阶段只朝该点直线推进。
- 效果：预兆期间侧移 → 一定躲开；扑击结束位置 = 玩家被锁定时的位置，
  燃料也从那里向前抛出，形成可学习的「站位 → 侧移」技巧。

## D-18 燃料释放用可控抛物线，不用刚体
- 需求原文：释放使用可控方向和速度，避免不可预测的高速物理碰撞。
- 选择：`FuelProp` 是 `CharacterBody3D`，抛出后自行积分
  （水平 7.2 m/s、上抛 3.4 m/s、重力 18、少量旋转），落地后恢复可拾取。
- 落点约在释放点前方 4.2 m；配合装货口 3.1 m 深的 AABB 判定，
  容错约 ±1.5 m，不需要像素级瞄准。
- 撞墙/斜面时水平速度快速衰减，避免弹飞或卡进几何体。

## D-19 装货口判定用固定 AABB + 漏斗斜面
- `collector.gd` 的 `CATCH_MIN/MAX` 是常量，比视觉开口宽一点。
- 视觉上是两侧 24° 斜面 + 0.22 m 门槛（步进辅助可跨过），
  让「差一点」的投掷也能被引导进去。
- 入仓只计一次：`FuelProp.collected` 与 `mode == "loaded"` 双重保护；
  重复 `consume()` 直接返回。
- 重开时 kill 入仓 Tween，避免动画把已复位的燃料又拉回仓里（本轮实测踩到过）。

## D-20 奶龙叼货与找燃料规则
- 嘴部挂点 `MouthAnchor`（头部子节点），燃料作为世界空间跟随体，
  不做物理咬合。叼着时罐子横卡在嘴里，一眼可见。
- 找燃料：8 m 内、无遮挡、且不在装货口附近（x > 10.8 不捡）。
  后者避免它把已经送到门口的货又叼回去。
- 叼货期间仍可被挑衅，上头增速提高到 +0.42（它更护食），
  让「先让它叼起来再骗它扑」比机械按三次更快。

## D-21 声音：本地合成，不引入第三方音频
- 5 个 WAV 由 `tools/audio/make_sfx.py` 用 Python 标准库生成
  （正弦/噪声 + 包络），22050 Hz 单声道 16-bit。
- 可复现、来源明确、许可无障碍；不使用网络热梗录音。
- 每种音有最短间隔；失败/命中不叠加播放。

## D-22 场景配色对齐飞船，而不是另起一套风格
- 取自 `ship_hub_3d.gd`：壳体 `#c4d2d0` 系、结构 `#375967`、

# 第二轮打磨（2026-10-29 晚）

## D-23 上头增量按情境，不再固定三次 Q
- 叼着货 **+0.50**（2 次就到阈值）；你抱着燃料 **+0.42**；空嘴空手 **+0.34**；阈值 0.95；冷却 0.7→**0.65 s**。
- 目的：把「原地按三次 Q + 横移」的机械循环换成“看情境按 1~3 次”。
- 保留单次 Q，不引入长按。

## D-24 够得着才扑：蓄势前先确认射程
- 新增 `_windup_reach() = pounce_speed * pounce_time - 0.4`（≈4.2 m）。
- 上头已满但距离超过射程时不再原地蓄势，而是 `_pending_windup = true` 继续靠近，靠近后立即蓄势。
- 目的：消除“在够不到玩家的位置扑空”的假动作（用户本轮点名的问题）。

## D-25 锁定时刻可视化：地面红圈
- `MilkDragon` 发出 `windup_locked(point)` / `pounce_ended(point)`；
  app 侧的 `PounceLockMarker` 在锁定点画一圈 0.98 m 的红环 + 四根短刻线，蓄势期间脉动，扑完淡出。
- 不靠文字：玩家看到圈就知道“这块地要被扑了”，走开即可。
- 自检覆盖：蓄势时标记可见且位置误差 < 0.4 m。

## D-26 装货口是卸货区，不是掩体
- app 侧：玩家 x > 11.2（舱口内）时挑衅直接拒绝，提示“它不肯冲进装货口”。
- 奶龙侧：`loading_zone.contains_point(player)` 为真时不做抢货。
- 目的：消除“躲在舱口里零风险完成全部装货”。

## D-27 抢货：有预警、有冷却、不掉血
- 触发：你抱着燃料、它空着嘴、距离 ≤ 2.1 m、持续 0.75 s；冷却 4 s。
- 表现：伸长脖子 + 张嘴（`set_snatch`）、咀嚼音、HUD 警告。
- 目的：让“安全搬运”真的有代价，也给“被抢→骗它扑→送进仓”这条链一个入口。
- 不新增血量/死亡；被抢只失去手上的货物。

## D-28 装货容错再加一层：漏斗内横向引导
- 容错盒扩到 `x 12.45–15.90, z ±2.40`；
- 抛出物进入 `x 12.0–16.2, |z| < 3.2` 后获得向中线 `7.0 m/s²` 的横向加速度（视觉上就是斜面把它引进去）。
- 目的：把“借力装货”从像素级矦准变成“大致站在舱口前 4 米”就能成。

## D-29 多人的最小接口（不做联网）
- `MilkDragon.setup_actors([...])` + 每 0.3 s `_pick_target()`：取最近、看得见的目标，不再写死单个节点；
  看不到任何人时保留当前目标（避免每帧切换）。
- `FuelProp.carrier` / `credit_peer`，`FuelCollector.last_credit_peer`：交付归属可追溯。
- 没有任何网络代码；不声称多人已验证。

## D-30 天空与地面环：两个画面级 bug
- `fog_sky_affect` 默认 1.0，指数雾把 BG_COLOR 整片染成浅灰 → 改用 `ProceduralSky`，
  `fog_sky_affect = 0.15`；过曝从 10.4% 降到 0.5%。
- `TorusMesh` 默认就躺在 XZ 平面，之前多余的 `rotation.x = PI/2` 让地面环全竖着 → 去掉。
- 手持燃料不显示地面光环，其 OmniLight 从 0.35 降到 0.10（否则半个屏幕发琥珀）。

# 第五轮：抢货读感 + 借力反馈（2026-11-10）

## D-38 抢货必须有“看得见的预兆”，且不能隔墙发生
- 抢货计时只在 **有视线** 时累计（`_last_los`）；视线一断就以 2.4 倍速度回落，
  所以绕到石头/货箱后面能真的摆脱，而不是“隔着障碍被抽走”。
- 预兆分三层传达，覆盖三个视距：
  1. 身体：前倾 + 伸脖子（`_facing` 轴向拉伸 9%）+ 张嘴；
  2. 声音：`dragon_snatch_warn.wav`（低吼下滑，0.32 s），在进度 45% 时播一次；
  3. HUD：提示条 + 进度条（剩余秒数直接写在文字里）。
- 为什么不是只加长计时：单纯拉长只会变成“站在那里等”，预兆必须同时改变
  **角色姿态**与**屏幕信息**，玩家才知道“现在该退”。

## D-39 数值：预兆 0.95 s、捡起保护 1.1 s
- 玩家步速 5.8 m/s（Shift 1.65 倍）；抢货半径 2.1 m。
  0.95 s 内后退 1 m 就脱离半径，留出“看得见 + 来得及”的余量；原来 0.75 s 只剩 0.3 s 余量，偏紧。
- 捡起保护 1.1 s：专门解决“刚夺回又被抢”——它不是难度参数，是节奏参数。
  刚被抢后奶龙也把货吐了/叼走了，4 s 冷却仍在，不会变成连续惩罚。
- 自测里对应两条：`pickup grace blocks an instant snatch`、`no snatch through a wall`；
  并用临时 6 m 宽墙做黑盒验证（不靠改内部状态）。

## D-40 扑空的喜剧反应只做表演，不延长等待
- 扑空 → `stun_time = 0.85 s`：头歪、身体偷看一下，视线钉在装货口（`intake_point()`）。
- 恢复窗口仍是 1.25 s，`stun` 完全落在里面；玩家可操作时间不变。
- 不新增状态机分支：复用 `STATE_RECOVER` + 一个 `_stun_timer`，
  外观层用 `set_dazed(bool)` 接，占位外观也实现了同名接口。

## D-41 路线去箭头化：靠痕迹和一处真实遮挡
- 原来两条 1 m 长的发光色块（青 9 段 / 琥珀 8 段）读起来像 UI 箭头，已删除。
  换成：两道磨暗车辙（无发光）+ 5 枚铜钉 + 穿场线的浅拖痕。
- 绕行线新增货箱垤（`(-5.6, 3.1)` 附近 4 个箱子）：挡住从奶龙窝到绕行线西段的一段视线，
  但往东走 3 m 就会被看见 —— “有限遮挡”，不是永久安全区。
- 自测用两条射线钉住这个性质：
  `outer route has a covered stretch` / `outer route is not a permanent hiding strip`。

## D-42 录像用脚本连续截图合成，必须标注非真人
- Godot 无内置录制；新增 `--record`：每 0.125 s 抓一帧到 `user://gulu_record`，
  再由 `tools/record_video.py`（ffmpeg + Pillow）合成 MP4/GIF。
- 录像里的操作是脚本按键（`Input.action_press`），只能证明**功能与可读性**，
  不能证明“玩家觉得好玩”；交付时在文件名与文档里都写明。
- 自动检查同理：81 条断言只能证明“不会卡死/不重复计数/能完成”，不代替手感评价。

# 第六轮：玩法换轨为足球式踢球（2026-11-10）

## D-43 新玩法覆盖旧玩法，不混用两套规则
- 用户明确：本轮以「踢球进门」为准，覆盖搬运/挑衅/怒气/诱导扑击。
- 删除 uel_prop.gd、milk_dragon_visual.gd；gulu_app.gd 启动时主动清掉
  provoke / interact 的动作绑定，避免两套输入同时存在。
- 旧代码保留在 git（94958b0 及以前），文档里标为历史，**不再维护**。

## D-44 球用 CharacterBody3D 自己积分，不引入物理引擎/插件
- 只做地面球：无重力、无弹跳、无旋转球。elocity 只含 XZ，y 固定为半径。
- 每帧  *= exp(-FRICTION * dt)，低于 0.30 m/s 直接归零（停得住、不抖）。
- 碰撞：move_and_slide 后遍历 get_slide_collision，按法线 ounce 并乘 0.72；
  法线 y > 0.7（地面）不反弹，避免贴地抽动。
- 滚动由位移驱动（转角 = 位移 / 半径），不是贴图滑动。
- 为什么不用 RigidBody3D：需要可预测的「停球后好再踢」「不无限加速」「边角不抖」，
  手动积分比调物理材质更容易保证手感；以后要重力/高空球时只换本文件。

## D-45 守门奶龙必须能被击败：射门瞬间「先扑再说」
- 只跟球、不追玩家；守门区 x 8.5..11.6, |z| ≤ 2.7（球门口 z ±2.4 之外留一点）。
- 反应延迟 0.24 s、最大速度 2.9 m/s、加速度 14，目标 = 球与球门中心之间。
- **关键**：检测到球速 > 9 m/s 时，冻结目标点 commit_time = 0.32 s。
  它按射门前的判断扑出去，这 0.32 s 内不修正 —— 所以打反方向能过。
  没有这条，奶龙会一直「贴着球线」，任何角度都会撞上它（实测多次）。
- 拦球半径 0.95（球心到奶龙中心），冷却 0.55 s，防止贴脸连击；
  球贴住且速度 < 0.8 时每帧轻推 1.1 m/s 离开身体，避免压死。

## D-46 左键：鼠标没锁定时，第一下只锁鼠标
- 需求原文：「点击收回鼠标时不要误触发射门」。
- 实现放在 gulu_app.gd::_input（早于 _unhandled_input）：
  未捕获 → 设 MOUSE_MODE_CAPTURED 并 set_input_as_handled()；已捕获 → 才踢。
- 控制器自身也会读 capture_mouse，所以保留该动作但不挂具体行为。

## D-47 装货口为「球」做的两处几何调整（不动判定 AABB）
- 入口 0.22 m 实心门槛 → 贴地 0.02 m 标线（无碰撞）。旧门槛是为挡燃料，现在会挡球。
- 两侧接货斜面从 z ±2.45 外移到 ±2.95：原位置正好压在球门口内侧，
  实测会把已经进门的球弹回场内（录到过 max_x=7.8 的诡异回弹）。
- CATCH_MIN/MAX 未改；门框立柱仍是实体，打外侧仍然弹开、不计分。

## D-48 角色动画：先修「看起来假」的三件事，不做重建
- 检查结论：不是网格/材质问题，是**表演层**问题——整体缩放 + 贴地滑动 + 瞬转。
- 修法：删掉 _body.scale 挤压；步频随速度（gait += dt*(3+5*speed01)），
  大腿/小腿/脚掌骨骼反相摆动，手臂反摆；身体只保留 ≤0.01 m 起伏与前倾。
- 转身放在行为层 lerp_angle(6 rad/s)，模型不再自己扭。
- 拦球动作：双臂张开 + 前倾 0.16 rad，持续 0.42 s，不改骨架、不加下颚骨。
- 骨骼限制如实记录：无下颚骨、无尾骨；张嘴仍用头部下压代替（本轮不需要张嘴）。

# 第七轮：真刚体 + 四状态守门员（2026-11-10）

## D-49 球改成 RigidBody3D，踢球只加冲量
- 上一版是 CharacterBody3D + 手写位移/反射/滚动，属于「看起来像物理」，本轮废弃。
- 现在：球形碰撞体 r=0.34、mass 1.2、linear_damp 0.45、angular_damp 0.55、
  PhysicsMaterial friction 0.7 / bounce 0.5、continuous_cd = true、can_sleep = true。
- 踢球用 pply_central_impulse()，不设位置、不覆盖速度、不手写旋转；
  低速不归零，靠阻尼 + 物理休眠自然停下。
- **坑**：对休眠刚体直接 pply_central_impulse() 会被吞掉。改为记 _pending_impulse，
  在 _physics_process 里统一施加（实测球速从 0.03 变成 13+ m/s）。
- 出界只在真的掉出世界时复位；「停 3.5 s 回玩家面前」是错误设计，已删。

## D-50 进球判定：球心越过门口平面，而不是「碰到门口范围」
- 旧版 contains_point 在球刚接触门口时就可能触发，且从上方/侧袋进入也难排除。
- 现在装货口监听一颗球，比较前后两帧 x：prev.x < 12.45 && cur.x >= 12.45，
  且 y ∈ (0, 2.30)、|z| ≤ 2.40。等价于「整球从场内穿过有效门洞（以球心为准）」。
- 逐帧比较 x 轴，高速球也不会漏；从一个方向越线才算，往回退、从上方落下都不算。
- 门框立柱仍是实体，外侧碰撞只反弹不计分（自测有专门两条）。

## D-51 奶龙改成四状态，出击由「到达时间 + 落点」决定
- 观察 / 拦截 / 恢复 / 回防，不再有 speed>9 就冻结 0.32 s 这种单条件触发。
- 出击条件：球朝门来（vx>2）、eta=(goal_x-ball.x)/vx < 1.5、预测落点 |z|<3.4、
  速度方向与「球→门」夹角 <70°。朝远处滚的球不会触发出击。
- 出击后目标锁定 intercept_time=0.5 s，冷却 intercept_cooldown=2.2 s；
  扑空后有 
ecover_time=0.7 s 站着不动，再回防。
- 站位：x≈11.1（门线前 1.3 m），z 按「球远近」在中路与近角之间插值
  （closeness=(ball.x-9)/3）。实测「一直站在球与门连线上」会把任何角度都堵死。
- 速度 1.6 / 2.4 m/s、加速度 14、转向 5 rad/s（按 delta 截断）——符合「速度与反应有限」。

## D-52 双重反弹的修法：物理归物理，拨球归拨球
- 球撞到奶龙身体：完全由引擎处理（胶囊 + bounce），代码里**不再反射速度**。
- 「主动拨球」是独立动作：只在 拦截 状态、距离 <0.95 m、球朝门来、冷却 0.8 s 时
  施加一次 5.4 N·s 冲量。因此同一次接触不会既反射又加冲量。
- 自测用两条钉住：keeper swats the ball once per contact、
  contact with the keeper does not add energy (peak < 20)。

## D-53 踢球距离与遮挡
- 2.7 m → **1.9 m**：上一版看起来像「隔空踢球」。1.9 m ≈ 玩家胶囊 0.4 + 球 0.34 + 一步。
- 增加视线检测：从玩家胸口到球的射线（mask = 场景 | 奶龙），命中点离球 >0.15 m 视为挡住。
- 提示只在「距离够 + 有视线」时出现（底部提示条）。

## D-54 动画：步态由位移驱动，转向由角速度限制
- _gait += speed * delta * 2.6：停步即停摆，不再用固定的 sin(time)。
- 膝盖只在摆动相弯曲（max(0, sin)*phase），脚掌按 -(thigh*0.85 + knee*0.45) 回正，
  支撑相尽量贴地。
- 转身在行为层：
otation.y += clamp(diff, -max_turn_rate*delta, +max_turn_rate*delta)，
  **不是** lerp 系数（上一版文档写错过，已更正）。
- 拦球姿势由 set_block 权重驱动，与拨球信号同一帧触发。
