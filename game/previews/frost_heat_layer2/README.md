# 霜烬星 · 第2层热源融冰

双击本目录 [play.cmd](play.cmd) 启动，或用Godot4打开 `preview.tscn` 按F6。原开放第1层保留；本轮只有一个新环境机制。

停机坪前的右侧检修口被薄冰封住。观察热风机、管线和固定在操作柱上的图片，靠近看向手柄，**按住E供热**。启动后可以转头看冰如何变化。松开E或走远会停机，已经融开的部分保留；回来继续即可。完整融开基础约8秒，融开后无需继续按住，能够单人穿过。

不必等到100%才尝试通行：观察实际开口，融开到约一半时，侧边已经可以走过去，残余冰仍留在头顶。停机后开口保持；也可以继续供热，把整个入口融宽。

也可以直接走外围侧门进入遗迹，完全不操作热源。冰封通道缩短路程，但需要停下供热；安全绕行不花操作时间。原内侧开启的返程门仍独立可用。

WASD移动，鼠标环视，Shift加速；短空格跳跃、长空格推进；Tab切换手持/装备，1、2或滚轮选格，G放下/卸装，左键安装手持瓶。E操作其他设施。Esc暂停操作/释放光标，再按继续；F5重开；Alt+F4或窗口关闭。

5HP和五格HUD、两个手持格、两个装备格、现有氧气与推进资源保持。无新消耗品，无热伤害，无重新结冰，不写正式存档。图片是贴在实体柱上的标识，未新增悬浮文字。

本轮为离线本机主机预览。环境融化状态只由主机更新；正式联网状态广播、加入/掉线、远征接入留第4层。设计上可由一人供热、另一人观察或进入，但本轮不声称已完成真实多人验证。

候选观测站布景仍不是确定剧情。第3层目标/奖励/物件故事和第4层正式远征仅留计划。请反馈：是否能看懂冰封原因、是否愿意走近路，以及供热过程是否只是等待。
