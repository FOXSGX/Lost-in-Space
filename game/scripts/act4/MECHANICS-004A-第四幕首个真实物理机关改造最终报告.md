## 四、机械结构与动力学

支架（`cradle.gd`，每个支架一套）：

| 部件 | 结构 | 物理作用 |
|---|---|---|
| 承托面 `SeatFloor` | `StaticBody3D`，0.92×0.06×0.92，layer 1 | 晶体靠重力站立的真实支撑（新增） |
| 锁爪 ×2 `Fork/Jaw_0/1` | 枢轴 + 爪体 0.14×0.30×0.52 + `StaticBody3D`（layer 1） | 沿叉口局部 x 对称滑动，闭合夹持（新增） |
| 棘爪 `Pawl` | 钢爪，锁定后落位 | 机械保持的视觉与状态 |
| 指示环/灯 | 原样 | 绿=对齐锁定，红=夹住但 yaw 不对，橙=待夹 |

**运动与限位（1 自由度对称夹钳，带明确行程/接触）**

```
jaw_x：0.62 m（张开） → 0.26 m（空叉口硬止挡），速率 0.22 m/s
接触限位：jaw_floor = 0.34（晶体半径）+ 0.07（爪半厚）− 0.002 = 0.408 m
pressing = 叉口里有晶体 且 jaw_x ≤ 0.408 + 0.006
latched  = 螺杆走到 floor 且 pressing（棘爪落位）
locked() = latched 且 晶体在叉口（≤0.30 m / ≤0.26 m）且 yaw 偏差 ≤ 30°
```

**任务状态只读机械事实**：`game.gd` 的 `_relay_ready()` 依赖 `cradle.aligned and occupied`，
而 `aligned` 只在**棘爪落位那一刻**由 `_yaw_aligned()` 决定（放下时不点亮）。

## 十、尚存限制（如实列出）

1. **锁爪是运动学执行器**（带真实碰撞体的 `StaticBody3D`），螺杆没有柔性扭矩求解；
   夹持力来自“爪面压入晶体 2 mm + Jolt 接触”，不是弹簧/螺纹动力学。
2. **晶体没有被真正“插入”**：它是从上方落进叉口的，靠承托面站立；没有导轨、导向锥或插拔阻力。
3. **yaw 容差仍是原设计的 30°**（未改），只是现在由棘爪落位那一刻读取。
4. **叉口外观改变**：原来的装饰性固定爪改为两只可动锁爪（尺寸略变），这是机械化的必要视觉调整。
5. **货运平台与出口门未改**：出口门仍是剧情触发的 Tween 抬升，已记录为下一候选。
6. **联机未验证**：支架的锁爪状态没有进入 `net_state`；网络专项仍暂停。
7. **第四幕内置 smoke-play 的 `mouse_captured` 在无头模式为 false**（环境限制，非回归）。
8. **真人手感验收未做**。
