# MECHANICS-001B-R2 追加（第 14 轮）：几何阻挡挂钩的失败与下一步精确设计

> 正式关卡状态：`MECH001A_DONE failures=0`、`RESULT failures=0 completion=true`（可玩）
> 001B 专项：12 项中 9 通过；B5/B6/B7（反向拉力）仍失败 —— 这是本任务唯一未达标的机械项。

## 1. 本轮做了什么

按上一轮结论，给锁爪加了一个**下挂钩**（`CollisionShape3D` 0.46×0.34×0.10，局部 `(-0.66,-0.22,0.42)`），
意图是闭合后挂在模块**后侧面**上，用实体几何挡住 +Z 方向的拔出（不靠摩擦）。

实测失败：
```
B2 锁爪由电机真实转到锁止角  |  0.001 → 0.100 rad（第 -1 帧）
```
**挂钩自身在锁爪下摆时先撞上模块顶面**，把锁爪卡在 0.100 rad，永远到不了锁止角，
连带 B3/B4/A4 一起失败。已回退挂钩，恢复上一版（压顶式）的状态。

## 2. 失败的精确原因（几何算得出来）

| 量 | 值 |
|---|---|
| 支点 | `(5.27, 2.30, -4.95)` |
| 模块 | 中心 `(4.25, 1.34, -5.02)`，1.10×1.00×1.02 → 顶面 y=1.84，**后侧面 z=−4.51** |
| 锁爪臂 | z 方向跨度 −5.40…−4.50（厚 0.90，中心 −4.95）→ 臂的 +Z 边缘 z=−4.50，**正好贴着模块后侧面** |
| 挂钩 | 挂在臂的 +Z 边缘（局部 z +0.42，世界 z ≈ −4.53），底部 y≈1.74 < 模块顶 1.84 |

挂钩的 z 位置是对的（正好在模块后侧面），但它的**高度**与模块顶面重叠，
且锁爪"打开位"就是水平（角度≈0），此时挂钩已经在最低点 —— 所以它一边下摆一边顶到模块顶，
既挡不住（还没来得及到位），又卡死锁爪。

## 3. 下一步的精确设计（参数已算好，可直接实现）

**打开位要抬高，闭合位才是"挂钩落下"。**

1. **打开位 = −0.34 rad**（臂向上抬 19°）→ 挂钩底部抬到 `2.30 − 0.22 − 0.17 + 1.08·sin(0.34) ≈ 2.27`，
   高于模块顶 1.84，完全让开；
2. **闭合位 = 0.00 rad**（臂水平）→ 挂钩底部落到 `1.74`，位于模块后侧面（z≈−4.53）外侧，
   **不与模块顶面相交**（因为它的 z 在模块外面），此时模块沿 +Z 一移动就会被挂钩实体挡住；
3. 电机方向（已实测符号）：`+1.25` 使角度**减小**、`−1.25` 使角度**增大**；
   - 闭合：从 −0.34 → 0，角度增大 → 目标速度 **−1.25**；
   - 打开：0 → −0.34，角度减小 → 目标速度 **+1.25**；
4. 判据：`at_target` = 闭合 且 角度 ≥ −0.06；`clamp_locked()` = 上述条件 且 `_touching_module()`；
5. 测试窗口同步改成 **−0.06…0.10 rad**（`mech001b_latch` 的 B2/B3/A4 判据）。

预估效果：模块 +Z 位移上限 ≈ 0.02 m（挂钩与后侧面几乎贴合），B6 应能通过 `d6 < 0.10`。
