## 二、R1 锁止失败的最终机械结论（本轮已修正）

R1 的棘爪是**绕 Z 铰链摆动**的臂。鼓齿的推力是**切向**，而臂的旋转恰好也让它沿切向让开
→ 鼓齿把棘爪"顺着它唯一的自由度"推走，止挡只是一块小方块，臂能从旁边滑过。

**本轮改用「径向销爪 + 静态导槽」：**

| 元素 | 作用 |
|---|---|
| 销爪 `RigidBody3D` 2 kg，0.36×0.10×0.12 | 只能沿 **X（径向）** 滑动 |
| 上下两片静态导槽（y=±0.085，位于半径 0.44–0.62） | **承受鼓齿的切向推力**（力的方向与销爪行程垂直 → 推不走） |
| 齿圈鼓 4 kg，4 齿位于半径 0.34（45/135/225/315°） | 齿从 0.28–0.40 扫过；销爪伸到半径 0.19–0.28 → **齿必然撞上销爪侧面** |
| 销爪伸入 = 双向锁止 | 齿从任一方向扫过都被销爪正面挡住 → 真正的**双向**停车制动 |

传力路径：**鼓齿 → 销爪侧面 → 导槽（静态）→ 支架**，与任务 §4.1 要求完全一致。
释放：执行器沿 −X 抽销爪 0.14 m；抽出方向与切向载荷**垂直**，载荷不阻碍释放。

## 四、接入正式第一幕：**未成功**（本轮 NO-GO 的原因）

把台架机构做成 `Act1ParkingBrake` 并放到正式场景的发车平台（6.9, 1.62, −49.35）后：

```
act1_solo_full_run → RESULT failures=7 completion=false
首条失败：FAIL parking brake released
后续级联：cargo restraint locked / departure interlock / rider attached / cart travelled / completion / handoff
```

即：**场景里按 E 之后销爪没有抽出来**（`pin_travel` 到不了 0.10 m），停车制动无法解除，发车链路全断。
台架里同样的代码与几何是正常的，因此差异在**场景侧**，最可能的三条：

1. 发车平台在该位置有**既有几何**（栏杆/立柱/踏板）与导槽或销爪重叠，把销爪夹死；
2. 销爪生成时与场景静态体相交 → 被求解器顶住；
3. 该处在玩家交互距离外的遮罩/碰撞层组合不同。

这条正是任务 §7 警告过的"台架与正式关卡必须一致"。

并把本轮全部成果归档。
