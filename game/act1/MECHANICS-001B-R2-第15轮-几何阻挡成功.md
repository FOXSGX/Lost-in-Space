# MECHANICS-001B-R2 追加（第 15 轮）：几何阻挡成功，出现新的横向楔紧问题

> 正式关卡：`MECH001A_DONE failures=0`、`RESULT failures=0 completion=true`（可玩）
> 001B 专项：12 项中 **10 通过**、2 失败（B5/B7：解锁后模块仍不动）

## 1. 本轮完成的机械改动（有效）

按上一轮算好的设计实现：

1. **锁爪增加下挂钩**：`CollisionShape3D` 0.46×0.60×0.10，局部 `(-0.66, -0.35, 0.58)`
   —— 挂在臂的 +Z 边缘**外侧**（世界 z ≈ −4.42…−4.32，模块后侧面在 −4.51，留 0.09 m 间隙）；
2. **打开位抬到 −0.34 rad**：挂钩抬到 y≈1.89（模块顶 1.84 以上），完全让开；
3. 闭合 = 相对角 0 → 0.35 rad，挂钩落下到模块后侧面外侧，**模块沿 +Z 一移动就被实体挡住**。

### 效果（关键指标）
```
B6 锁止后同一外力拉不动模块 | 锁爪 0.353 rad，位移 0.041 m    ← 通过
```
改造前是 **3.754 m**，现在 **0.041 m** —— 几何阻挡成立，不再依赖摩擦。

## 2. 新出现的问题：解锁后模块也拉不动

```
B7 解锁后同一外力又能拉动模块   | 锁爪 0.040 rad，位移 0.005 m   ← 失败
B5 未锁止时 600 N 反向力能拉动   | 位移 0.006 m                   ← 失败
```
诊断数据：
* 解锁（锁爪抬到 −0.36 物理角）后，挂钩已在模块顶面之上 0.05 m、z 方向留 0.09 m 间隙，
  **几何上不接触**；
* 用 **2400 N** 推同样的方向，模块能飞出 6.9 m —— 说明不是"被焊住"，而是**楔紧**；
* `C1` 显示模块 x 从 4.25 漂到 **4.37**：锁爪下压时把模块**横向推进了导轨护栏**
  （护栏在 `SOCKET.x ± 0.78`），侧向楔住后轴向摩擦急剧增大。

**结论**：锁爪的接触点偏向模块的一侧，闭合过程给模块一个 +X 的侧向分力，
把模块压进护栏造成楔紧。这是锁爪**着力点位置**的问题，不是力的方向或摩擦系数问题。

## 3. 下一步的精确修法（两种，任选其一）

1. **把支点沿 +X 收回**：现在支点在 `SOCKET.x + 1.02 = 5.27`，臂尖伸到 4.19，
   压在模块中心偏左；把支点移到 `SOCKET.x + 0.80`，让臂压在模块**中线**上，消除侧向分力；
2. 或**加宽导轨护栏**（护栏从 `±0.78` 移到 `±0.86`），并给模块加 0.02 m 侧向余量，
   使楔紧不成立。

两者都只需改 1–2 个数值，改完直接跑 `mech001b_latch` 即可验证 B5/B7。
