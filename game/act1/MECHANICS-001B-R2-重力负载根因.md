## 1. 本轮两个新结论（都很硬）

### 1.1 "刚体休眠"假设：部分成立但不是全部

位置扫描（同一关节参数、只平移整组夹爪）：

```
dx=0（原位）  changed=false   ❌
dx=+0.2       changed=true    ✅
dx=+1.0       changed=true    ✅
dy=+0.5/+1.0  changed=true    ✅
dz=+1.0/-0.2  changed=true    ✅
原位 + 显式唤醒  changed=true  ✅
```
重叠查询 `intersect_shape`（不看 mask）在出生位置只命中锁爪自己（count=1），
所以**不是埋在几何里**；而"原位显式唤醒"就能转 —— 说明**休眠/未激活**确实是因素之一。

### 1.2 真正的拦路虎：**马达克服不了重力**

按 1.1 加了 `can_sleep=false` + 绑定前唤醒后，正式场景里马达仍然只走 **0.002 rad**。
把锁爪质量按机械合理性降到 25 kg、马达冲量从 40 提到 420（仍远小于 m·g·arm ≈ 152 N·m 的等价冲量）后：

```
t=  0 angle=-0.000 w=+0.000
t= 30 angle=+0.001 w=-0.294   ← 马达刚抬起一点，重力已经在把它拉回
t= 60 angle=+0.037 w=-0.234
t= 90 angle=+0.011 stalled=true  ← 0.6 s 后我的堵转逻辑撤掉马达，臂回落到限位
```

**关键认识（也是我个人方法上的失误）**：我前面所有台架都用 `gravity_scale = 0`，
所以"台架能转"从未验证过**马达能否克服重力矩**。锁爪是水平轴、25–45 kg、臂长 0.62 m，
重力矩 152–274 N·m，是一个**有实际负载**的机构；台架里它是"零负载"，自然怎么调都能转。

## 2. 下一轮的正确设计（有物理依据，不再盲调）

1. **重算马达需求**：`τ_gravity = m·g·r_cm`。
   45 kg / 0.62 m → 274 N·m；25 kg → 152 N·m。
   马达冲量上限必须显著高于该值（按 Godot 语义，`PARAM_MOTOR_MAX_IMPULSE` 是**每步冲量**，
   等价扭矩 ≈ impulse / dt = impulse × 60），所以 40 → 2400 N·m 其实够；
   但实测只出 0.037 rad，说明还有**限位阻尼/软度**在吃力矩（`LIMIT_SOFTNESS 0.9` + `BIAS 0.3`），
   下一轮应把 softness 降到 0.2 量级再测。
2. **改零负载台架为真实负载台架**：把 `gravity_scale` 设回 1、锁爪质量 25 kg，
   先让台架在**有重力**下能闭合，再搬进关卡。这是本轮最大的方法论修正。
3. 若仍抬不动，就把锁爪改成**配重式/竖直轴**（重力不产生绕轴力矩）——这是机械设计层面的
   合法选择，任务明确允许重新设计锁爪形状与安装位置。
