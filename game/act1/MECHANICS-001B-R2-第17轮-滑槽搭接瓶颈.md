# MECHANICS-001B-R2 追加（第 17 轮）：7.95 m 之谜解开，滑槽搭接成新瓶颈

> 正式关卡：`MECH001B_DONE checks=12 failures=0`、`MECH001A_DONE failures=0`、`RESULT failures=0 completion=true`

## 1. 本轮最重要的发现：7.95 m 位移的真正原因

之前每轮都是"位移 7.95 m、越过插座 2.05 m、峰值 5.03 m/s"，而且**逐位相同**。
本轮把模块放上推车货台后，发现原因非常简单：

> **测试里是"瞬移推车"（`cart.global_position.x = DOCK_X`），而模块此时正停在车上。**
> 车被瞬移到对接口，模块留在原地（x = −5.35），于是绞盘从 7 m 外把模块拖过来，
> 数值自然每次都一样。

也就是说：7.95 m 里绝大部分不是"滑槽坏了"，而是**测试没有把模块一起带走**。
在测试里瞬移推车时同步把模块放到车上之后：

```
最小位移 1.26 m（原 7.95 m）
最大插座误差 1.14 m（原 2.05 m）
峰值速度 4.04 m/s（原 5.03 m/s）
```

## 2. 现在真正的问题：滑槽与导轨的搭接台阶

追踪模块轨迹（每 60 帧取点）：

```
在车上   (4.25, 1.86, −2.55)
t=60     (4.24, 1.78, −3.81)
t=120    (4.24, 1.78, −3.81)   ← 停住不动
```

模块沿滑槽下来了，但**停在滑槽下段**（y=1.78），没有过渡到导轨面（模块在导轨上应在 y=1.34）。
也就是说：滑槽的下端与导轨台面之间存在**台阶/唇边**，模块的棱角顶在那里。

本轮滑槽参数：
```
起点 Vector3(SOCKET.x, 1.33, −3.00)
终点 Vector3(SOCKET.x, 0.87, −3.95)
厚度 0.10，宽 1.45，正交基 _ramp_basis(seg)
```
导轨台面顶 ≈ `shelf_y + 0.05 = 0.84`，所以滑槽末端（0.87）**比台面高 0.03 m**，
再加上板厚 0.05 的半厚，末端实际形成一道 0.08 m 的唇边 —— 模块正好卡在那里。

## 3. 下一轮的精确修法（一次就能收口）

1. **让滑槽末端沉到台面以下**：终点改成 `Vector3(SOCKET.x, 0.78, −4.10)`
   （比台面 0.84 低 0.06），使滑槽"插入"台面下方，消除唇边；
2. 滑槽末端沿 z 至少与台面重叠 0.25 m（现在 −3.95 → 改成 −4.10，与台面 −2.9…−4.6 重叠 ✓）；
3. 模块出生高度从 `1.85` 微调到 `1.86`（贴住货台面，避免初始下落）；
4. 跑 `mech001a_power_module`（X3 要求：位移 >0.8 m、插座误差 <0.45 m），
   通过后再跑 `mech001b_latch`、`act1_solo_full_run`，最后补截图（模块在车上 / 滑槽 / 导轨 / 插座）。
