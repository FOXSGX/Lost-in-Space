## 二、选定改造的机制：B 主制动（前甲板手制动棘轮）

选择理由：

1. B 是玩家在行驶中唯一能直接操作的矿车制动，也是剧情文案里承诺的"B 制动/紧急制动"；
2. 车体是运动学剧情体，按任务书第四节的允许路径，采用**受轨道约束的一维动力学近似**，
   把"制动力"变成真实量，而不是重建整车刚体；
3. 空格鼓刹属于断轨绞盘（`repair_yard`），改造它会越界到另一个已验收的机械子系统。

**明确标注**：本轮交付的是"受轨道约束的一维动力学近似 + 真实机械制动机构"，
**不是 Jolt 完整刚体车辆**，也不是真实轮胎/轮轨蠕滑模型（见第十四节）。

## 三、制动机构的实际结构（`cart_brake_rig.gd`，车体子节点）

| 部件 | 构造 | 真实作用 |
|---|---|---|
| 机座 | 甲板上的 0.30×0.26×0.26 m 铸铁座（带 layer 2 碰撞，不让人站进去） | 固定件，可见 |
| 手柄 | 绕枢轴摆动的 0.46 m 钢柄 + 红色握把，行程 0 → 62° → 机械止挡 | 玩家操作对象，有限行程 |
| 棘轮扇形板 | 黄铜扇形板 + 3 个齿槽（0/1/2 档） | 档位定位，机械限位 |
| 棘爪 | 随手柄摆动的钢爪，落进齿槽 | 保持档位 |
| 拉杆 | 手柄下端 → 闸瓦托的真实两点连杆（每帧按两点重算位置与长度） | 传力 |
| 闸瓦 | 0.30×0.07×0.12 m 衬片 + 钢托，沿径向压向鼓面 | 摩擦副 |
| 制动鼓 | 近侧前轮外侧的 φ0.60 m 铸铁鼓（随轮速转动，带散热筋） | 摩擦副，随车转 |
| 支架 | 鼓的固定支架 | 固定件 |

**驱动链（每帧，与矿车积分同一个物理步）**：

```
手柄行程 travel（0..1，速率 3.2/s，约 0.19 s 拉到 1 档）
   → 闸瓦行程：先走完 4 mm 间隙（travel ≥ 0.18 才接触），之后压缩弹簧
   → 弹簧压紧量 compression = clamp((travel-0.18)/0.82, 0, 1) × 0.120 m
   → 闸瓦法向力 N = 210 000 N/m × compression
   → 摩擦制动力矩 T = μ · N · r_drum
   → 轮缘等效制动力 F_brake = T / r_wheel
```

档位：`0 = 释放`（N=0）、`1 = 常用`（travel 0.62，N=13 522 N）、
`2 = 紧急`（travel 1.00，N=25 200 N）。

**B 键是棘轮三档循环**：释放 → 常用 → 紧急 → 释放。HUD 与底部帮助行都写明"B 手制动（连按换档）"，
状态栏在拉闸时显示"手制动 常用 / 紧急"。

**受阻时不假装**：手柄推不动（例如连杆被楔块顶住）时 `travel` 停在接触点之前，
`compression = 0`、`N = 0`、`F_brake = 0`，机构状态 `blocked = true`——闸瓦没有咬合就是没有制动。

## 四、受力公式与常数（`moving_cart.gd`）

```
M_eff · dv/dt = F_traction − F_brake − F_resistance − F_grade
M_eff = 1650 kg（矿车整备）+ Σ 车上容器真实质量（6 kg/件）+ 78 kg × 在车人数
F_traction = clamp( F_grade + F_resistance + KP·(v_target − v), −2500 N, +1200 N )
F_brake    = μ · N · r_drum / r_wheel          （来自机构，见第三节）
F_resistance = (CRR·M_eff·g + 1.35·v²) · sign(v)
F_grade    = M_eff · g · slope(distance)        （route_height 的真实纵坡）
```

常数与来源：

| 量 | 值 | 说明 |
|---|---|---|
| 矿车整备质量 | **1650 kg** | 车体/走台/设备的设定值（不是从货物质量反推的） |
| 在车人员 | 78 kg/人 | 按 `contains_point` 判定在不在甲板 |
| 容器 | 6 kg/件 | 002A 的 RigidBody 真实质量，直接读取 |
| 轮半径 | 0.795 m | 与既有轮子转速换算 `speed/0.795` 一致 |
| 鼓半径 | 0.30 m | 机构几何 |
| 闸瓦摩擦系数 | 0.40 | 干态有机衬片 / 铸铁鼓 |
| 闸瓦弹簧刚度 | 210 000 N/m | 压紧量 → 法向力 |
| 牵引上限 | 1200 N（≈0.69 m/s²） | 保持原手感，低于 1 档制动力 |
| 电制动（调速器）上限 | 2500 N | 安全/调度停车用，不抢玩家的闸 |
| 滚动+轮缘阻力系数 | 0.008 | 大于本线路最大纵坡力（0.0065），静止不溜车 |
| 空气阻力 | 1.35·v² N | 1.5 m/s 时约 3 N，量级很小 |
| 纵坡 | 最大 0.0065（0.37°） | 来自既有 `route_height`，±110 N |

**速度是真积分出来的**：`speed += (F_net / M_eff) · dt`，`distance += (v₀+v₁)/2 · dt`，
位置仍由 `route_pose(distance)` 给出（轨道约束）。没有任何一处直接写 `speed = 0`。

## 九、本轮自己发现并修掉的 Bug

**Bug 1 · 搬运速度辅助把锁紧的货压进锁爪（68 mm）**
现象：加速时 2 号容器被判 locked，但实际往车尾滑了 68 mm，撞进爪体。
根因：`cart_cargo.gd::_integrate_forces()` 每帧把容器速度往"车台速度"写（co-motion assist），
夹紧后这股速度和固定爪对顶，把容器压进爪里；Jolt 允许约 2 cm 穿透，实测 68 mm（含初速滞后）。
修复：`phase == "locked"` 时不再写速度辅助——夹紧后车体运动只通过接触传递，弯道横向冲击仍然保留。

**Bug 2 · 锁爪装在容器"收腰"的高度上，实际夹的是空气（45 mm 间隙）**
现象：即使去掉速度辅助，锁紧容器在 0.7 m/s² 加速下仍漂移 25 mm。
根因：002A 的锁爪中心在甲板 +0.10 m，而容器是胶囊（r=0.245、高 0.99）：在那一高度它的有效半径只有
约 0.19 m，爪内表面（0.245 m）离真实表面有 45 mm。
修复：锁爪改为覆盖 2.05–2.55 m（胶囊的满半径段），高度 0.22 → 0.50 m。
结果：漂移从 25.3 mm 降到 20.6 mm（剩下的就是 Jolt 穿透容差），`slot_secured` 全程 true。

**Bug 3 · 制动鼓在 Compatibility 渲染器里是纯黑**
金属度 0.65 在没有环境反射时直接变黑（002A 也踩过同一坑）。改为 0.10 金属度后可见。

**Bug 4 · 手柄的安装位被护栏立柱挡住**
第一版把手柄放在 (2.30, 0.99)，正好和近侧护栏立柱重叠，玩家视角里几乎看不到。移到前甲板空处
(1.55, 1.35)，并把鼓装在近侧前轮外侧，正常视角可读。

## 十四、尚存限制（如实列出）

1. **这是受轨道约束的一维动力学近似，不是 Jolt 完整刚体车辆**：位置仍由 `route_pose(distance)` 约束，
   车体是 `AnimatableBody3D`；没有转向架、轮轨蠕滑、悬挂或车体侧倾。
2. **车轮仍只是可视网格**：没有碰撞、没有转动惯量、没有关节；制动力矩被折算成"轮缘等效纵向力"，
   不是真实的轮轨摩擦接触解。
3. **货物→矿车的反作用没有传递**：车体是运动学体（无限质量），容器的撞击不会推动矿车；
   货物对运动的影响只通过 `M_eff`（真实质量）体现。这是 002A 已声明的耦合边界，本轮未改。
4. **Jolt 接触穿透容差约 2 cm**：锁紧容器在 0.7 m/s² 加速后仍会相对车台沉降约 2 cm 再回位；
   容器始终留在 pocket（±0.12/±0.16 m）内、`slot_secured` 保持 true。按任务要求没有改全局 Jolt 配置。
5. **手制动是运动学执行器**：手柄行程、棘轮档位、闸瓦压紧量由脚本推进，闸瓦力用弹簧刚度算出；
   不是刚体连杆求解，也没有螺纹自锁、衬片磨损、热衰退。
6. **B 是 0→1→2→0 循环档**：比"按一下到底"更机械，但连续按会松开制动；HUD 与帮助行已写明。
7. **调速器电制动（≤2.5 kN）与自动驻车是独立路径**：断轨停车、安全制动、到站停车走它，
   会把车停住并自动落闸（1 档）；玩家按 B 会把档位推到 2 档再松开，此时若在坡道上松开，
   车会按物理缓慢溜动（本线路 CRR 0.008 略大于最大纵坡 0.0065，实测不溜）。
8. **联机未做双端验证**：`apply_net_state` 仍只同步距离/速度/状态，客户端不画手柄动作；
   网络专项继续暂停。
9. **未做热衰退、雨雪/油污、衬片磨损、闸瓦间隙自动调整**；也未做真人手感验收。
10. **第一幕没有在本轮重跑**（约 20 分钟通关）；只做了过幕接线与场景切换验证 + `game/act1/` 未改动的核对。
