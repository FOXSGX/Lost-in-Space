## 四、实际机械结构与物理原理

建在 106 m 站台内侧（`dock_clamp.gd`，车体局部坐标 PIVOT (1.00, 1.60, −0.72)）：

| 部件 | 结构 | 物理作用 |
|---|---|---|
| 立柱 + 铰座 | 1.6 m 立柱、铰座、扇形齿槽板 | 固定件 |
| 闸臂 | 1.55 m 钢臂，末端 0.36 m 压车垫块，臂根 0.28 m 配重 | 绕水平轴（x）转动的 1-DOF 刚体 |
| 棘爪 | 0.26 m 钢爪 + 5 齿齿槽 | 到闭合止挡自动落位，机械保持 |
| 拉手 | 站台侧横杆（高 1.25 m） | 玩家操作点 |
| 状态灯 | 停靠成立时亮红 | 状态反馈 |

**运动方程**（每帧与矿车/玩家同一个物理步）：

```
I · d²θ/dt² = τ_pull − τ_counterweight − τ_damp − τ_stop
I = 130 kg·m²
τ_pull = 430 N·m      （按住 E 时的玩家拉力矩上限，方向闭合）
τ_counterweight = 330 · sin(θ) N·m   （配重把臂抬回，方向开放）
τ_damp = 95 · ω
θ ∈ [0, 1.50 rad]     （0° 竖起 / 85.9° 横压，两端机械止挡）
```

**停靠判据**（全部是真实几何/状态，没有 flag 捷径）：

```
docked = 棘爪落位(latched)
       且 |cart.distance − 106| ≤ 0.35 且 cart.speed < 0.05
       且 臂端垫块到车体近侧板（z=0.87）的距离 < 0.18 m，y ∈ [0.50, 1.95]，x ∈ [−3.2, 3.0]
```

棘爪只在“玩家正在拉 + 车在门区 + 垫块压住车”三条同时成立时才会落；抬棘爪后配重臂自己抬回。

## 十、尚存限制（如实列出）

1. **矿车是运动学剧情体**（002B 的 AnimatableBody3D），夹钳对车**没有 Jolt 力耦合**：
   “压住”是真实几何接触判定 + 棘爪状态，车的保持靠它自己的手制动，不是被夹钳拎住。
2. **闸臂是 1 自由度折算刚体**（I=130），不是 `RigidBody3D + HingeJoint3D`；没有铰轴间隙与磨损。
3. **玩家拉力是输入驱动的力矩**（按住 E，上限 430 N·m），不是角色胶囊对臂的接触力求解。
4. **棘爪在闭合止挡自动落位**，没有独立的“插销”刚体行程；摘爪是瞬时状态切换。
5. **第三幕本身只有这一个剧情节点**：晶体矿区内部（矿洞）仍未实现。本轮只把“到站”这一步做成机械，
   没有新增剧情，也没有声称第三幕已经做完。
6. **到站不再自动完成**：五幕连续远征脚本（`work/` 下的 p5 驱动）现在必须多做一个停靠动作，
   本轮没有重跑那条外部脚本；正式玩家流程（H1–H5 + 003A 专项）已实测。
7. **联机未验证**：夹钳是本地/主机逻辑，`net_state` 没有加入夹钳角度；网络专项暂停。
8. **站台视野偏挤**：夹钳装在 106 m 站台与岩壁之间，玩家视角只能看到车侧与臂，截图 06 用证据镜头并已标注。
