## 三、卷筒/电机/鼓刹的机械关系

```
I_drum · dω/dt = τ_motor(ω) − T·r − τ_brake − τ_bearing − c·ω
free_length   += −ω · r · dt
T             = clamp((|sheave − eye| − free_length) · k, 0, max_force·1.05)   （轨道侧求解）
```

| 量 | 值 | 来源 |
|---|---|---|
| 卷筒转动惯量 `I_drum` | **45 kg·m²** | 卷筒 + 减速箱折算（设定值） |
| 卷绕半径 `r` | **0.34 m** | 机构几何 |
| 电机堵转力矩 | **1088 N·m** | 额定缆绳力 3200 N × 0.34 m |
| 电机空载角速度 | **1.30 rad/s**（≈0.44 m/s 线速度） | 保持原手感 |
| 电机力矩曲线 | `τ = 1088·(1 − ω/1.30)`（收绳侧，clamp ≥ 0） | 直流电机近似 |
| 放绳侧力矩 | `−220 N·m × (1 + ω/0.62)` | 放绳电机/阻尼 |
| 鼓刹摩擦容量 | **950 N·m**（≈2794 N 缆绳） | 闸瓦压紧 × 摩擦系数 |
| 鼓刹行程建立 | 4.0 /s（约 0.25 s 拉满） | 机械行程 |
| 轴承静阻 / 粘性阻尼 | 30 N·m / 18 N·m·s | 轴承与密封 |
| 角速度硬上限 | 3.0 rad/s | 机械限位 |

**缆绳反作用**：张力永远把鼓往放绳方向拉，所以 `τ_cable = −T·r`（ω 正向 = 收绳）。
**鼓刹**：静摩擦能吃掉当前驱动力矩就不动；吃不掉就按库仑摩擦 `−sign(ω)·950` 打滑，
并且在一步内不允许把鼓"推"成反转。
**绳长硬限位**：`free_length` 撞到 0.9 m / 12 m 时 ω 被机械止挡吃掉（不是穿模）。
**没有"离合器把绳长退回去"**：旧代码 `observe_tension()` 里的假打滑已删除，改成真堵转标记。

## 五、不同负载的实验

维修区唯一真实负载就是摆动轨（9000 kg·m² 绕铰链）。本轮用**两个真实吊耳**做负载差异实验：

* **中段吊耳**（力臂短）：张力顶到 3159 N 仍拉不脱 4000 N·m 的卡阻，5 s 后角度仍是 15.00°；
* **前端吊耳**（力臂长）：同样电流/力矩下卡阻解除，轨道被拉到 12° 以下。

这不是"改参数"，而是 `τ = T · d(distance)/dθ` 在真实几何上的结果：力臂短的吊耳把同样的张力
变成更小的力矩。测试 C10 同时断言两者，避免"随便挂哪个都能过"。

## 六、玩家正常操作流程（与原有剧情一致）

```
矿车在 s=88 安全停车（002B 的调速器停车）
  → 下车走到断轨处，E 把缆绳挂上前端吊耳
  → 回到绞盘控制台接管（E），W 收缆：卷筒真的出力，轨道被拉回
  → 到导向槽（±4°）后松 W，按空格落鼓刹（鼓刹把卷筒抱住，轨道不再回掉）
  → 离开控制台，走到锁定座 E 插销：销子进导向槽，0.55 s 把最后几度拉正
  → 轨道 0°，锁定销到位 → 线路恢复（cart.release_route）
  → 回矿车控制器 E 重新发车 → 驶向终点
```

**关键行为变化（物理导致，已记录）**：松开 W 之后，负载会**反拖卷筒**（真实绞盘没有自锁）。
所以"收进绿区 → 空格落闸 → 再去插销"是新的必要顺序；不落闸就去插销，轨道会慢慢掉回去，
插销会以"还差 X°"拒绝。这正是鼓刹在本任务里的真实作用，而不是装饰。

## 七、维修成功的真实判据

`install_lock()` 依次检查：支架收起 → 卡阻已解除 → 角度在导向槽 ±4°（含导向轮加成）→
要么已经静止在 ±2° 且垂直误差 ≤ 0.06 m（直接插销），要么进入 `guided`：销子进槽后由槽
把轨道拉正 0.55 s，`_finish_lock()` 才发 `lock_installed`。
`rig` 收到信号才置 `completed=true` 并广播 `mission_completed`，`level_flow` 再
`cart.release_route()`。**没有任何一处写 `repair_complete=true` 了事。**

## 十二、尚存限制（如实列出）

1. **卷筒是"折算的一维刚体"**（I=45 kg·m²），不是带真实轴承/几何的 `RigidBody3D + HingeJoint3D`；
   卷绕半径固定 0.34 m，不模拟多层叠绳导致的半径变化。
2. **缆绳是理想弹簧（k=26000 N/m）+ 真实几何力臂**，不是离散绳索/弯曲刚度/绳槽摩擦；缆绳没有碰撞体。
3. **负载仍是 1-DOF 铰链轨道**（`AnimatableBody3D`，9000 kg·m²），不是自由刚体——这是原有设计，本轮保留并如实说明。
4. **电机模型是力矩-转速曲线 + 堵转**，不含电流限幅、启动冲击、热保护。
5. **鼓刹是库仑摩擦容量模型**，不含热衰退、磨损、湿滑；容量固定 950 N·m。
6. **松开 W 后负载会反拖卷筒**（真实），因此必须用空格鼓刹保持；这是本轮引入的行为变化，
   流程提示已按"收缆 → 落闸 → 插销"更新。
7. **联机未同步力矩/绳长细节**：`net_state` 仍只带状态摘要；网络专项暂停。
8. **卷筒视觉用 `lerp_angle` 平滑跟随 `drum_angle`**（1～2 帧视觉滞后），物理量本身不滞后。
9. **绞盘操作位被机座/岩壁包围**：玩家视角很难直视鼓面（截图 04/06 用证据镜头并已标注）；
   这是关卡布局问题，本轮未改场景几何。
10. **未做真人手感验收**；维修全程约 8.6 s 收缆，是否过长需要真人试玩判断。

## 十四、自主修复的 Bug

1. **假的"离合器打滑"**：旧 `observe_tension()` 在张力到顶时把 `free_length` 往回加、把
   `drum_angle` 回退 0.25 rad。这不是打滑，是把绳长改小。已删除，改为真堵转标记
   （τ_motor 到顶、ω→0）。
2. **鼓刹是布尔冻结**：旧 `brake=true` 直接把线速度置 0。改为 950 N·m 摩擦容量 + 行程建立 +
   静摩擦保持 + 超容量打滑。
3. **卷筒没有惯量/反作用**：改为 `I·dω/dt`，缆绳张力以 `T·r` 反作用到鼓上。
4. **鼓刹过零抖动**：初版在 ω 穿越 0 时会把鼓"推"成反转（实测停稳后 ω 抖到 0.2187）。
   现在一步内越过零就停在零，下一步走静摩擦分支。
5. **松开 W 后负载反拖**（物理上正确，但旧代码掩盖了它）：本轮暴露并写进流程——
   必须先落鼓刹再插销。E2E 与 C17 验证了这条顺序可完成。
