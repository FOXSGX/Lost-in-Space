```

  风险等级：⚠️⚠️⚠️（高）

### **镜面失败→成功的高潮设计**

```
【第一次尝试】
  场景：A 光束校准 + B 光束校准完成
  结果：镜面对齐失败（设计好的）
  
  屏幕反馈：
    UI：对齐度 94%（中文/英文）
    音效：失败的"呃"声 + 警告音
    画面：镜面微微抖动，光束没对齐
  
  玩家感受："这么接近！"
  持续时间：2-3 秒（快速反馈）

【中间】
  系统提示："需要更精准的相位调整"
  队友讨论："再来一次，这次更小心"
  
  心理建设时间：2-3 秒

【第二次尝试】
  场景：玩家重新调节两个光束
  结果：镜面对齐成功
  
  屏幕反馈：
    UI：对齐度 100%！（金色闪烁）
    音效：成功的"叮"声 + 音乐升调
    画面：镜面反射出彩虹光束
