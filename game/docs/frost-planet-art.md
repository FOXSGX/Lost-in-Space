# 霜烬星美术：视觉基调重做（第一轮）

更新：2026-10-13。这一轮只动视觉，不改玩法数值、碰撞和联机同步。
所有取值都是美术方向上的第一版，仍可继续调整。

## 为什么先做这一轮

霜烬星是当前唯一能完整通关的关卡，也是画面离目标最远的地方。
用真实渲染存下四张检查图之后，问题集中在三点：

| 现象 | 原因 |
| --- | --- |
| 雪原整体泛白、区域之间看不出明度差 | 环境光是 0.85 的亮蓝，等于给所有表面无差别加了一层白，顶点色被压平 |
| 画面中心过曝、外围偏暗 | 两盏补光固定在 `(-6,5,7)` 和 `(8,6,-5)`，而地图是 384×256 米，它们只照亮出生点附近 |
| 冰岩、电池读起来像贴在地面上的白色纸片 | 俯视视角看不到底部接触关系；碎冰装饰只有 0.42×0.8×0.28 米，在 28 米的镜头范围里就是几个白点 |

另外，色调用的是 `TONE_MAPPER_FILMIC`。它会把 0.2~0.35 的线性中间调抬到 0.53~0.66，
于是冰湖、台地和普通雪面全挤进高亮区间，俯视画面几乎没有层级。

## 这一轮改了什么

### 光照与环境（`scripts/main_3d.gd` → `_build_environment`）

- 环境光 0.85 → 0.32，颜色由 `#94c8d8` 加深到 `#4d7c96`。
  目标是让"受光面亮、背光面冷"成为主要结构，地表颜色回到设计值附近。
- 主光抬高到 58°、能量 1.6。阴影是俯视视角里唯一能说明"这个物件有多高"的线索。
- 删掉固定在地图原点的两盏点光，换成低角度冷蓝天光 `FrostSkyWrap`（0.6）。
  背光面仍然有雪地反照的冷色，但不再制造局部亮斑。
- 色调映射 filmic → ACES，泛光阈值提到 1.25。泛光只留给热源、信标和发光标识，
  雪面本身不再发光。

### 地表（`_terrain_color`、`_region_color`）

- 区域色整体加深一档，拉开六个区的明度与冷暖差：
  台地最亮、峡谷最暗、裂谷偏暖褐、残骸区中性灰、撤离点暗绿。
- 雪面质感由"单向提亮"改成"过零切换明暗"：正侧是受光的雪脊，负侧是背光的雪窝。
  在完全不改地形起伏的前提下（碰撞面必须保持水平，角色没有重力与上坡逻辑），
  俯视画面也能读出地面不是一张平板。
- 碎冰装饰从 0.42×0.8×0.28 放大到 0.62×0.86×0.44，每区 28 → 34 枚。

### 落脚与体积（`scripts/art_utils.gd`、`scripts/frost_obstacle_3d.gd`）

- 新增 `art_utils.gd`：提供贴地的柔和暗斑（径向渐变、无光照、按透明度缓存材质）。
  俯视 46° 下物件底部和雪面的接触关系很弱，少了这一层，物件会像贴纸一样浮着。
  已接到冰岩、气象信标、热能电池、异常冰样、撤离平台、地标和安全屋。
- 冰岩重做明暗结构：顶面压暗、顶面之上加一层不规则的冰冠并提亮。
  原来顶面接近纯白，和雪地同色，从上方看冰岩直接消失在地面里。
- 冰面材质粗糙度由 0.72 降到 0.52 并给一点金属度，让顶面有掠光。
- `FrostObstacle3D.setup()` 增加可选参数 `terrain_sample`，由主场景传入地表高度，
  落脚暗斑才知道自己脚下地面的高度，不会在雪包上被吃掉一半。

## 复查方式

```powershell
godot --path game --rendering-method gl_compatibility --script res://tests/frost_art_capture.gd
```

输出到 `builds/frost-art/`：坠机点（玩家视角）、全图俯瞰、斜俯瞰、中央冰湖。
对比图和结论记录在 `builds/` 之外的对话记录里，`builds/` 本身不入库。

## 这一轮没有做

- 地图仍然是一整块连续雪面，没有冰面减速、冰裂缝地形和风雪粒子。这些属于玩法 + 表现，
  需要和 `docs/design/planets/planet-00-demo.md` 的待验证项一起决定。
- 气闸、驾驶台以外的主舱、敌人和界面没有跟着重做，风格统一留到确认这版基调之后。
- 冰崖只调了明暗关系，还没有做顶面的碎裂棱角；从俯视看仍然是较规整的长条。

## 下一轮建议

1. 确认这版基调（冷蓝雪原 + 暖橙热源、明暗比现在强得多）之后，再统一主舱与星球。
2. 冰崖顶面加碎裂轮廓，让 12 道墙在俯瞰下不再像规整的浅蓝条。
3. 热源、信标、撤离点做一组"暖光冷地"的专属光效，强化路线规划时的视觉锚点。
4. 若要做冰面/裂缝表现，先确定玩法规则，再决定用贴地材质还是分块地形。
