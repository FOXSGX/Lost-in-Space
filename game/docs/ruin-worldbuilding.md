# 腐墟星世界观底层设定

> 这份文档是腐墟星剧情、关卡和结局的唯一底层设定。后续做医院病历、学校广播、
> 超市营地遗迹、能源站反应堆和 NPC 对话时都以这里为准，不再另起一套“病毒爆发”。

## 一、灾难不是病毒，是能源事故

- 这颗星球原本是**星际能源公司**的深层开采站。地表的生活区（医院、学校、超市、
  能源站）是给矿工家属建的。
- 公司在深层钻探一种高密度晶体能源，暂名 **“星髓”**。
- 星髓不是普通矿物，而是**地下共生菌群的代谢结晶**。钻探击穿了菌脉，菌群泄漏。
- 菌群通过**能源站的循环系统**扩散到全城：冷却、供暖、通风、供水都经过能源站。
  所以能源站是爆发原点，也是唯一能切断循环的地方。
- 感染体不是“病毒感染者”，而是被菌群改写的矿工/家属。他们保留部分本能：
  - 会聚集；
  - 会回“家”；
  - 会重复生前行为。
  因此学校、医院、超市里的感染体可以有行为模式，不是无脑乱走。
- 医院最早沦陷，因为医院收治了第一批矿工，并试图用镇静剂压制菌群，失败。
- 超市曾有人靠物资撑过一阵，最后菌群从通风口灌入。
- 学校广播站的学生录音，是地表最后一段正常人类声音。

## 二、庇护所 NPC

庇护所由当年值班的工程师和医生维持，靠地下室独立维生系统活着。他们不知道地表
已经烂成什么样，只知道“主反应堆快停了，停了我们就永远走不了”。

### 老工程师

- 表面任务发布者，坚持“重启反应堆我们就能走”。
- 隐瞒事实：当年是他签字同意钻探深层矿脉，他知道爆发与自己有关。
- 玩家拿到医院病历/能源站日志后可以质问他，影响结局对话。

### 年轻医生 / 实习生

- 知道地表已经没救，偷偷准备“只带样本走”的方案。
- 给玩家支线选择：带幸存者走，还是带星髓样本走（样本可以卖钱，也推动世界观）。
- 她掌握“反应堆重启会激活地下菌群二次喷发”的关键信息。

## 三、离开的三个关键件

离开不是找一块电池，而是 **重启反应堆 + 导航密钥** 两条线汇合：

### 1. 星髓点火芯（能源站）

- 主反应堆的点火核心在爆发时被紧急弹射到能源站 B2 应急舱。
- 它不是普通电池，而是星髓菌群的代谢结晶；点火芯是“把反应堆重新点着、给登陆艇跃迁电池充电”的能量钥匙。
- 玩家需要先从医院拿到 E-07 门禁卡，再进入 B2 取回。
- 这是“回家”关卡：已经跑过全城，最后回到起点，但能源站内部已经变了。
- 能源站内部是菌群密度最高的地方，应有精英感染体。

### 2. 冷却剂稳定剂（医院）

- 反应堆重启会过热，需要医院地下药库的低温稳定剂（原本给矿工做低温手术）。
- 医院支线揭示“感染者镇静实验”，病历里能读到行为模式线索。
- 顺带拿到一把门禁卡，用于能源站深层。

### 3. 导航密钥 / 星图碎片（学校 + 超市）

- 学校机房：天文台观测数据 / 学生社团记录。
- 超市仓库：民用导航模块（运输无人机用）。
- 两个拼起来才能算出安全跃迁路线。
- 学校可埋“学生广播求救”录音；超市可埋“幸存者抢物资自相残杀”的痕迹。

## 四、回庇护所后的选择

集齐三件套回到庇护所：

1. **老工程师方案**：立刻重启反应堆，但医生发现会激活地下菌群二次喷发，
   地表 30 分钟内彻底沦陷。
   - 快速重启，限时逃回飞船，路上感染体狂暴化。
   - 通关，但星球毁灭。
2. **医生方案**：先去能源站深层手动关闭菌群泵，再重启反应堆，然后回登陆艇。
   - 多一个泵房关泵步骤，耗时更长、风险更高。
   - 星球保住，真结局。
3. **隐瞒信息直接跑**：拿到密钥就走，不重启反应堆。
   - 飞船能源不足，只能迫降附近星球。
   - 坏结局 / 续作钩子。

## 五、通关流程一句话版

能源站地下室遇 NPC → 医院取稳定剂 + E-07 + 病历（揭示真相）→ 学校取观测数据 →
超市取导航模块拼导航密钥 → 回能源站 B2 取星髓点火芯 → 选择重启方案 →
关泵/重启 → 回登陆艇按 E 离开。

## 六、记忆点

1. 能源站地下室入口伪装成**配电间暗门**。玩家第一次路过不会注意，拿到 NPC 无线电
   信号后才标记，制造“原来我一直在它上面跑”的反转。
2. 医院药库：感染体护士围着病床重复打针动作，病历散落。病历说明镇静剂对菌群无效，
   顺手解释医院为什么沦陷最快。
3. 学校广播站可选支线：修复广播后播放学生录音，吸引一波感染体，但打开一条近路，
   奖励“用声音引怪”的玩法。
4. 超市做成幸存者营地遗迹：自制路障、留言板，暗示曾有人撑过一阵，最后被通风口
   灌入的菌群吞没，把四栋建筑的沦陷原因串成一条线。
5. 离开关键物不是单一道具，而是三件套 + 一个选择。

## 七、当前实现状态

- 能源站外部：已从加油站改成储能/充电/变压器/太阳能板的“废弃能源站”。
- 能源站内部：本轮实现四层结构（2F 控制/通风、1F 大厅/控制/汽轮机房、
  B1 泵房/冷却剂、B2 反应堆/应急舱/菌晶生长）。已接入 LIS Physics 的 Jolt
  铰链维护门，以及 ART-SAMPLE-002 的星髓晶体、控制台和工业压机。
- 能源站 1F 配电间暗门已接入：可进入独立的地下庇护所；B2 应急舱有**星髓点火芯**
  （需 E-07 门禁卡），B1 有菌群泵控制台，B2 有反应堆重启控制台。
- 庇护所内部：工程师工作台、医生诊疗台/样本冷柜、上下铺、无线电/地图桌、维生柜；
  老工程师和年轻医生可交互，带最终三选一方案。
- 医院内部：四层结构 + B1 地下药库、2F 镇静实验观察室、1F 保安室。
  三件医院任务物已接入：2F 镇静实验病历、B1 低温稳定剂、1F 能源站门禁卡；
  任务物是队伍共享状态，进快照，不占普通物品格。
- 拿到病历后，工程师对话会承认当年签字；门禁卡用于打开 B2 应急舱取星髓点火芯。
- 学校内部：三层，1F 大厅/食堂/校长室、2F 教室/实验室、3F 计算机房/天文台/广播站；
  3F 天文台可取得“天文观测数据”。
- 超市内部：两层，1F 卖场/收银/冷柜/幸存者路障、2F 仓库/办公室/装卸口；
  2F 办公室可取得“民用导航模块”。观测数据 + 导航模块拼成导航密钥。
- 图书馆：大门从内侧焊死、书架顶门，按 E/R 都打不开，也不登记建筑；
  不制作室内，保持“锁死不对外开放”。
- 任务/结局已接入：庇护所双 NPC 对话、星髓点火芯/稳定剂/导航密钥三件套、
  工程师快速重启倒计时、医生先关菌群泵再重启、隐瞒真相直接离开；
  三种方案最后都回登陆艇按 E 结算，医生方案在重启后不立刻结算；结局状态进快照。

## 八、用词约束

- 不使用“病毒爆发”“丧尸病毒”作为官方解释。
- 用“菌群泄漏”“星髓污染”“感染体”“行为残留”等词。
- 感染体仍然可以叫“丧尸/感染者”作为玩家口语，但设定层是菌群改写。
- 星髓样本具有商业价值，但也是生态灾难源，不能写成单纯“能量电池”。
