# 太空舱试玩与接入说明

更新：2026-10-12。本轮按用户要求优先补齐储物、维修、补给玩法；以下数值是可调整的原型实现，不代表团队已确认的最终平衡规则。

## 运行与操作

Godot 4.7.2 导入 `game/project.godot`，运行后“创建主机”直接进入归航号主舱。局域网其他玩家填写主机 IP 加入，最多 4 人，端口 24567。

- WASD / 方向键移动；按住 Shift 加速。靠近设施按 E；M 打开 / 关闭地图，Tab 打开 / 关闭日志，Esc 打开设置（设施面板和航线界面优先关闭或返回）。
- 设置界面可以重新绑定 Shift 加速、M 地图和 Tab 日志；设置时游戏暂停，地图和日志打开时世界继续运行。
- 储物架：领取或存回医疗包、氧气瓶；全队共享库存，每人每种最多携带 2 件。
- 维修台：消耗 1 个零件，恢复 20% 舰体；舰体低于 60% 时不能确认登陆。
- 补给柱：免费恢复生命、氧气和体温；用回收点数制作医疗包、氧气瓶和零件，制成物进入共享库存。
- 任务终端：显示最近一次远征的结果、入库点数和下一目的地。
- 气闸：全队在主舱和操作训练舱之间切换，训练是可选练习，不阻止起飞。
- 右上“准备出发”：每名船员各自标记就绪；有人新加入时清除准备状态。
- 驾驶台：打开航线图，全员准备且舰体达标后，由主机确认登陆。
- 星球内按 3 使用医疗包（恢复 2 点生命），按 4 使用氧气瓶（恢复 45 氧气）；状态已满或已经倒地时不消耗。
- 任务结束返回主舱，保留剩余随身用品和生存状态，清除准备状态。倒地船员获救后至少有 1 点生命、10 氧气和 20% 体温，仍需到补给柱恢复。
- “退出房间”返回主界面；主机退出后，客户端会返回主界面并显示断开提示。

## 舱室尺度与视野

按用户反馈，主舱从约 14×11 米扩大到 42×33 米，面积为原来的 9 倍。设备保持人物尺度，储物区在左侧，维修和补给在右侧，舰桥在前方。主舱镜头的正交 size 为 14，并平滑跟随角色；整舱超出单屏，出生位置看不到驾驶台，需要走动进入各区域。

模型、碰撞、设施交互点、出生点和可移动边界已同步更新。操作训练舱仍使用原有场景；主舱提示条提供各区方向。

## 美术方向与本轮实现

用户明确不偏好像素风，并选择“精致卡通：清晰轮廓、圆润设备、统一色彩”。本轮优先在太空舱落实，属于可试玩的美术迭代，不代表整个游戏的美术已完成。

- 配色：奶油白外壳、低饱和青蓝地面与设备、暖橙和鼠尾草绿座椅。
- 模型：设备增加圆角、层次、抽屉把手、卡扣、仪表和控制台屏幕图案；GLB 使用平滑设备法线和正确的线性色彩。
- 场景：中央通道增加地面嵌板、星图轮廓、船名与分区标记，补充座椅、边桌、杯子、平板和绿植；新增陈设有对应碰撞，并检查设施可达性。
- 舷窗：程序绘制星空与小行星，保留可编辑着色器源码；场景使用柔和环境光与暖色主光。
- 角色：原角色模型轮廓与部件保留，使用平滑表面和较柔和的发光材质。
- 界面：舱内设施使用奶油色面板，HUD 使用青蓝色半透明面板。
- 主舱仍为 42×33 米，使用跟随镜头，超出单屏；新的集合点位于中央星图附近。

上一版源模型、生成脚本和预览保留在 `art-source/editable/spaceship-cabin/archive/v0.1.2/`。星球场景、敌人与其余界面尚未按这一方向整体重做。

## 本轮原型数值

| 项目 | 当前实现 |
| --- | --- |
| 新档库存 | 医疗包 8、氧气瓶 8、零件 6 |
| 新档舰体 | 80% |
| 制作成本 | 医疗包 10、氧气瓶 5、零件 10 回收点数 |
| 回收入库 | 已投送物资的回收价值在返航时记入回收点数 |
| 返航损耗 | 成功扣 8% 舰体，失败扣 20%，最低 40% |
| 应急保障 | 返航时至少保留 1 个维修零件，避免零库存造成无法出发 |
| 存档 | 主机本地自动保存共享物资、舰体、点数和最近远征记录 |

物资调整由主机验证玩家身份、设施距离、库存和携带上限后执行。客户端只申请操作，不能直接写入库存。船员断开后，未消耗的随身用品回到共享库存。

存档位于 Godot 的 `user://ship-cabin-save.json`（Windows 默认在 `%APPDATA%/Godot/app_userdata/迷失太空 · Lost in Space/`）。重开房间时，上一房间尚未消耗的随身用品统一回库，临时网络 ID 不写入存档。这里保存舱室物资，没有保存进行中的星球关卡。

## 资源与实现

- 概念图和可编辑源模型：`art-source/ai-generated/spaceship-cabin/`、`art-source/editable/spaceship-cabin/`。
- 游戏导入模型：`assets/ship-hub/ship_hub.glb`，与可编辑源 GLB 一致。
- `ShipHub3D` 负责模型、简化静态碰撞和设施标记；游戏镜头切掉近侧门扇、门楣与立柱，避免挡住角色，源 GLB 保留完整门结构。
- `ShipSession3D` 负责共享库存、背包、设施界面、准备状态、区域切换、返航结算和主机存档。
- `Main3D` 继续负责联机入口与星球流程；`SpacePlayer3D` 使用舱内正交跟随镜头，进入星球后恢复跟随镜头和原有操作。
- 驾驶台操作点位于平台前方，可从地面走到；这一版没有做登台、楼梯与导航网格。

## 验证

- `godot --headless --path game --script res://tests/ship_hub_integration.gd`：39 项单人检查，包含单屏范围、镜头跟随、设施可达性、碰撞、存取守恒、维修、制作、用品消耗、登陆、返航、延迟状态隔离与存档。
- 双实例分别运行 `res://tests/ship_hub_network.gd -- host` 和 `-- client`：25 项双客户端检查，包含中途加入训练舱、区域切换、库存同步、全员准备、用品消耗、返航和断开回库。
- 霜烬星控制、探索功能、合同循环和角色外观检查通过。
- `res://tests/ship_hub_capture.gd`：用实际图形渲染保存主舱、储物、维修、补给和航线截图到 `builds/ship-cabin-preview/`。

Windows 本地试玩目录：`builds/ship-cabin-v0.1.4/`；双击“启动试玩.cmd”。此包包含 Godot 运行程序和 PCK，供本轮试玩使用。

角色漏面与脚部穿地已修复，详见 `protagonist-3d.md`；实机近景在 `builds/ship-cabin-preview/character-grounding.png`。
