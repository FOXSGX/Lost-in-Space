# 共振星玩法链与空间安全规范

## 已确认规则

共振星位于红褐色异星山洞内，安全岩台之间是悬崖，悬崖下方是深层熔岩海。玩家只能在安全甲板、轨道连接桥、检修坡道和反应堆平台上移动；越过悬崖边缘后先播放受控下坠动画，落入熔岩后设置 `lava_dead`，生命归零，不能进入队友的 R 救援目标。主机调用 `Main3D.kill_player_in_lava()`，并释放该玩家持有的能源核心、货箱或冷却单元。

共振星使用完整第三人称控制：相机位于角色背后斜上方约 15 米、抬高约 8.6 米，鼠标水平旋转相机，鼠标向上抬高视角、向下压低视角，并使用平滑角度过渡；角色始终面向相机水平朝向；W/S 或方向键前后移动，A/D 或左右方向键横移，移动方向跟随相机水平朝向；镜头被限制在洞窟安全体积内，命中大型设施时只做射线收缩与抬高绕行，**不再有任何透明淡出**；不显示屏幕准星。Esc 释放鼠标，返回飞船或切换区域时恢复系统光标，点击窗口后重新捕获。

主线按以下顺序串联，不能跳过前置：

1. **洞底热阀链**：左阀 → 右阀 → 泄压阀；多人模式下相邻阀门必须由不同玩家交替开启，单人模式允许同一玩家完成。
2. **第一节移动模块**：路线切换 → 供能端 → 对接夹具。
3. **上下层支援接力**：第一节完成后，低位发送端启动，另一名玩家沿高位维护桥接入接收端；单人由无人机占位。接力完成后支援安全闸打开，第二节才开放，并降低下一次快线风险。
4. **第二节移动模块**：低位快线选择 → 磁力货箱 → 绿色稳定插槽 → 保险栓/安全锚点。
5. **第三节移动模块**：A/B/C 交替光束校准 → 供能端 → 对接夹具。
6. **反应堆甲板**：升降接力 → 左右中央镜面反射 → 冷却单元护送。
7. **中央核心**：双人握持，搬运者不能攻击，队伍沿安全路径抵达返航平台。

## 空间结构

- 关卡现在分为三层：地面安全甲板 / 5.4 米中层观景桥 / 11.5 米高位竖井观察台。登高网络只有三条坡道：西侧检修平台 → 坡道 → 中层观景桥（56 米）→ 东侧下坡 → 反应堆甲板 → 坡道 → 高位观察台；其余平台同高直接相接。高架平台两侧有 1.1 米护栏碰撞，竖井观察台东端封口。
- 洞穴东侧已经塌陷开口：四段 8—15 米矮断垣之外是远景山脊与程序化天空，背景不再使用纯色；洞口一侧另有一盏日光溢入灯。
- 洞底安全甲板使用 `SAFE_DECK_RECTS` 定义，防止玩家把熔岩当作普通地面横穿。
- 主轨道之间使用 `SAFE_PATH_SEGMENTS` 连接，保证热阀、三节模块、反应堆塔和返航台之间存在连续路线。
- 三条高位维护桥各自拥有桥面碰撞和两端检修坡道。高位点的机关状态仍由阶段控制器验证，视觉 GLB 不携带玩法碰撞。
- 玩家相机使用远景肩后视角并被夹在洞窟安全盒内；大型模块、反应堆塔或维修仓不再触发任何透明淡出，遮挡通过镜头体积限制与桁架减量解决。
- 关键交互装置采用大轮廓、发光环和高位标签：热阀、模块端口、光束节点、镜面节点、冷却接收座和下一步信标不会被小型细节淹没。
- 反应堆甲板新增独立的升降接力甲板：低位节点完成后，平台沿液压柱上升到高位控制点；左右中央镜面和冷却接收座拥有独立指示灯状态与碰撞挂载。
- `LAVA_PIT_RECTS` 用于标记洞底裂隙；即使玩家位于地图边界内，进入裂隙仍会立即阵亡。
- 熔岩潮汐周期会同步改变熔岩表面与裂隙的高度和发光强度；安全甲板保持原高度，形成可读的危险窗口。

## 交互小游戏（2026-10-17）

设备类交互改成两次按键的校准小游戏：第一次按键开启校准条（光标往返、绿区为合格区），光标进入绿区时再按一次确认。通过后按原规则结算；偏差过大提示重试，超时自动关闭且不推进任何状态。难度按设备区分：热阀亮区最宽、反应堆节点最窄且光标最快。搬运类交互（磁力货箱、能源核心、冷却单元）不经过校准。小游戏由主机推进与结算，客户端只发送交互意图。

## 状态与联机

阶段主机维护 `heat_valves`、`heat_chain_complete`、`lava_tide_clock`、`lava_tide_active` 和 `lava_dead`。轨道压力状态可以影响低位快线过载速度，但共振星不会启用周期性视线遮罩；镜头和工业设施始终保持清晰可见。快照同步热阀顺序、熔岩潮汐显示状态、模块、反应堆任务、核心搬运和无人机状态。客户端只发送交互意图，不能自行解锁后续目标。
