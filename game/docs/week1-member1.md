## 本地运行

1. 用 Godot 4.3+ 导入 `game/project.godot`。
2. 运行项目；一台实例点击“创建主机”。
3. 其他实例填入主机局域网 IP，点击“加入主机”。
4. 四台实例分别用 WASD 或方向键移动，验证颜色和位置同步。
5. 主机点击阶段按钮，验证所有实例的阶段标题同步变化。

## 局域网排查

- 所有电脑使用同一 Wi-Fi/局域网，并确认主机 IP。
- Windows 防火墙允许 Godot 测试程序使用专用网络。
- 若无法加入，确认端口 `24567` 未被其他程序占用。
