# 腐墟星废弃学校室内

学校位于城西北，外形是三层教学楼 + 连廊。大门打开后进入独立室内层，
入口在 1F 南侧大厅，出口也在同一位置。

## 楼层

### 1F · 大厅 / 食堂 / 校长室

- 接待台、奖杯柜、公告板、候诊椅、储物柜。
- 食堂长桌、打菜台、菜单板、餐盘。
- 校长室办公桌、文件柜、书架和相框。
- 入口门厅有水磨石地砖、旧荧光灯和“安全出口”灯。

### 2F · 教室 / 实验室

- 三间教室：成排课桌、讲台、黑板、储物柜。
- 科学实验室：实验台、烧杯、试剂架、洗手池。
- 走廊有班级牌、管道、吊顶梁和散落纸张。

### 3F · 计算机房 / 天文台 / 广播站

- 计算机房：六台旧电脑、服务器机柜、机柜指示灯。
- 天文台：星图桌、旋转星图环、望远镜、星图海报；**天文观测数据**在桌上。
- 广播站：调音台、麦克风、ON AIR 红灯、留言板；暗示学校最后的求救广播。
- 3F 走廊有红色应急灯和更明显的撤离痕迹。

## 西侧楼梯

- 折返楼梯连接 1F/2F/3F，楼梯井有扶手和楼板开洞。
- 每层楼梯口有青色门框，可回到中央走廊。

## 剧情任务物

| 任务物 | 位置 | 作用 |
| --- | --- | --- |
| 天文观测数据 | 3F 天文台桌上 | 与超市民用导航模块拼成导航密钥；记录菌群沿能源站循环管网扩散的路线 |

- 靠近按 E 取走；队伍共享，不占普通物品格。
- 学校/超市内 HUD 显示 `导航线索 · 观测数据○ 民用导航模块○`。
- 两件都取走后提示“导航密钥拼合完成”，写入日志。
- 状态进 `sync_ruin_progress` 快照，晚加入客户端同步隐藏。

## 入口与出口

- 学校门锁打开后，门前提示 `[E] 进入废弃学校`。
- 进入后落在 1F 大厅，面朝走廊。
- 转身靠近南门按 E，提示 `[E] 离开学校 · 回到大门`。
