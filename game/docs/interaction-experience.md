# 交互与操作反馈补强

更新：2026-10-13。本轮在已有现场设备、扫描器、日志和联机同步的基础上，补齐持续操作的可视化进度与关键动作的即时反馈。

## 已完成

### 持续操作进度

- 现场设备的解冻、修理、观测、绞盘和路标操作会在屏幕交互提示下方显示进度条。
- 进度由主机的真实操作计时驱动，离开设备、倒地或再次按 E 中止时立即归零，不会出现“看起来完成但状态未同步”的错觉。
- 进度条只在本地船员正在操作时显示，不遮挡日志、地图和目标面板。

### 战斗与救援反馈

- 攻击命中、未命中、受伤和救援成功会在目标上方短暂显示浮动文字。
- 攻击、受伤、倒地和救援会触发轻量镜头震动；震动只影响对应船员的本地镜头，不改变角色位置和联机状态。
- 信标修复、电池/冰样拾取、撤离点投送也增加了目标位置的浮动确认文字，方便多人协作时确认是谁完成了关键动作。
- 所有由主机确认的浮动文字和镜头反馈都通过可靠 RPC 同步，单人模式与多人模式使用同一套路径。

## 操作体验约定

- 交互提示仍以 E/F/G/R 等实际按键为准；进度条只表达“正在进行”，不会替代文字说明。
- 反馈文字使用与现有 HUD 一致的颜色语义：青绿代表完成，金黄代表关键目标，橙红代表伤害或危险。
- 镜头震动保持在短时、低幅度范围内，避免影响地图判断；返回主舱或传送时会清除残留震动状态。

## 验证

进入霜烬星后，靠近应急补给箱或供暖炉按 E，确认交互条随停留时间增长；离开设备后应立即消失。攻击敌人、受到伤害、救援队友，以及修复信标、拾取物资、投送物资时，确认目标附近出现浮动反馈且本地镜头产生短促震动。
