# 太空舱第一人称

日期：2026-10-22。依据：用户在太空舱 Blender 美术优化后要求“帮我做成第一人称的”。

## 当前操作

| 操作 | 功能 |
| --- | --- |
| 鼠标 | 水平转身、上下环视；俯仰限制约 ±72° |
| WASD / 方向键 | 跟随当前水平视线移动，A/D 横移 |
| Shift | 加速 |
| 空格 | 跳跃，重力落地；空中不能连跳 |
| E | 根据目标拾取、操作设施、安装、投送或救援 |
| 左键 / 右键 | 使用当前物品（空格攻击）/ 内置扫描器 |
| 1、2 / 滚轮 / G | 选择两格物品栏 / 循环切换 / 放下选中物品 |
| E 对准驾驶台 | 就位 / 取消；四台一人一台，全员就位倒数出发 |
| E 对准航线、集市等终端 | 直接操作对应设备，无需光标 |
| Esc | 关闭只读记录；否则打开设置 |

主舱与训练舱均采用第一人称。眼睛高度为 1.6 米，透视 FOV 74°，近平面 0.05 米；没有额外的走路摇头或强制镜头晃动。本机角色外观隐藏，其他船员的模型仍显示且朝向与角色根节点一致。

最新物品与训练规则见[两格物品栏与统一交互](interaction-inventory.md)。道具在场景和手中显示原生资产组合模型；两格位于画面底部，提示文字仍为 HUD 或地面标记。

主舱玩法采用[实体设备交互](ship-devices.md)，移除准备、集市、返回训练等 HUD 按钮和设施操作按钮；Tab 不再切换光标。只读航行记录和 Esc 设置打开时释放鼠标，关闭后恢复环视。离开房间恢复系统光标。登陆霜烬星后恢复该星球原有正交镜头，返航恢复舱内第一人称；共振星第三人称仍使用其已有控制路径。

## 舱室显示

当前主舱已按用户后续要求接入 Kenney Space Station Kit 和 Modular Space Kit，替换舱壁、地板、天花板及主要陈设。`ShipHub3D` 保留第一人称围合、灯光和公共设施坐标；`ShipHubKenneyArt` 维护新模块的排布与材质。旧 `ship_hub_blender_v2.glb` 仍加载，但只保留其程序星空窗和植物显示。资源、实机图与本轮验证见[Kenney 美术接入](ship-hub-kenney-art.md)。

运行时围合几何由 `scripts/ship_hub_3d.gd` 维护，未回写 Blender 原稿。原版剖面展示图和 Blender 工程继续保留。

## 验证与边界

- Godot 4.7.2 主工程启动：运行工具报告 `ok: true`，无解析和运行错误；已有 GDScript 风格警告保留。
- 主舱集成：39 项检查通过；镜头断言已从旧正交视角更新为透视投影、眼睛高度与本机模型隐藏。
- 图形输入回放：`tests/ship_first_person.gd` 共 28 项操作检查通过，覆盖真实鼠标事件、转向后前进、Tab、HUD 按钮点击、设施/航线/集市/设置光标、远端模型可见性、训练舱和登陆/返航切换。该测试需要图形显示；headless 驱动无法捕获鼠标，因此该入口在 headless 下明确报告未执行。
- 图形输入回放结束时，GLES3 驱动输出两条 `Texture ... leaked 349524 bytes` 纹理回收错误。行为断言通过，但不将整份退出日志标记为无错误；独立截图运行没有对应错误。
- 既有主舱双进程联网测试：主机 15 项、客户端 10 项断言通过；主机日志仍有客户端调用 authority `show_feedback_rpc` 被拒绝的报错。源码中 `_assign_kit()` 原有广播路径会在客户端执行，本轮未修改该工具分配逻辑，不将其写为联机日志完全通过。
- 静态 lint 修改前后均为 1 error / 9 warnings，未新增；原有错误为腐墟星引用缺失的购物车 SVG，其他为旧测试路径等提示。
- 实机检查中央舱室、舰桥、维修台和设施面板。截图位于 `art-source/editable/spaceship-cabin/first-person-preview/`，原始日志位于 `work/ship-first-person-20261022/`。
