# 新航程与当前星系图

2026-10-28。用户确认推荐方案后接入正式入口。归航目标与产量为本轮原型数值，尚待真人试玩平衡。

## 试玩流程

1. 正式主菜单选“新航程”，建立可供局域网加入的房间；单人可以直接游玩。飞船已坠落在霜烬星，普通燃料尚存、起飞核心损坏。“继续航程”读取独立航程存档；没有存档或文件无效时会保留文件并显示原因。
2. 航线电脑可查看当前星系。核心修好前无法飞往其他星球；选择霜烬星可“继续探索”。气闸右侧新增一台“出舱探索”电脑，也可确认进入停机坪。原训练舱门保留。
3. 在新霜烬星取得钥匙、开科考站保险柜、回船外核心台安装能源，再按 E 恢复航行。恢复航行不强制结束探索。停机坪船内新增固定图示的进舱设备，靠近按 E，全队回到飞船附近后一起进入主舱。
4. 航线电脑显示当前星系连线、飞船位置、已访地点、普通燃料、归航能源和归航物资。点击星球只浏览；确认才设定全队计划。任何船员可提交，其他人就位前可改；过期的并发确认会被拒绝并提示重新选择。
5. 全体在线船员分别在四个驾驶席按 E 就位，三秒后出发。单人只需一席。换目的地、离席、加入和掉线清除旧准备。驾驶席固定屏幕显示目的地。
6. 共振星沿用现有关卡，完成核心搬运并返舱后将能源唯一入账。腐墟星沿用现有搜刮点，回西南登陆点按 E、全员集合后撤回主舱，已搜刮物资唯一入账。返回主舱时位置为对应星球轨道。
7. 再访霜烬星保留钥匙、已安装核心、融冰、开箱、调查和剩余物资；不会重刷关键能源。任务钥匙与归航运输箱物资在队伍任务匣中，不占两格。工具、电池、氧气瓶及余量可以在舱内与新霜烬星之间往返，热风机在舱内放下再拾取仍保留电量。
8. 地球为远程归航出口。资源达标后确认返航，再走全员驾驶席流程；达标不会自动结束探索。抵达后打开归航记录，停止继续远征；可以从菜单新建另一航程。

## 本轮资源配置

- 普通燃料初始 4；霜烬星核心台交付按累计差量入账；带回主舱的燃料可选中后左键存入。暂不扣航行燃料，避免未验证的耗油经济产生软锁。
- 霜烬星 frost_core_01 记为“已安装”，只恢复航行能力，不重复计入可用归航能源。
- 原型归航要求：能源 2、物资 2。共振星首次成功回收核心提供能源 2，重复完成不重复发放。
- 霜烬星三个可选运输箱各有一份归航物资；开箱记录交给航程层，以稳定箱 ID 唯一结算。现场原有应急物品照常留下。腐墟星每个首次搜刮点可带回一份归航物资。因此可以深挖霜烬星，也可以去腐墟星补齐，不要求把所有星球都通关。
- 日志、凶手结论与所有支线完成度均不作为返航门槛；没有加入跨星球钥匙。

## 状态、网络和存档

`CampaignNavigation` 管位置、核心、归航储备、计划版本与唯一结算。`CampaignTravel3D` 管公共主舱与新霜烬星的切换。星球元信息的 available 表示内容存在，玩家能否出发由航程条件另行检查。正式选星接新霜烬星；原 `_create_host()` / 旧 demo 启动只保留为既有测试和开发调用。

主机拥有任务、资源和计划。新霜烬星保持已有主机移动模拟；主舱维持既有移动方式。临时星球节点的输入与状态通过稳定航程节点传递，使用切换代次拒绝迟到包，客户端建好场景后确认接收。世界状态使用可靠包；船员位姿由服务器转发，航程关闭客户端互相转发。未加入预测、主机迁移、公网延迟保证或外部账户。

新航程独立写 `user://campaign-v1.json`，不读取或覆盖旧 `ship-cabin-save.json`。版本、校验值和完整类型快照一起保存，先写临时文件再原子替换；未知版本/校验失败拒绝读取并保留原文件。新霜烬星探索中每五秒保存，并在正常关闭窗口时补存。继续时回到飞船，保留新霜烬星世界与任务进度、船舱物品和归航账目；共振星/腐墟星不承诺恢复退出瞬间的战斗位置。非主机的旧网络 ID 不作永久身份，其保存的随身物品恢复为主舱共享实物，重新加入不会复制发放。

测试入口：`tests/campaign_navigation.gd`、`tests/campaign_navigation_input.gd`、`tests/campaign_navigation_network.gd`、`tests/campaign_navigation_four_peers.gd`。证据与限制见 `work/gameplay-iterations/20261028-navigation-story-alignment/`。没有据此宣称真人节奏、探索趣味或最终经济平衡已验证。
