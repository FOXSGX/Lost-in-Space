# 霜烬星战斗试玩调整（2026-10-19）

本次是可试玩的机制验证，不代表团队已经确认最终设计。

当前霜烬星已有调查、信号、热源、收集和支线，继续叠加任务未必能改善操作乐趣。本次只调整敌人的近身攻击：靠近到 2.8 米后，敌人在玩家当前位置显示半径 1.6 米的橙圈，蓄力 0.75 秒后向锁定位置扑击。预警开始后落点不再追踪玩家。落地只结算一次伤害，随后停顿 1.25 秒，形成诱导、躲避、反击的循环。风暴仍提高追击速度，但不缩短预警、不额外提高这次扑击伤害。

玩家可以普通移动离开橙圈，不要求额外按键或新装备。低频信号仍可在蓄力前诱导敌人；已经开始的扑击不会被新诱饵取消。碰到墙时扑击会被阻挡，伤害以实际落点为准。伤害由主机结算，橙圈与蓄力/恢复标签通过可靠 RPC 同步；敌人死亡时橙圈随节点清理。

仅霜烬星调用启用这套规则，共振星与腐墟星沿用原有攻击逻辑。现有客户端与主机应一起更新版本。中途加入时，已经开始的短暂预警不补发，下一次攻击起正常同步；正式多人试玩仍需观察网络延迟对躲避窗口的影响。

验证：`frost_attack_window.gd` 覆盖提前预警、落点锁定、躲避免伤、停顿反击、风暴命中、低频诱导与旧规则兼容；`frost_controls.gd` 覆盖现有霜烬星流程。

试玩时关注：玩家是否能认出橙圈、是否愿意主动诱导扑击、同时出现多个敌人时能否读清预警。地图过大、调查步骤较多仍是后续需要单独验证的问题，本次不宣称已解决整颗星球的可玩性。
