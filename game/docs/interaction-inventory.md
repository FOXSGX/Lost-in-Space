## 操作方案

| 输入 | 行为 |
| --- | --- |
| WASD、鼠标、Shift | 移动、环视、加速 |
| 空格 | 短按跳跃；长按喷气，单瓶 0.5 秒 / 双瓶 1 秒，按格位依次耗条；落地松开等待后两条同时耗氧恢复 |
| E | 对附近目标执行拾取、安装、投送、救援、操作设施等上下文动作 |
| 左键 | 使用选中物品；选中空格时攻击 |
| 右键 | 内置扫描器，不占物品栏 |
| Tab | 切换装备栏 / 手持物品栏焦点，保留两栏各自选格，不释放鼠标 |
| 1 / 2、滚轮 | 选择当前栏的两个格位 |
| G | 手持栏丢落选中物品；装备栏卸下选中装备并丢在地上；空格无操作 |
| Esc；星球 J / M | 关闭记录/设置；星球日志与地图 |

取消训练对 Q/F/G/R/空格分别代表七种互动的依赖。星球的专用工具、合作装置、任务条件保留，公共入口负责把 E 转为已有操作；地图、无人机等辅助功能不加入基础训练。

## 物品与反馈

- 初始恰好两格，一格一件，不叠加。医疗包、氧气瓶、电池、样本和可重复使用的欢乐道具使用同一容量。
- 底部两个手持格，屏幕左侧竖排两个橙色装备格，容量互相独立。高亮边框只出现在当前栏的选中格；空格不显示文字。氧气瓶所在装备格显示右下角余量及同格内喷气细竖条。选中装备栏时左键不会误用手持物品，走动、环视、E 拾取仍可使用。电脑、设置等界面打开时 Tab/G 不操作装备栏。
- 可装备道具为氧气瓶、恒温外套、广域扫描器、信号稳压器。所有新装备统一优先占空位；满栏时替换同类（选中格为同类则优先该格，否则按格位顺序），旧装备回到当前手持格；满栏且无同类才提示“装备栏已满”。同类也允许放入两个格位；氧气瓶容量叠加，其他现有装备效果仍按是否穿戴判定。装备电脑的领取仍受共享拥有数量限制，不生成额外物件。
- 两瓶氧气各自保存氧气余量和充气条，按装备格从上到下依次消耗，上一瓶耗尽立即接下一瓶；落地松开等待 0.3 秒后两条同时恢复，空到满各约 1 秒，各消耗对应瓶内 2% 氧气。每条满条支持 0.5 秒，双瓶总计 1 秒；推力保持原值。空瓶不会阻断另一瓶的充气。新瓶初始不赠送压力，卸下、拾回、同类替换保留各瓶已有充气量。
- 卸装不依赖手持空位：装备直接生成有碰撞的地面刚体，原装备位清空、效果停止；可 E 拾回重新装备。G 不再从手持空格隐式卸下氧气瓶。共享装备拥有总数与价格保留，可领取量扣除全队已装备、手持和地面已有件数，防止卸下后从电脑重复领取同一件。
- 实体和手持模型使用现有 Kenney 箱体、管件、原有工具资产组合，物品在世界、物品栏和手中名称一致。没有悬浮名称牌，提示放在 HUD。
- 医疗包恢复生命成功才消耗；氧气瓶拿起后左键安装为宇航服推进设备，释放物品格，瓶内余量随充气减少，补给设备才能补回；HUD 以装备格百分比和同一装备格内的细条分别显示瓶内氧气和喷气储备。欢乐道具重复使用不扣数量、不加冷却。
- E 优先处理救援、近处可投送点和可拾取实体，再走设施/关卡操作。上下文解析与 HUD 使用同一组状态判断，遮挡物后方的实体不可拾取。信号阵列和地下异常改为 E 打开选项，鼠标选择，避免占用 1/2；选项仅在有效距离和短时有效期内接受。
- 放下的物品留在当前区域，可再次拾取；多人争抢同一个实体只允许主机确认一次。

## 训练改造

训练舱已按用户追加要求改为氧气瓶推进练习：拿取实物氧气瓶、左键安装、短按跳上低台、长按登上高台、跨越落台抵达终点。没有供电、扫描和打靶前置关卡，进度根据真实落地位置判断。

场内设置不同高度的落台、实物架、灯带和固定在墙上的操作图示，不使用悬浮文字。训练随时可离开；练习物资和宇航服设备与正式状态隔离，退出或提前取消均恢复进入前的物品、装备和生命状态。详见[氧气瓶推进训练](oxygen-jet-training.md)。

大型能源核心、磁力货箱和冷却单元也需要一个空格才能接入；它们保留原合作规则与场景实体。未投送的星球任务货物不会以失效引用带回主舱；失败时两格货物均按既有规则散落回星球。欢乐道具单次点击立即使用，不沿用攻击间隔作为冷却。

## 联机与存档边界

- 主机拥有库存、物品格、拾取实体、训练进度和使用结果；客户端提交动作，不能提交任意物品或数量。发送者身份从 RPC 获取。
- 背包、当前格、丢落物和训练快照进入可靠状态同步，中途加入得到同一状态。显示不提前扣除共享物资。
- 两个装备位、装备栏焦点及选格同样由主机确认并可靠同步。氧气余量和每瓶充气条按格位同步，旧消息不能回涨资源。旧背包缺少装备数组时恢复原氧气瓶标记和可用旧装备分配。训练进入时隔离两栏，离开恢复正式装备、选格、焦点和余量。共享装备的拥有总数沿用现有存档字段；离队与保存按实际瓶数及各瓶氧气余量归库，不新增临时网络 ID 存档。
- 拾取不做本地预测，网络延迟时等待主机确认；同一实体移除后后续请求不能再领取。掉线时随身补给回库，正常任务货物留在现场，合作货物释放已有占用。
- 临时网络 ID 不存入长期库存。退出房间时剩余正式补给归还共享库存；练习物品不回库。既有 v1-v3 存档仍按共享库存读取，旧文件不需要转换。
- 任务电池/样本保持关卡引用，拾取、投送、放下同时更新关卡实体和物品格，避免复制和幽灵物品。
