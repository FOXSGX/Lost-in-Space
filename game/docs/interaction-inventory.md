# 两格物品栏与统一交互

2026-10-22。用户确认范围：道具实体化、初始两格物品栏、简化操作并重做训练室；追加空格跳跃。下面的键位、训练顺序和物品规则为本轮实现方案，保留后续试玩调整空间。

## 操作方案

| 输入 | 行为 |
| --- | --- |
| WASD、鼠标、Shift | 移动、环视、加速 |
| 空格 | 短按跳跃；安装氧气瓶后长按喷气登高（基础满条 0.5 秒），落地松开等待后耗氧充气 |
| E | 对附近目标执行拾取、安装、投送、救援、操作设施等上下文动作 |
| 左键 | 使用选中物品；选中空格时攻击 |
| 右键 | 内置扫描器，不占物品栏 |
| 1 / 2、滚轮 | 选择两个物品格 |
| G | 放下当前格的物品；空手格时卸下宇航服氧气瓶 |
| Esc；星球 Tab / M | 关闭记录/设置；星球日志与地图 |

取消训练对 Q/F/G/R/空格分别代表七种互动的依赖。星球的专用工具、合作装置、任务条件保留，公共入口负责把 E 转为已有操作；地图、无人机等辅助功能不加入基础训练。

## 物品与反馈

- 初始恰好两格，一格一件，不叠加。医疗包、氧气瓶、电池、样本和可重复使用的欢乐道具使用同一容量。
- 底部物品栏保留两个携带格，屏幕左侧单独竖排橙色宇航服装备格。当前携带格用边框标识；空格不显示文字。装备格内显示氧气瓶图标，右下角显示剩余百分比；喷气储备是一根嵌在氧气瓶装备格右侧内部的细竖条。物品名称在针对实体的交互提示和拾取反馈中出现。新物品进入空格，满格拒绝且不扣共享库存、不替换已有物品。
- 实体和手持模型使用现有 Kenney 箱体、管件、原有工具资产组合，物品在世界、物品栏和手中名称一致。没有悬浮名称牌，提示放在 HUD。
- 医疗包恢复生命成功才消耗；氧气瓶拿起后左键安装为宇航服推进设备，释放物品格，瓶内余量随充气减少，补给设备才能补回；HUD 以装备格百分比和同一装备格内的细条分别显示瓶内氧气和喷气储备。欢乐道具重复使用不扣数量、不加冷却。
- E 优先处理救援、近处可投送点和可拾取实体，再走设施/关卡操作。上下文解析与 HUD 使用同一组状态判断，遮挡物后方的实体不可拾取。信号阵列和地下异常改为 E 打开选项，鼠标选择，避免占用 1/2；选项仅在有效距离和短时有效期内接受。
- 放下的物品留在当前区域，可再次拾取；多人争抢同一个实体只允许主机确认一次。

## 训练改造

训练舱已按用户追加要求改为氧气瓶推进练习：拿取实物氧气瓶、左键安装、短按跳上低台、长按登上高台、跨越落台抵达终点。没有供电、扫描和打靶前置关卡，进度根据真实落地位置判断。

场内设置不同高度的落台、实物架、灯带和固定在墙上的操作图示，不使用悬浮文字。训练随时可离开；练习物资和宇航服设备与正式状态隔离，退出或提前取消均恢复进入前的物品、装备和生命状态。详见[氧气瓶推进训练](oxygen-jet-training.md)。

大型能源核心、磁力货箱和冷却单元也需要一个空格才能接入；它们保留原合作规则与场景实体。未投送的星球任务货物不会以失效引用带回主舱；失败时两格货物均按既有规则散落回星球。欢乐道具单次点击立即使用，不沿用攻击间隔作为冷却。

## 联机与存档边界

- 主机拥有库存、物品格、拾取实体、训练进度和使用结果；客户端提交动作，不能提交任意物品或数量。发送者身份从 RPC 获取。
- 背包、当前格、丢落物和训练快照进入可靠状态同步，中途加入得到同一状态。显示不提前扣除共享物资。
- 拾取不做本地预测，网络延迟时等待主机确认；同一实体移除后后续请求不能再领取。掉线时随身补给回库，正常任务货物留在现场，合作货物释放已有占用。
- 临时网络 ID 不存入长期库存。退出房间时剩余正式补给归还共享库存；练习物品不回库。既有 v1-v3 存档仍按共享库存读取，旧文件不需要转换。
- 任务电池/样本保持关卡引用，拾取、投送、放下同时更新关卡实体和物品格，避免复制和幽灵物品。

## 验证计划

1. 两格混合携带、第三件拒绝、切换、无效使用不消耗、放下再拾取、投送清格与资源守恒。
2. 完整训练用真实状态完成；跳步骤、超距、满格、提前退出、重复进入、两名玩家独立进度及练习资源隔离。
3. 空格起跳、空中不能连跳、落地、开面板不跳、主舱/训练/星球输入映射一致。
4. 既有主舱集成、第一人称、星球资源与真实双进程联网检查；保存实机 HUD、实体和训练流程截图。测试通过不代表新玩家已无理解成本，仍需用户试玩。

## 试玩反馈修复：训练舱出入口与氧气瓶（2026-10-22）

- 进入训练舱的落点从左侧练习区改到右后方门内，视线朝向练习区；退出后回到主舱气闸内侧，朝向主舱。多人在门前分开站位。初次创建主舱和星球返航仍使用原来的主舱出生点。切舱时清除上一舱的临时提示。
- 原先训练氧气瓶只按阶段生成，没有记录领取，导致取走后仍留在补给目录。现在主机为每位玩家记录本轮已领取物品，并随快照同步。每轮每种练习物品只提供一件，放下可拾回原物，使用后不会自动补货；完成后明确重置练习或退出重进才刷新。正式共享库存不受练习影响。
- 拾取前重新核对当前权威目录，过期实体请求不能复制物品；满格失败不写领取记录。医疗包在电池收纳后提供，避免提前拿取造成教学步骤无法完成。

修复验证：`inventory_training.gd` 55 项通过；实际输入回放增加出入口位置/朝向、重复 E、放下再拾取、使用后再领取和跨舱提示检查；双进程主机 27 项、客户端 19 项通过，两端错误日志为空。日志位于 `work/training-fixes-*.log`，出入口实机截图为 `previews/05-training-entry.png` 与 `previews/06-training-return.png`。工程导入和启动回执位于 `work/training-fixes-validation/20261022T031936067Z-015db68d/receipt.json`。

## 试玩反馈优化：减少界面文字（2026-10-22）

用户明确要求空物品格留白、减少整体界面文字。本轮物品栏改为两个 68 像素图标格，移除空手说明、常驻物品名、格位数字、重复计数与操作口诀。选中状态保留高亮边框，当前教学动作仍用一条短提示说明。

主舱和训练舱缩短标题与状态，移除无交互目标时的常驻按键说明；提示框按文字宽度收窄。设施面板保留资源数量、费用和效果，删除重复解释。星球 HUD 移除整排按键清单与“背包空”，目标文字收为三行；剧情和日志正文保留。

设置页仅保留标题、三项功能与当前按键、“默认”和“继续”。按钮悬停可提示改键，进入改键时才出现新按键/取消说明。实际输入回放检查 Esc 打开、改键入口、取消改键和恢复游戏；界面文字减少没有取消已有功能。
