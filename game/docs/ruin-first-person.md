# 腐墟星第一人称与精致卡通改版

更新时间：2026-11-27
状态：腐墟星已移除丧尸与激光剑；保留第一人称、撬棍撬门与撬锁。以下“感染体/近战”章节为历史记录，不再代表当前玩法。

## 方向

- 视角与归航号主舱一致：第一人称、眼高 1.62 米、鼠标环视、WASD 沿视线移动。
- 美术与主舱一致：奶油白壳体、青蓝结构、暖橙功能色、低饱和鼠尾草绿点缀；
  低模但轮廓清楚、表面干净，靠倒角、色块和道具读体积，不靠脏污与暗部。
- 腐墟星为纯探索关：不生成丧尸/感染体，第一人称不显示激光剑，也没有 F 近战。

## 操作

| 输入 | 行为 |
| --- | --- |
| WASD / 鼠标 / Shift | 第一人称移动、环视、加速 |
| 左键 | 使用当前物品 |
| E | 上下文交互：翻找、撬锁、查看建筑、在登陆艇返航 |
| R | 撬棍暴力撬门（不需要撬锁工具） |
| 右键 | 扫描 |
| Tab | 收起/展开任务栏 |
| I / 1–4 / 滚轮 / G | 装备栏、切格、丢落（四格手持 + 两格装备） |
| J / M | 日志 / 地图 |
| Esc | 设置；打开时释放鼠标 |

第一次点击如果光标还在窗口状态，会先收回准星，不当作攻击。

## 相机

- 本地玩家：透视相机，FOV 76，近裁面 0.05，远裁面 400。
- 眼高 1.62 米；倒地降到 0.55 米并轻微侧倾。
- 相机跟随玩家朝向与俯仰，俯仰上限 ±1.15 弧度；走路有很小的上下摆动。
- 第一人称下隐藏本地角色模型；远端玩家仍显示第三人称角色。
- 离开腐墟星时在 `return_to_ship()` 中恢复主舱第一人称，避免把透视相机带回舱内。

## 玩法边界（2026-11-27）

- 腐墟星不再生成 `RuinInfected`/丧尸，也没有噪音吸引、感染者伤害、近战命中和击杀反馈。
- 第一人称不显示 `Saber*` 激光剑；F 不再触发近战。`main_3d` 的通用敌人攻击逻辑保留给霜烬星/共振星，不影响腐墟星。
- 保留 `E` 撬锁小游戏与 `R` 撬棍暴力撬门；两者都有实体动画和主机权威结算。
- 任务栏不再显示噪音百分比，只显示目标、任务物品进度、回收价值和用时。

## 美术实现

- `ruin_cartoon_art.gd`：调色板、倒角方盒、水平面片、路灯、花坛、长椅、树、护柱、
  接地软阴影。所有材质在写入 `albedo_color` 前做一次 `srgb_to_linear()`，
  避免十六进制色被当成线性色后整体发白。
- 环境：程序化天空（灰青低天顶 + 脏灰地平线）、冷灰方向光、高密度雾、ACES 色调映射；
  阴影只保留方向光软阴影与贴地软阴影，不依赖暗紫环境。
- 全图光照在 2026-11-10 再次压暗：环境光改成低能量灰绿色、曝光 0.69、太阳 0.75、
  雾密度 0.0085，饱和度 0.82、对比度 1.14；奶油/青蓝/暖橙调色板整体降明度。
- 地面：水平面片 + 顶点色噪声 + 8 米铺装分缝 + 积水；主街、支路、广场、
  人行道、斑马线、车道虚线重新用面片铺，避免压扁盒体顶面法线导致发暗。
- 建筑：通用的学校/图书馆改成倒角奶油壳体 + 珊瑚/青蓝屋顶 + 青蓝窗带 +
  暖橙雨棚 + 几何招牌色带；南侧原加油站改为**废弃能源站**（储能柜、充电塔、
  变压器、顶棚太阳能板）；超市与医院保留原体块和破洞，改用同一套配色，
  去掉整面做旧层与水渍层，血迹改成低饱和珊瑚。
- 陈设：8 盏路灯、8 个花坛、5 张长椅、公交站、树线、远景低丘与远处建筑剪影；
  地面另撒 26 丛草和 20 块碎石，全部无碰撞。
- 感染体相关美术与动画已在 2026-11-27 停用；以下章节仅保留历史记录。

## 历史记录：2026-10-31 感染体动作（已停用）

- 现有感染体不是贴图，而是运行时拼的低模分件。之前只有受击缩放和整体倒地，
  没有步态，所以移动时像整只滑行。这一轮在分件模型上加关节和程序化动作，不重做 GLB。
- 新增二级关节：步行者的膝（`KneeL/KneeR`）和肘（`ArmLElbow/ArmRElbow`），
  鼓胀者也补了肘；每个关节带球状关节盖，弯曲时不会露出空隙。
- 动画由 `RuinInfectedVisual.animate()` 每帧在**初始站姿上叠加**：
  - 步行者：左右腿反相摆动、膝盖在后摆时收紧、身体上下起伏、头部缓慢扫视、双臂反向轻摆。
  - 鼓胀者：更慢的左右摇晃 + 肚子呼吸缩放 + 手臂拖摆；即使停下也有轻微晃动。
  - 爬行者：两条手臂交替向前拖、残肢踢动、身体起伏，摆幅比站立形态更大。
  - 攻击：靠近后的攻击窗口内双臂抬起、身体前倾；主机通过 `sync_ruin_attack` 让客户端也看到前扑。
  - 受击：保留原来的挤压回弹，并叠加短促的躯干/头部后仰。
  - 死亡：先停掉步态，再由 `RuinInfected3D.play_death()` 整体倒地、压扁。
- 没有使用 Blender：本机没有可用的 `blender` 可执行文件，也没有腐墟星感染体的 `.blend` 源文件；
  现有模型是运行时按形态拼的分件，直接加关节和程序化动画比新做一套 GLB 骨骼风险更低，
  也能保持现有低模、碰撞和联机同步。

## 2026-10-31 物品落脚与铺装碰撞

- **物资箱不再埋在铺装里**：广场顶面是 9cm、主街 3.5cm、人行道 4cm、店前小路 6cm。
  五个物资点现在统一按 `surface_height(x, z)` 落在真实顶面上，物质环和箱底都在地表之上。
- **物资箱和登陆艇补了实体碰撞**：玩家、感染体和掉落物不会再从箱体/停机坪里穿过去。
- **food_b 原来正好压在广场长椅上**（(6,12) 的自动售货机与 (6,12) 长椅同点），
  已挪到广场中北部的 (0,12.5)，不再和长椅/花坛重叠。
- **铺装补了薄碰撞**：主街、人行道、中央广场、店前小路、门前平台各加一层只做顶面的
  `StaticBody3D`（layer 2），掉落物和角色不会沉到 y=0；视觉平面不增加侧面台阶。
- **街具跟着地表抬高**：路灯、花坛、长椅、树、护柱、公交站和建筑门口护柱都按
  `surface_height` 放到广场/人行道顶面，不再出现“椅子腿埋进广场”。
- **感染体出生点**也按地表高度放置，不会在广场/店前路出生时卡进碰撞层。
- 新增 `ruin_item_placement.gd`：检查五个物资点顶面、街具间距、广场/主街碰撞射线，
  以及真实丢一个医疗包后它落在广场顶面而不是穿下去。

## 2026-11-03 大门锁与二级弹子锁

- 5 栋建筑的大门默认全部上锁，外观统一：黄铜锁板 + 锁芯 + 锁孔 + 橙色锁灯。
  所有门共用同一把**二级四弹子锁**，没有随机难度或每栋不同的锁型。
- 靠近门后提供两种开法：
  - `E` 撬锁：需要物品栏里的**撬锁工具**；没有工具时只提示缺工具，不会打开界面。
  - `R` 暴力撬开：不需要工具，直接拿撬棍顶住门缝，主机计时 **2.4 秒**；
    玩家必须留在门口，完成后直接跳锁并发出较大噪音。
- 每局登陆自动把一把撬锁工具放进空物品格（图标借用了维修扳手）；工具不消耗，
  但可以被丢掉或选择/丢弃，丢了就只能用 R 暴力撬门。
- 撬锁界面是独立 CanvasLayer：
  - `A / D` 或 `← / →` 选择弹子；
  - 按住鼠标左键或空格把弹子往下压；
  - 弹子压到底会卡住并变绿，松开没到底的弹子会弹回；
  - 四根全部卡住后锁芯归位，门锁打开；
  - `Esc` 退出，`R` 重置；失败/取消不消耗资源、不报警。
- 门锁状态由主机权威：主机校验玩家仍在门口后才会开门；`unlocked` 进入
  `sync_ruin_progress` / `sync_full_state` 快照，晚加入的客户端也能看到哪些门已经开了。
- 开门后锁模型收起，并沿用原有 `enter_building()` 登记发现；医院有独立室内，其他建筑内部仍然未开放。
- 再次登陆会重置所有门锁和建筑发现状态。

## 一局目标与撤离

- 目标：翻找 **3 处物资** + 查看 **3 栋建筑**（共 5 处物资、5 栋建筑，允许不同路线）。
- 目标完成后：`extraction_enabled = true`，登陆艇亮起青绿灯带，HUD/罗盘提示“撤离开放”。
- 全员（未倒地）进入登陆艇 4.2 米范围并保持 **3 秒**，任务完成，2.5 秒后返航。
- 目标未完成时按 E 是**紧急返航**：立即回主舱，不结算“搜刮完成”，总结里会写明当前进度。
- 全员倒地仍然失败，总结改成腐墟星口径。
- 主机通过 `sync_extraction_state` 同步开放/读条，通过 `sync_ruin_progress` 同步已翻找物资、已登记建筑和噪音。

## 2026-10-29 门面光栅修复与色调压暗

- **光栅根因**：门洞、门板、壁柱、窗玻璃有几处落在同一深度平面，移动时出现横向或竖向 z-fighting。
  已确认的典型位置：通用建筑门洞中心的奶油壁柱与门板共面；医院 `EntranceRecess` 的正面正好贴在病房楼墙面上；市场店面玻璃背面与墙体共面。
- **修复**：
  - 通用建筑不再在门洞中心生成壁柱；门洞、门板、门框各自拉开深度差。
  - 医院门洞暗面前移并减薄，木门整体前移；病房楼正/侧/背窗、门诊翼窗全部离开墙面 12cm。
  - 市场店面整组前移，玻璃/竖框/窗台/门洞分别留深度差；门洞暗面缩薄并退到门后。
  - 门框、窗棂、招牌、灯杆等薄片不再投射实时阴影，避免细影在移动时变成条纹；建筑主体和贴地软阴影保留。
- **色调**：天空改为更灰的青蓝，环境光/曝光/饱和度下调，奶油白、青蓝、暖橙整体压暗，保留原色相和可读性，气质更接近“废弃殖民城”而不是明亮样板间。
- **名称**：主舱星图设备中的显示名从“废墟星”统一回“腐墟星”，与航线图、HUD 和文档一致。

## 联机

- 客户端收到 `sync_full_state` 时按 `planet_id == "ruin"` 切星球、建世界、生成本地玩家，
  再应用感染者快照；此前客户端会落回霜烬星。
- 第一人称只作用于本地客户端；远端玩家仍按第三人称位置与朝向插值。
- 返航时收起腐墟星世界、清空本局感染者、恢复 `current_planet_id = "demo"`，
  防止感染体在主舱里继续 `tick` 或刷到飞船内。
