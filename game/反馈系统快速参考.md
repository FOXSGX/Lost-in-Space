# 🎮 反馈系统快速参考

## 操作键位与反馈

| 按键 | 操作 | 视觉反馈 | 文字反馈 |
|------|------|---------|---------|
| **WASD** | 移动 | 🔵 浅蓝脚步粒子 | - |
| **空格** | 攻击 | 🔵 青色光束 + 🔴 红色爆发（击杀） | 🟠 "命中 -1 HP" / 🔴 "✓ 击杀异形" |
| **Q** | 扫描 | 🔵 扫描圈扩散 | 🔵 "扫描启动..." |
| **E** | 修复信标 | 🟡 金色粒子爆发（20个） | 🟡 "✓ 信标修复成功" |
| **F** | 拾取电池 | 🟢 青绿粒子爆发（15个） | 🟢 "✓ 电池已拾取" |
| **G** | 投送电池 | 🔵 蓝色粒子爆发（25个） | 🔵 "✓ 电池投送 X/Y" |
| **R** | 救援队友 | 🟢 青绿粒子爆发（30个） | 🟡 "救援中..." / 🟢 "✓ 队友救援成功" |

## 被动反馈

| 事件 | 视觉反馈 | 文字反馈 |
|------|---------|---------|
| **受到攻击** | 🔴 红色粒子爆发（12个） | 🔴 "受到攻击 -X HP" |
| **倒地** | 🔴 深红粒子爆发（25个） | 🔴 "× 你已倒地！" |
| **攻击失败** | - | 🔴 "× 超出射程" |
| **扫描冷却** | - | 🟠 "× 扫描冷却中 X.Xs" |

## 颜色语义

| 颜色 | 含义 | 代码 |
|------|------|------|
| 🟢 青绿色 | 成功、友好、治疗 | `#6ee7b7` |
| 🔵 蓝色 | 中性、信息、功能 | `#5ac8ff` |
| 🟡 金黄色 | 重要、关键、任务 | `#ffd966` |
| 🟠 橙色 | 警告、注意、冷却 | `#ffaa66` |
| 🔴 红色 | 危险、伤害、失败 | `#ff6b6b` |
| 🔴 深红色 | 严重、倒地、死亡 | `#ff3333` |

## 物体识别

| 物体 | 标签颜色 | 光源颜色 | 操作 |
|------|---------|---------|------|
| **敌人** | 红色 | 🔴 红色光 | 空格攻击 |
| **气象信标** | 金黄色 | 🟡 黄色光 | E键修复 |
| **热能电池** | 青绿色 | 🟢 青色光 | F键拾取 |
| **撤离点** | 蓝色 | 🔵 蓝色光 | G键投送 |
| **安全屋** | 橙色 | 🟠 橙色光 | 自动补氧 |

## 核心代码函数

```gdscript
# 显示屏幕反馈
_show_feedback(text: String, color: Color, duration: float)
show_feedback_rpc.rpc(text, color, duration)

# 生成粒子爆发
_spawn_particle_burst(position: Vector3, color: Color, count: int)

# 生成脚步粒子（玩家脚本）
_spawn_footstep_particle()
```

## 性能指标

- ⚡ 帧率：≥60 FPS
- 🎨 粒子数：12-30个/次
- ⏱️ 粒子生命：0.4-0.8秒
- 💾 内存：自动清理，无泄漏
- 📡 网络：RPC同步，延迟<50ms
